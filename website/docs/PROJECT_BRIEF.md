# MAW 官网项目简报

## 本轮目标

接续 PR 236，把官网做成柔和、典雅、有科技感的产品展示。视觉由 Astra High 负责，文案、资料核对与集成由 Sol 负责。首页提供中英两版；更新页让访客连贯阅读各版变化，并直达该版说明与下载。

## 产品背景与事实来源

MAW（Moy’s ASR Workflow，阿墨的字幕工作台）把字幕生成后的校对、整理与交付接起来，适合口播、访谈、课程等内容。主流程：

```text
本地媒体 → 自选 ASR 服务 → .mosp 工程 → MAWE 校对 → 字幕 / 视频 / 剪辑交换文件
```

- [README](../../README.md)：定位、安装包和数据边界。
- [工作流](../../docs/user/WORKFLOW.md)：从转写到工程保存与导出。
- [编辑器](../../docs/user/EDITOR_GUIDE.md)：波形、字词时间码、字幕轨与可逆编辑。
- [工具箱](../../docs/user/TOOLBOX.md)：文稿修正、可选 LLM、媒体工具与交付。
- [数据契约](../../docs/engineering/JSON_SCHEMA.md)：工程真源是字幕与编辑状态；波形可重建。
- [发布管线](../../docs/releases/README.md)：正式版归档与真实发布附件。

云端 API 是主要识别路径，无须独显；由用户自己配置服务、支付 API 费用。实验性本地模型保留实验性标识。编辑与保存留在本机；云端转写发送音频，可选 LLM 整理发送相关字幕与文稿。MAW 没有自己的媒体服务器。

## 页面叙事与动效

1. 首屏：一句话说明用途，下载与 GitHub，下面立即看见编辑器。
2. 工作流程：转写、整理、交付的细线目录与可点击大图，每个阶段解释一个具体动作。
3. 编辑器：大幅界面与可控功能展示，支持鼠标、触屏、键盘；不自动无限滚动。
4. 常见问题：费用、设备、数据去向与导出能力，原生折叠，脚本不可用仍可读。
5. 收尾：下载、上手指南和开源入口。
6. 更新记录：正文连续阅读，月份索引定位，保留每版独立 URL 与真实下载。

动效用于入场、展示切换和轻微景深；减少动态偏好下取消位移、缩放与平滑滚动。移除无目的背景粒子与外部 Star 计数请求。移动端保持自然换行和清晰点击区域。

## 内容与交付边界

- 不承诺免费云端识别、所有字幕逐字精准或任意地区可访问。
- 不把实验性本地模型宣传为稳定默认路径，不把 MAW 宣传为完整剪辑软件。
- 不在官网索要 API Key 或上传媒体；下载始终指向真实 GitHub Release。
- 首页与更新页独立样式，文档页面保持现有外观。
- Launcher 原型图如保留，须明确标为设计预览；发布前由维护者确认素材与版本相符。
- 自动化布局检查与人工审美验收分开；手机真机与跨浏览器观感仍需维护者确认。

## 本地维护

先运行 `pnpm --dir website install --frozen-lockfile`、`pnpm --dir website run sync:releases`，再运行 check、build 或 dev。真实发布核对用 `python scripts/build_release_site.py --github`。默认预览不向公开 JSON 宣告未发布软件更新，详见 [内容同步](CONTENT_SYNC.md)。
