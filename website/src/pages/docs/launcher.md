Launcher 负责选择媒体、转写、批量任务和工具箱。第一次安装见 [工作流](../workflow/)，服务商字段见 [PROVIDERS](../providers/)。

## 识别设置

先选择识别方式、供应商与模型，再设置语言、断句、热词或上下文。高级选项随模型能力显示，不支持的选项不能作为所有供应商的通用能力。

- 默认云端模型为 Qwen-Audio 3.0；3.1、Qwen3-ASR 和 Fun-ASR 可在模型菜单切换。
- Qwen-Audio 3.1 可选保留方言表达；其他模型不支持该开关。
- 已知语种时可提供语言提示；混合语言可留空让模型判断。
- 说话人标签是本段音频中的匿名编号。开启颜色后会写入一次性颜色快照，之后仍可编辑。
- 快速测试时长支持 `20s`、`2m` 等值；完整转写前需取消限制。
- 字幕断句使用字符型或单词型规则；CLI 对应参数见 [CLI](../cli/)。

云端 Key、地域、模型和地址可以保存到本机 `.env`；识别预设不保存密钥。界面语言首次跟随系统，之后可在通用设置中切换。

「⚙️ 设置 → 断句与标点」统一控制转写与文稿匹配。默认断句符号为 `，。？！；,.`，末尾保留 `？！`，其余断句符号从句尾剥除；删除某个符号即取消它的断句作用，文稿换行始终生效。旧设置首次加载时迁移，已有显式选择继续保留。

## 选择声音轨道

含多条音轨的视频会在媒体路径下方显示「声音轨道」。默认选择 FFprobe 标记的默认轨，没有默认标记时选第一条；转写、波形和频谱使用同一条轨道，选择会保存到工程。

*示意图，非界面截图：音轨名称仅作示例，程序不会按「人声」名称自动选轨。请根据录制方式确认所需轨道。*

默认轨缓存没有后缀，其他轨使用 `.track-N`。所选轨缓存缺失时优先重建，重建失败才临时回退到默认轨缓存。纯音频和单音轨视频不显示此控件；探测失败时沿用第一条轨道。批量任务对每个文件独立探测默认轨，不复用单文件页面的选择。

## ASR 识别预设

高级选项旁的「预设管理」可以搜索、查看和加载预设。单击列表项只看资料，点击「加载预设」才应用；加载不会切换供应商、模型或开始识别。

| 操作 | 结果 |
| --- | --- |
| 另存为新预设 | 保存当前识别表单。 |
| 仅保存名称/描述 | 只改选中预设的资料。 |
| 更新预设 | 经确认，用当前表单覆盖选中预设。 |
| 复制预设 | 生成副本，可继续改名。 |
| 删除预设 | 经确认移入系统回收站。 |

当前表单偏离已载入预设时，会出现「更新预设」入口。预设包含高级识别参数、快速测试与断句设置，不包含密钥、媒体、输出位置或后处理链。Qwen 上下文、OpenAI Prompt 和 Soniox 背景文本共用同一份提示词。热词文件仅保存路径，文件缺失会提示。

每个预设是一个 `.json` 文件，名称取自文件名，描述可为空。默认目录为 MAW 用户数据目录下的 `asr-presets/`；可在通用设置选择已有可写目录，并选择是否迁移旧文件。损坏或不支持的预设会标记不可用。

## 批量转写

切换到「批量」，添加或拖入多个媒体，再点击「开始全部」。重复路径会忽略，任务按顺序执行，同一时间只转写一个文件。

- 整批共用当前模型、语言、热词和自动处理设置，不支持逐文件覆盖。
- 单个文件预检、转写或后处理失败后，其余文件继续。
- 「停止全部」取消当前及未开始任务；已完成结果保留。
- 每个文件生成自己的 SRT / MOSP；命名冲突自动加后缀。完成条目可以打开工程或文件夹。
- 每批在首个有效媒体的输出子目录记录 `maw-batch-manifest.json`。它是结果清单，不是断点续跑入口。
- 当前批量模式跳过文稿匹配及其 AI 整理模式，避免把同一份文稿用于多个录音；不修改已保存的单文件设置。

其他自动处理步骤按 [自动处理指南](../postprocess-pipeline/) 执行。

## 输出目录与命名

通用设置中的「文件输出」控制 Launcher 产物：

| 设置 | 默认 | 行为 |
| --- | --- | --- |
| 将所有输出文件放入子文件夹 | 开启 | SRT / MOSP 写入媒体旁 `_maw`；关闭后在媒体旁。 |
| 每个视频单独创建子文件夹 | 关闭 | 开启后使用 `<媒体名>_maw`。 |
| 在输出文件名中附加模型名称 | 关闭 | 开启后附加供应商或模型段。 |

波形 `.mopeaks` / `.quapeaks` 跟随输出子文件夹设置；读取时也查找媒体旁和旧输出位置。REAPER 原生 `.ReaPeaks` 始终在媒体旁。旧 `*.waveform.json` 不再读取，其他已支持的缓存位置不会因切换设置自动迁移。

自动处理中间产物、调试文件、浏览器转换缓存和批量清单使用辅助目录。常见布局为：

```text
媒体目录/
├── clip.mp4
└── _maw/                  # 或 clip_maw/
    ├── clip.srt
    ├── clip.mosp
    ├── clip.mp4.mopeaks   # 按需生成
    ├── 后处理/            # 英文界面：postprocess/
    └── 调试/              # 英文界面：debug/
```

图形设置不等同于公开 CLI 的默认命名；脚本要稳定定位文件时，显式指定输出路径，见 [CLI](../cli/)。

## 波形、日志与通知

波形由编辑器按需读取或生成；提前生成波形会额外扫描媒体，频谱是可选的耗时步骤。缓存失败不会让已经生成的字幕失效。

日志显示起止时间、耗时和实时率（RTF = 转写耗时 ÷ 媒体时长，越小越快）。阿里云费用估算使用程序内参考值，不能代替账单；服务商现价见 [PROVIDERS](../providers/)。

完成通知默认关闭。开启后，单文件完成/失败和整批结束会触发系统通知；手动停止批量任务不算完成。

处理已有字幕或媒体请打开 [工具箱](../toolbox/)；希望转写后自动串接处理，请配置 [自动处理链](../postprocess-pipeline/)。
