# MAWE 字幕按键调整

本文专门说明 MAWE 中用于微调字幕时间的键盘操作。它们适合在波形区快速修正字幕的整体位置、起点和终点，不需要拖动边界手柄。

## 开始使用

1. 点击波形区 header 右侧的 ⚙️，打开「音频波形区」设置。
2. 调整「按键调整字幕 → 字幕按键微调幅度」。默认值为 `50 ms`。
3. 按需调整「操作 → 自动吸附调整相邻字幕」。该开关默认开启。
4. 选中字幕后，按方向键进行微调；或者在波形区按住字幕块，再按 `A` / `D`。

在 macOS 上，下面写作 `Ctrl` 的组合键使用 `Cmd`。本文中的“按住字幕”是指在波形区按住字幕块的鼠标左键，同时保持按键操作；仅把鼠标悬停在字幕块上不算按住。

## 快速创建字幕

把鼠标移到波形空白处后：

| 操作 | 作用 |
| --- | --- |
| `N` | 以鼠标所在音频位置为起点创建一条字幕。只在波形行上生效。 |
| `Ctrl+左键拖动` | 在波形空白处拖出范围，创建对应时长的字幕；拖动方向不限。 |

创建成功后，新字幕会被单选、滚动到列表可视区域，`current-cue-panel` 也会切换到它并聚焦文本框；波形操作不会进入字幕列表的内联编辑。拖动经过已有字幕时，预览会停在已有字幕的边界，不能跨过；可用范围不足 `100 ms` 时不会创建。

## 选中字幕时

先单击字幕块或字幕列表中的字幕，使其处于选中状态。

| 按键 | 作用 |
| --- | --- |
| `←` / `→` | 按设置的微调幅度向前 / 向后移动选中字幕。 |
| `Ctrl+←` / `Ctrl+→` | 按微调幅度调整选中字幕的左边界，也就是起点。 |
| `Ctrl+Shift+←` / `Ctrl+Shift+→` | 按微调幅度调整选中字幕的右边界，也就是终点。 |
| `Shift+←` | 将选中字幕的起点直接贴到前一条字幕的结尾。 |
| `Shift+→` | 将选中字幕的终点直接贴到后一条字幕的开头。 |

「自动吸附调整相邻字幕」只控制普通移动、边界微调和共享边界拖动的默认模式。关闭时，当前字幕默认独立调整，不会连带改变相邻字幕；按住 `Alt` 临时反转为联动。开启时，默认保持相邻字幕联动；按住 `Alt` 临时解除联动。`Alt` 始终是临时修饰键，不是需要单独开启的功能。

`Shift+←` / `Shift+→` 是显式的直接贴合操作，不按微调幅度逐步移动，不受上述自动吸附开关影响，也不会把邻居一起改动。多选时，普通方向键移动全部选中字幕；涉及单个边界的操作使用选区最外侧的字幕：左侧操作取第一条，右侧操作取最后一条。

## 按住字幕块时

在波形区按住一个字幕块的鼠标左键，再按下列按键：

| 按键 | 作用 |
| --- | --- |
| `A` | 按微调幅度向前移动当前按住的字幕块。 |
| `D` | 按微调幅度向后移动当前按住的字幕块。 |
| `Alt+A` / `Alt+D` | 临时反转「自动吸附调整相邻字幕」的默认模式：默认关闭时改为联动，默认开启时改为独立调整。 |
| `Shift+A` | 将当前字幕的起点贴到前一条字幕的结尾。 |
| `Shift+D` | 将当前字幕的终点贴到后一条字幕的开头。 |

`Shift+A` / `Shift+D` 与选中字幕时的 `Shift+←` / `Shift+→` 使用相同的显式贴合逻辑，不受自动吸附开关影响：只改变当前字幕对应的边界，不移动相邻字幕。没有前一条或后一条字幕时，不会进行贴合。

## 使用时的边界规则

- 微调和贴合都会遵守字幕的有效时间范围与最小时长限制；可能造成负时长或过短字幕的操作会被拒绝。
- 每次成功的时间调整都会生成一条编辑历史，可以用撤销操作回退。
- `Shift` 贴合是一次性定位到相邻字幕边界；如果两条字幕本来已经贴合，再按一次不会产生重复修改。
- 「字幕按键微调幅度」只影响带有“微调”含义的移动和边界调整，不影响 `Shift` 的直接贴合。
