用法：逐行确认。点 ✓ 采纳 接受新文案；点 保留原文 维持现状；直接在「新文案」输入框里改写则标记为「已修改」。进度自动保存在本浏览器（localStorage），换电脑可用「导出结果 JSON / 导入上次进度」接力。全部确认后点「导出结果 JSON」，把文件交给开发侧落地。

复用这套管线：复制一份 maw-copy-review-data.js 改名（例如 foo-data.js），按同一结构填写 meta / decisions / sections，然后用 copy-review.html?data=foo-data.js 打开即可。数据是唯一事实源；本页面不修改源数据文件。
