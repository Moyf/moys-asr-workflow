# 文案评审工具

**状态：已过期，不再维护。** 维护者已退役本次文案重写工具；保留现有页面、数据和下列操作说明用于历史追溯，不再用于新的文案工作或继续开发。状态以 [工具功能介绍页](../index.html) 为准。

打开 `copy-review.html`，默认读取同目录的 `maw-copy-review-data.js`。可通过 `?data=<文件名>.js` 指定同目录的另一份数据；数据格式与现有文件保持一致，页面不修改源文件。

## 操作

- 按状态或关键词筛选；「重置筛选」清除过滤，不清空编辑和决策。
- 每行分别选择「采纳」或「保留原文」，也可编辑新文案。整行不绑定默认决策，避免误采纳。
- 分区标题整条可折叠，批量按钮明确作用于本节全部改动，不只当前筛出的行。
- 顶栏切换深浅主题与精简显示；精简降低密度，不隐藏新文案或备注。窄屏将每行改成带字段标签的纵向内容，备注不再隐藏。
- 展开「导出结果预览」查看全部 JSON；预览与导出使用同一结果模型。进度按数据文件名沿用原存储键，主题偏好单独保存。
- 「导入上次进度」读取结果 JSON；失败提示不清空现有进度。工作状态保存失败会持续警告，仍可导出结果留存。
