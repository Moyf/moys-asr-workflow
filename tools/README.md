# 本地浏览器工具

维护者入口：[工具功能介绍与状态](index.html)。新增工具或调整维护状态时，必须同步 `catalog.js` 与对应 README；介绍页从清单自动渲染，不能只在聊天里记录。

「使用说明」以页内阅读弹窗显示，弹窗保留「打开源文件」入口。说明正文只在各工具 README 维护，离线副本由生成脚本同步，不能手改。Markdown 解析与 HTML 安全清理复用本地固定版本成熟库，不加载 CDN；已过期工具的说明仅保留历史使用边界。

==阅读说明不会修改工具的工作状态==。高亮中可以包含 **强调文字**，代码示例中的 `==这段保留原样==` 不转换；共享渲染接口和安全边界见 [共享模块说明](shared/README.md)。

工具按用途保留各自结构，共享 Launcher 的主题与基础交互。开发前阅读 [工具页规范](TOOL_PAGE_GUIDE.md) 和 [性能约定](AGENTS.md)；共用样式/主题启动在 `shared/tool-page.css`、`shared/tool-page.js`。

| 工具 | 用途 / 入口 | 结构与边界 |
| --- | --- | --- |
| [转写对比](compare.html) | 本地打开，载入 SRT / MOSP | 多列按时间对齐、字符差异、时间分布；有主题和筛选重置，不添加无用选择/导出 |
| [时间码对比](timestamp-compare.html) | 本地打开，最多载入两个文件 | 按段序号与字词比较、展开明细；精简仅隐藏辅助时间条，明细仍可展开 |
| [人工核对清单](verification-checklist/README.md) | Markdown / JSON 生成 | 分区进度、整行打勾、备注、结果导出；保留稳定 ID 与原存储键 |
| [文案重写／文案评审](copy-review/README.md) | 已过期，不再维护 | 保留历史页面与数据用于追溯，不再作为当前文案工作入口 |
| [开发看板](dev-dashboard/README.md) | 受限 localhost 服务 | 保留任务列、拖拽与状态选择；共用资源走精确路由，CSP 不放宽 |
| [CHANGELOG 编辑器](changelog-editor/README.md) | 本地 / 看板入口 | 保留编辑预览与文件授权；窄屏上下分屏，不改变写盘与冲突流程 |
| [波形实验台](waveform-compare/README.md) | 暂停维护 | 保留现有实验实现，不继续更新或列为本轮人工验收目标 |
| [OCR 确认页](term-extract/README.md) | 视频术语候选审阅 | 本次视觉/交互参考；尚未接入 Launcher 工具箱 |

[Filmstrip Lab](filmstrip-lab/README.md) 是阶段 0 历史原型，维护者本轮暂不处理；`merge-flow.mjs` 为 CLI，无浏览器界面。

静态页依赖仓库内相对资源，保留目录一起使用；独立生成页内联共用资源，无需外部网络。模板更新不自动改写既有报告，按工具说明重新生成或明确指定刷新。

精简开关的样式直接复用 OCR 确认页。核对清单精简只显示每项标题与勾选，看板精简只显示标题、忽略按钮和状态选择；工作数据与结果导出不因精简改变。
