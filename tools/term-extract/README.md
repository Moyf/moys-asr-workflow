# term-extract：视频术语提取（M1 独立工具）

游戏录像 → PP-OCRv6 画面扫描 → 聚合与规则评分 → **AI 语义筛选** → HTML 确认页 → 热词表。

目的是减少「真希 → 珍惜」这类同音错字：**画面提供写法，声音提供读音**。产出的热词表
可填回 Launcher 热词输入、批量 CLI 或豆包 `--hotword`，供 ASR 转写与后续 AI 处理使用。

完整链路的扫描/缓存/AI 推荐/导出回归与证据见 [独立复核](../../docs/logs/release1.11.0/261110_工具页规范同步/REVIEW_FINDINGS.md)；旧局部通过不代表组合边界已经验证，真实 OCR/AI 与长视频磁盘/耗时仍须按该记录的未测范围确认。

完整规格与合并进 MAW 的预留点见 [SPEC.md](SPEC.md)。本工具是独立测试形态：不接
Launcher、不进打包；验证通过后按 SPEC §5 合并进工具箱「媒体工具」。

## 1. 环境准备（一次性）

```powershell
uv sync --group ocr --group test
```

之后统一用 `uv run --no-sync python …` 执行（也可先 `.venv\Scripts\Activate.ps1` 激活
venv 再用裸 `python`；**不要用系统 Python**，它没有仓库依赖）。

## 2. 三步用法

### 第一步：只做提取（测效果，无需任何 Key）

```powershell
uv run --no-sync python tools\term-extract\run.py "你的录像.mp4" --ocr local --no-ai
```

跑 提取 → 聚合 → 规则评分，直接产出确认页。打开产物目录里的 `report.html`：

- 按分数 / AI 判定 / 搜索过滤候选，「重置筛选」一键恢复默认；展开「证据与理由」看评分明细、变体、出现时间；
- 右侧导出栏（窄屏为底部单行栏：已选数 + 复制 + 导出，点「已选」展开预览与更多操作）：「导出预览」以词条显示当前勾选，点 × 单独移除，内容与「导出热词 txt」一致；勾选状态在搜索/筛选后保留；
- 右上角 ◐ 切换深色 / 浅色（默认跟随系统，记住上次选择；配色与 MAW Launcher 一致：深色橙、浅色红）；
- 筛选栏右侧「精简显示」开关（或按 `V`）：每个候选压成一行（勾选 / 分数 / 词 / 指标），隐藏缩略图、上下文与明细，适合快速扫读勾选；状态会记住；
- 顶部数字输入支持悬停滚轮步进（分数 ±5，其余 ±1；光标为 ⇅ 样式）；
- 每张卡片右侧显示首个证据帧，点击放大：‹ › 按钮或左右方向键在该候选的证据帧间循环切换，底部显示词、n / 总数与帧时间，可在大图里直接勾选（X），Esc 关闭；
- 候选按评分分四组显示（推荐 / 待定 / 观察 / 排除），各组带代表色（青 / 琥珀 / 灰蓝 / 灰）与左色条，整条组头都可点击折叠，「全选本组」一键勾选——「观察」「排除」默认折叠，整句噪声不刷屏；分档线跟随生成时的 `--min-score`；
- 证据缩略图与放大图上，OCR 识别到的文字位置画红框标注，快速定位画面文本；
- 「字数 ≤」默认 12——超过该长度的整句字幕/UI 文案默认隐藏，清空输入框可显示全部；「出现 ≥」按独立显示事件数过滤；
- 键盘审阅：`J` / `K` 上下切换卡片、`X` 或空格勾选、`O` 或 Enter 看证据帧、`/` 聚焦搜索；鼠标直接点卡片整行即可勾选（缩略图、展开明细与按钮除外，拖选文字不会误触）；
- 勾选后在导出栏「导出热词 txt」/「复制清单」（结果以页面底部提示反馈）；超热词硬限制（如非 ASCII > 15 字符）的项会标灰说明原因，不能勾选。

长视频建议先 `--fps 0.5`（每 2 秒一帧）全片粗看，再对重点段落 `--fps 1` 重跑。
历史速度量级：tiny 模型 CPU 约 2–4 帧/秒；当前完全一致的 OCR 输入复用上一成功识别结果，但仍保留采样时间点以避免把持续显示误算为多次出现。新的精确像素策略尚未重测真实长视频耗时，不外推旧速度基准。

### 第二步（可选）：补 AI 语义筛选

`--no-ai` 的推荐项只来自规则评分（只有召回、没有语义判断），正式使用前应过一遍 AI：
规则评分管「找全」，AI 管「挑对」，HTML 人工勾选是最后一道关。

```powershell
$env:MAW_POSTPROCESS_ZHIPU_API_KEY="你的Key"
uv run --no-sync python tools\term-extract\run.py "你的录像.mp4" --resume --llm-preset zhipu
```

`--resume` 复用第一步的已验证 `ocr.json`，**不重扫画面**，只跑聚合 + AI + 报告；fps、模型、区域和上限沿用缓存，显式传入不同扫描参数会拒绝并提示去掉 resume 重扫。
LLM 连接三选一：预设 `--llm-preset deepseek|zhipu|qwen`（Key 走对应
`MAW_POSTPROCESS_<预设>_API_KEY` 环境变量，与工具箱 AI 处理共用约定）；
或 `MAW_TERMS_LLM_API_KEY` + `--llm-base-url/--llm-model`；或显式 `--llm-api-key`。

AI 筛选失败会写 `ai-failure-record.md` 并以非零码退出，**不会静默降级**——
未经语义筛选的输出不该被当成最终热词表。

默认推荐为「规则达到推荐线且 AI 判 keep」，AI reject 不自动勾选或进入初始热词文件；候选仍保留，人工勾选时明确警告。AI 请求前保存本轮规则候选并清空旧热词，失败/取消状态写入报告，不沿用上一轮成功结果。

扫描缓存 **v3** 保存文件名、大小、纳秒修改时间、完整扫描参数和独立证据目录。源变化、v2/更旧缓存、坏 JSON（含非有限数值）、无效时间码/汇总关系或参数冲突均拒绝；旧版缓存须去掉 `--resume` 重扫。轻量身份不检测保持全部这些字段不变的内容替换。

新扫描先写暂存目录，不覆盖旧报告引用的帧；成功后发布独立 `frames/run-<id>`。取消或失败保留完整旧缓存/报告/证据，热词仍保守清空，不称为新扫描成功。文件逐个原子替换并带恢复记录，写入中断可回滚/下次读取前恢复，但不宣称多文件瞬时原子。旧帧代际与恢复备份留存、不自动清理：单轮受帧数上限约束，历史累计磁盘不设全局预算，长期使用须由用户留意并清理不再需要的产物。

### 第三步：热词表进 ASR

确认页导出的 `hotwords.txt`（每行一词，或 `--weight-by-score` 时带 `词: 权重`）：

- Launcher「即时热词」直接输入或拖入该 txt；
- 批量流水线 / CLI 用热词文件参数传入。

## 3. 常用参数

| 参数 | 说明 |
| --- | --- |
| `--fps 1.0` | 采样密度 0.2–2.0；长视频建议 0.5 |
| `--model tiny\|small` | PP-OCRv6 档位；small 更准更慢 |
| `--region full\|bottom30\|custom x1 y1 x2 y2` | 只扫部分画面（如下方字幕区） |
| `--ocr runtime\|local` | 默认 `runtime`（托管环境，需在设置安装）；`local` 直连开发 venv |
| `--min-score 60` | 推荐分数线，低于此不预勾选 |
| `--resume` | 复用产物目录里的 `ocr.json`，跳过扫描 |
| `--weight-by-score` | 导出带权重：≥80→5、70–79→4、60–69→3 |
| `--max-frames 20000` | 采样帧数安全上限 |

## 4. 产物（默认视频旁 `<视频名>.termextract/`）

| 文件 | 内容 |
| --- | --- |
| `report.html` | **确认页**：过滤 / 勾选 / 证据 / 导出，`file://` 直接打开 |
| `candidates.json` | 完整候选与证据（时间点、事件、变体、评分理由、AI 判定），编辑器联动的数据源 |
| `report.csv` | 全量候选（带 BOM，Excel 直开） |
| `frames/run-<id>/` | 当前和历史扫描的独立证据帧，报告/缓存指向同一代际；不自动清理旧代际 |
| `hotwords.txt` | 推荐项初始导出；以确认页导出为准 |
| `ocr.json` | 扫描原始块，`--resume` 复用 |

在产物目录新建 `ignore-extra.txt`（每行一个词，`#` 注释）可追加 UI 忽略词。

热词总量最多 2000 个去重有效词，超出部分明确提示不进入导出；页面预览、复制和下载使用同一结果与权重规则。无推荐时 `hotwords.txt` 写为空文件，不保留上轮词表。扫描到上限只覆盖前缀，CLI 和报告明确截断、失败帧与最后采样位置，不能当作全片无遗漏。

## 6. 边界（如实）

- 规则评分只管召回；语义判断 = AI 筛选 + HTML 人工确认两道关，OCR 结果不可全量收入。整句字幕/UI 文案（>12 字符）评分 −20 沉底，且超热词硬限制的词不进入推荐；确认页可用「最多字数」隐藏它们。
- 采样是成本与召回的平衡：闪现 <0.5s 且无场景切换的文字可能漏。
- 「命中次数」按唯一采样时间点计帧，原始框命中单列 `rawBlockHits`；评分用「有效命中」（每事件最多计 4 帧）。同组近似写法的重叠/连续出现合并为显示事件；相隔超过采样间隔约 2.5s（fps=1 时）才另计，原相似度分组边界不变。
