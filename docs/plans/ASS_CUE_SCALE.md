## 用户明确要求

1. 选中一条主字幕时，可调整这条字幕的**整体缩放比例**，不是修改全局字号。
2. 选中边框周围提供 handle，拖动时保持宽高比。
3. 单句选中且鼠标位于视频画面区域时，滚轮调整该句缩放。
4. 比例发生变化后才显示控件，位于现有 X/Y 左侧，提供「重置大小」。
5. X/Y 显示与新写入位置四舍五入到整数，例如 `331`、`161`。
6. 缩放使用倍率、保留两位小数，例如 **`1.22`**；不要使用百分比界面。
7. 实现完成后提交独立 PR，等一轮 CI / PR 反馈，有确认的问题再修复；不自动合并或发布。

附件只作为现有 X/Y 区域的视觉参考，不引入其它操作要求。

## 可行性与边界

可在现有逐句定位链路中扩展。`assOverride` 已参与保存、拆分/合并、历史恢复和 ASS 计划缓存；单句缩放应复用这条链路，不另建 CSS 专用变换或覆盖全局样式。

首期只处理 ASS 模式的主字幕，普通 CSS 预览、副字幕与叠加轨不增加缩放操作。主副换轨仍保留元数据，换回主轨后恢复。SRT 不表达位置或大小。工程 segment 不因缩放或震动被拆成多条。

缩放与位置相互独立：只调大小不创建 `pos`；只调大小的句子继续参与全局排布、避碰和空间不足时的自动适配。已有 `pos` 的句子仍遵循手动定位规则。不要为方便缩放而把所有句子转换成手动定位。

## 数据与数值规则

建议扩展为：

```json
{"assOverride": {"scale": 1.22, "pos": {"x": 331, "y": 161}}}
```

字段均可单独省略，示例不表示缩放必须伴随位置。

| 项目 | 规则 |
| --- | --- |
| `scale` | 数值倍率；实现范围为 0.10–5.00，输入 step 0.01；这是实现默认值，不是维护者额外提出的限制 |
| 默认倍率 | 1.00；归一化为不保存 `scale`，无其它覆盖时删除空 `assOverride` |
| 精度 | 倍率显示两位小数，新值按两位小数写入，数值 1.2 显示 `1.20`；JSON 不要求尾随零 |
| 非法值 | JS/Python 拒绝字符串、bool、null、NaN/Infinity、越界倍率；保持错误路径一致 |
| X/Y | 输入 step 1，显示整数；拖动、数值编辑、方向键的新位置统一在写入入口取整 |
| 已保存的小数位置 | 不在读取工程或仅修改大小时悄悄改写；显示取整，明确编辑位置后才保存整数 |
| 重置大小 | 只清除 `scale`，保留 `pos` |
| 重置定位 | 只清除 `pos`，保留 `scale`；实现与测试已确认两个字段互不影响 |

倍率归一化在 JS 与 Python 中均固定两位小数，测试覆盖 `1.005`、`1.225` 等舍入边界；默认倍率仍省略。X/Y 仅在用户明确编辑位置时按 `floor(value + 0.5)` 写为整数，导入的历史坐标不因读取或缩放被改写。旧有默认输出及未修改工程不因增加新字段而改变。

逐句 `an` 没有发布，不存在需迁移的旧工程；继续按现有契约拒绝 `assOverride.an`，不新增兼容逻辑或迁移测试。

## 交互设计

### 四角 handle

- 只有唯一主字幕选中、该句当前可见、ASS 模式与字幕预览开启时显示。
- 沿用现有定位边框，四角提供独立命中区；不要在现有 button 内嵌套另一个 button。可以把 handle 作为 overlay 的同级按钮，或合理重构命中容器。
- 围绕全局样式的文字块锚点等比缩放，已有 `pos` 不变；震动使用基准几何，不把瞬时偏移写成位置。
- pointerdown 只记录初态；数值实际变化时才建立命令。一轮拖动一条撤销；点击、舍入后未变、拖回原倍率均不新增历史。
- 捕获 pointer，支持 Esc、pointercancel、lostpointercapture、窗口失焦取消；复用已有拖动中的保存、撤销和键盘隔离保护。
- 初始尺寸、全局锚点、投影方向和坐标映射在手势开始冻结，避免每帧重算分母造成漂移。测试九种锚点、横竖屏、黑边、旋转、过小命中区与锚点附近的 handle；不能只验证下中锚点。
- 实现以冻结的初始边框、锚点和对角方向计算相对倍率，限制到范围后按 0.01 量化；即使手柄靠近锚点也有最小灵敏度，缩放不创建 `pos`。

### 视频区滚轮

- 事件接在视频 stage，但必须检查鼠标落在实际视频画面矩形内；控制条、黑边、页面其它区域不触发。
- 仅唯一且当前可见的主字幕选中时触发；未选中、多选、离屏、副字幕、ASS 关闭、预览隐藏时保持原滚轮行为。
- 向上放大、向下缩小，按 `deltaMode` 归一化滚动量后连续计算倍率；不把触控板的小滚动固定量化成大档。
- 不拦截 Ctrl/Meta/Alt 等浏览器快捷操作；只有确实消费字幕缩放时才 preventDefault，监听器需支持 `passive: false`。
- 连续滚动合为一次命令，静止 240ms 后提交；新一轮滚动再记一条撤销。上限/下限处继续滚动不写入无意义历史。
- 手势结束前自动保存等待；显式保存先结束事务；Esc/失焦取消并清理计时器。切换字幕、退出 ASS、开始其它命令前要先结束当前滚轮事务，防止完整工程快照覆盖其它操作。

### 编辑区控件

```text
字幕文本框      倍率 1.22       X 331
                重置大小       Y 161
                               重置定位
```

只是关系示意，最终对齐与留白沿用现有紧凑 UI。倍率列在 X/Y 列左边；两列各自按覆盖字段显隐，未调整倍率时隐藏大小列，未调整位置时隐藏 X/Y 列。

不增加当前字幕编辑区的垂直占位，不因选择/取消选择或两列显隐挤动视频。窄侧栏下检查文本框剩余宽度，避免简单增加固定宽度后变成不可编辑。各相邻操作行间距至少 8px，用计算样式和实际矩形测量，收尾截图自查。补齐英文标签、aria-label、输入校验和焦点行为；倍率框的方向键不能误触发 X/Y 微调。

## 预览、排布与 ASS 导出

核心入口：

| 入口 | 责任 |
| --- | --- |
| `web/shared/utils/ass-canvas-layout.js` | 在计划条目携带独立的 `cueScale`；测量、预折行、自动适配和动态 bounds 都感知倍率 |
| `web/editor/styles/editor-wiring-ass-preview.js` | Canvas 使用用户倍率 × 原有组适配倍率；动画先按原有时钟求值，再乘整体倍率 |
| `web/shared/utils/ass-export.js` | 生成同样尺寸、描边/阴影/字距和字体动画目标，覆盖普通/手动/震动各事件分支 |

以全局字体和句内 `++`、`--`、强调等相对样式为基础乘倍率，不把工程文本改写成新的字符标记。计划的 `manual` 只能由 `pos` 决定；`scale` 不能当成固定层开关。不要把改变字号产生的布局位移写回工程。

实现通过共享字号、字距、描边、阴影和动画目标缩放管线处理整体倍率，预览与 ASS 导出共享排布结果。倍率不改变 `manual` 语义；只有 `pos` 决定手动定位，只有 `scale` 的句子仍参加全局自动排布。自动排布先按用户倍率测量文字框，再应用组适配倍率；ASS 导出的位置偏移只乘组适配倍率一次，字体、效果、动画和震动幅度使用组适配倍率与单句倍率的乘积。

震动保持原句时间相位，导出分片不会重启相位；定位和震动始终使用基准锚点。首版的 Canvas、Server/libass 与导出帧对照已覆盖九锚点、横竖屏、震动及单句缩放。首轮 review 新增的隐藏预览、命令隔离和缩放自动堆叠帧对照 e2e 已写入测试，最终 CI run `38875181279` 的 29 项全部通过。
