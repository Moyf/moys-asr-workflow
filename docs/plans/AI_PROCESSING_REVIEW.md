# AI 处理核对与工程备注方案

范围：2026-10-12 的产品讨论。当前口播整理、校对、翻译、断句、自定义任务已能生成只读 HTML 对比；交互式译文编辑和通用备注适配尚未实施。本方案不改变本次功能默认值，也不将模型自评当作可靠性保证。

## 职责与建议

MAW 的 AI 处理负责输入工程、任务执行、结果校验、MOSP/SRT 和核对页输出。`tools/` 提供模板生成、独立检查等维护能力，不应成为用户完成翻译的另一个必需入口。可共用模板与生成脚本，但产品中的「生成核对结果」应属于 AI 处理。

离线 HTML 适合初期译文核对：方便分享，源文与译文逐条对照，并可下载修改后的 MOSP。若用户逐渐需要播放、Seek、批量替换或同时编辑时间，则直接交给 MAWE，避免在 HTML 内重建编辑器。

## 先做通用备注

建议任务适配器返回经校验的结果与可选 annotations，统一的工程写入器负责将备注转换为现有 `markers`，不让各任务分别拼工程格式。以下是候选内部协议，不是已发布 MOSP 新字段：

```json
{
  "annotations": [
    {
      "source_ids": ["c0001"],
      "kind": "note",
      "message": "API 在这里指开发接口，建议统一术语。"
    },
    {
      "source_ids": ["c0002"],
      "kind": "review",
      "message": "代词指向有两种可能，需要结合画面确认。"
    }
  ]
}
```

- 模型只引用本批原始 cue/atom ID，不生成时间。脚本从源工程解析区段；无可靠范围的全局提醒保留在运行结果。
- `note` 对应 `[AI] 注：…`，普通说明不设待核查；`review` 对应 `[AI] 待核查：…`，使用现有 `review.status=pending`。类型不要仅由备注文案推断。
- 保留已有用户标记和稳定 ID，新增标记记录任务来源及本次运行标识，便于筛选、重跑去重和追溯；沿用已有字段，新增来源字段须更新 schema、正规化和保存重开测试。
- 备注不修改字幕、空隙或删除决定，移除备注也不撤销处理。重跑只替换本任务拥有的备注；用户修改过的备注应保留或明确冲突，不能按 `[AI]` 文本前缀批量清空。
- 范围校验与内容校验分开。拒绝未知 ID、空说明及无效类型，并限制数量、文本长度；HTML 用纯文本渲染。无需额外请求模型逐段解释「保留」，避免噪声和费用。
- 对模型备注采用可选协议和各任务的格式适配。断句可以仍只输出断点；无词级时间、超长不可拆、网络降级等确定性提醒由脚本产生。无法可靠定位的技术错误不要伪装成某个字幕的语义疑点。

首批适配建议：断句的不可拆超限和未处理范围；校对中多种专名/同音字；翻译中术语、代词、文化表达；自定义任务仅接收符合声明协议的备注。口播整理现有待核查先由统一写入器适配，保持行为和恢复方式。

## 翻译核对 HTML 的最小版本

1. 沿用「生成处理前后对比结果」，翻译结果显示原文、译文、任务备注和可编辑译文字段；编辑只允许改译文，不提供拆句、时间和任意工程字段编辑。
2. 内嵌源工程快照、处理结果快照、稳定 ID/双语绑定与版本指纹。保存只生成新下载文件，源快照不可改；不新增任意文件路径读写的服务器接口。
3. 固定脚本将编辑内容应用到原结果中的译文字段，校验 ID 唯一、条数/顺序/时间、绑定完整性及空译文。单语结果沿用当前翻译产物格式，双语结果只改译文轨并保留主轨；不强制另创工程格式。
4. 修改译文后清除该译文段失配的 `items`，不生成虚假译文词级时间；保留原文时间、未改译文的合法数据、标记、用户元数据和隐藏副轨。
5. 导出前显示修改条数及问题列表。HTML 独立导出「核对后 MOSP」，进入 MAWE 后仍能继续编辑；SRT 可随后复用现有导出逻辑。
6. 核对页是快照，不自动回写后来修改过的磁盘工程。未来支持选择另一份工程回填时，须校验指纹/ID/原文，版本不同则停止并说明冲突。

## 其他任务的改进空间

| 任务 | 建议 | 必须守住的约束 |
| --- | --- | --- |
| 校对 | 展示字级增删差异，对歧义专名留备注；可逐条接受或恢复 | 不扩写事实，变化后只清理失配词项，时间保持来源 |
| 翻译 | 术语表、只读上下文和可编辑译文核对 | 不漏段、合并或改变输入映射；不把流畅度当准确度 |
| 断句 | 标记不可拆超限、局部补拆和未处理区段；必要时评估不可拆语义短语 | 全文与源词项不改，备注与断点选择分开；严格上限取舍需用户理解 |
| 自定义 | 预先声明校对/翻译/编辑稿等可验证协议及输出能力 | 自由文本提示不获得任意工程结构或时间修改权 |
| 口播整理 | 统一待核查写入与核对入口，保留覆盖复查 | 原文与删除可恢复，疑点不转成隐式删减 |

## 建议顺序与待决策

先统一备注的内部协议与写入器，再做只编辑译文、下载 MOSP 的核对页。对有播放需求的用户提供进入 MAWE 的入口。

实现前需要明确：离线 HTML 是否为正式编辑入口；是否首先仅支持单语或双语回填；空译文允许清空还是阻止导出；用户修改后的 AI 备注在重跑时如何保留。本次只形成设计建议，待维护者确认后实施。
