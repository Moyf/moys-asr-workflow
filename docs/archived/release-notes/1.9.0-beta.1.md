## [1.9.0-beta.1] - 2026-10-15

### ✨ 提升

- **视频画面导航** ： 本机编辑器在波形与字幕区域上方显示可隐藏的画面带，缩放时自动调整密度并逐步补齐，点击和拖动沿用原定位与帧吸附。Launcher 从原视频生成独立基础缓存并报告进度，取消后复用已完成结果；编辑器只补可见区域，暂停时优先补齐播放头附近画面；播放时暂停同源画面解码，暂停后恢复，纯音频及未绑定的便携空壳自动隐藏。图片不存进工程，缓存失效或生成失败不影响字幕保存。
- **AI 核对与工程备注** ： 翻译对比 HTML 可手动修改译文并下载核对后 MOSP，支持单语、补译回填与双语合一，保留时间及其他工程数据，空译文或无效映射会阻止下载。校对、翻译和自定义任务的可选说明写为普通注释或待核查区段，断句异常也留下定位提醒；重跑更新未修改的同任务备注，并保留用户修改或已确认的内容。

- **纯文本编辑与批量文本工具** ： 纯文本编辑入口移出「批量操作」并增加 📝 图标；顶部查找支持循环定位、大小写与正则切换，展开后可单项或全量替换，结果先保留在草稿中供应用或取消。英文界面保持字幕原文与查找高亮不变，批量替换与纯文本编辑共用查找、正则和标准捕获组替换规则，并显示当前范围；文本处理重排 ASS / 普通字符预设，加入自定义左右字符、保守中文数字转换和前后文本全部展开 / 收缩。
- **字幕列表工具栏** ： 跟随播放按钮显示「跟随中 / 恢复跟随」状态，超长字幕筛选改用 🧐 图标，独立文本编辑入口与批量操作之间移除分隔符。
- **复核与转换反馈** ： 波形标记弹窗可设置或取消 AI 复核静音，并与管理面板同步状态；字词拆分明确保留撤销并改用简洁警告、转换统计提示和红色确认按钮。新出现的 Launcher / 编辑器行内警告会滚动到可见位置，运行中的「打开编辑器」保持 🎬 图标；无主题偏好时继续默认深色。
- **AI 重新断句** ： 按完整意群与阅读节奏选择断点，原文、标点与词级时间由本地重建；支持可选每条字幕最大字数，超长结果自动沿合法边界补拆，保护数字与帧、像素等单位，并减少连接词悬尾和孤立引导语。无法安全细分的词项或缺时间码段保留并提示；部分段缺时间码不再导致整体降级，保留已有局部删减的恢复能力；一对一副字幕绑定段原样保留并提示。自动处理计划保存字数限制，可使用处理前后 HTML 对比。
- **字词时间码编辑** ： 可在波形中查看、试听、移动、调整和合并字词时间码，或将完整字词码转换为独立字幕并撤销。编辑文字时，完整落在单个字词块内的替换和增删可同步字词文字，不再要求字数相等，原时间保持不变；跨块修改或清空整块时明确提示未同步。试听临时忽略静音空隙，播放完选定区域后停止。
- **波形布局与快捷操作** ： 工具栏集中提供双语、重叠、ASS、字词与标记开关，以及 ASS 样式库和 localhost 实际画面预览入口。字词支持独立行高和默认 5 秒的单行长度，切换双语与字词模式时恢复各自设置；句块、字词和叠加字幕按行高分层显示，保留可操作区域。普通拖动同步移动各轨所有选中字幕并保持相对时间，标记与区段支持跨行拖动。
- **工程与全局设置** ： 随工程保存的时间、语言、字幕轨道、ASS 样式、颜色与说话人、表情包目录覆盖集中到工程设置，双语拥有独立标签页；全局设置按用途分组，可关闭表情包功能、配置默认目录和切换消息提示位置（上方、右上方、右下方）。功能区支持打开局部面板，相关设置间提供直接跳转，工程导入改为独立菜单。
- **设置搜索与帮助** ： 全局与工程设置均可搜索，左侧显示标签页和设置项结果，点击后定位到目标并闪烁提示；跨窗口搜索保留归属信息，同页重复结果合并，清空后恢复导航。设置中的工程设置引用可直接跳转，从设置打开帮助时保留原窗口；中英文名称、说明和导出菜单统一。
- **标记管理与复核** ： 标记列表支持名称、备注搜索高亮、按筛选结果全选与批量删除，批量操作可一次撤销；空轨道可点击创建，名称与备注编辑后一次点击完成即可收起。备注显示可切换，空备注不占位；预设收敛为八色并保留已有自定义色值，确认后的标记以半透明显示。标记编辑默认关闭，可用 M 切换；关闭后恢复字幕点击和拖动操作，并取消未完成的标记修改。
- **AI 口播整理** ： 可独立选择并记忆供应商、填写补充要求，手动执行和自动后处理共用配置；参考文稿可选，模型按原文划删与待确认标记生成可恢复空隙和复核区段，保留原文特殊格式、数字与否定条件；支持离线 HTML 对比及旧计划设置恢复；支持查看模型实时输出、停止操作和直接跳转服务设置。重录选优保护信息覆盖，分批判断参考相邻录音，候选删除后复查剩余内容，恢复不安全删除并标记疑点；可靠字词码下可移除句内一个或多个废词范围，保留正文与绑定副字幕，预览、字幕和时间线导出同步生效。无法可靠核验时转为待复核，取消后不写出整理结果。
- **AI 复核区段静音** ： 可为待复核标记关联的区段启用或取消去空隙静音，作为独立来源随工程保存，不与 AI 整理自动移除混合；AI 注释统一说明操作与原因。
- **去空隙媒体导出** ： Server Editor 可按当前保留区间导出重组视频或 WAV 音频，显示处理、下载与保存阶段，并可在最终保存前停止和清理本次输出。视频尽量以流复制保留容器支持的媒体流，切点精度受关键帧和编码包边界限制；音频使用当前音轨，保留源采样率、声道与采样精度，切点按最近音频样本裁切。
- **文稿驱动对齐（实验性）** ： Launcher「生成时间码」和 CLI 可直接从准确文稿与录音生成字词时间码工程及 SRT，跳过 ASR，保留换行、组合字符与标点，保存重开后仍保持原文。短录音整段对齐，长录音使用静音或人工锚点；可先在无需模型的情况下检查输入与分块，再指定音轨和输出目录生成结果，处理后提醒听审。
- **文稿匹配与工具反馈** ： 普通匹配和带字词码的匹配均可停止，取消后保留输入并可重新运行，开始保存时明确提示已进入提交阶段。字幕 AI 处理也支持实时输出与停止；切换工具标签后保留各自结果与输出，切回可继续查看，任务完成或失败时定位到对应信息。
- **ASS 预览与文字格式** ： 即时预览和样式库改用 Canvas 渲染，描边、行内强调和缩放文字更平滑；新增 `//注释//` 语法，可配置颜色、样式与文字比例，支持用 `>>文字<<` 控制单句渐入渐出。样式预览超宽时按实际尺寸裁切，特殊格式仅在 ASS 模式下提供；SRT 预览不受影响。
- **字幕文字与拆分** ： 可为单条或多条主字幕左右添加预设或自定义字符，支持双列输入和 Enter 插入；新增渐进拆分（Shift+B）和复制拆分（Ctrl/Cmd+Shift+B），分别让后半句或两侧保留完整原文。「字词拆成字幕」仅在字词码模式显示，缺少时间码时明确提示；右键高级操作以侧向菜单展开。
- **说话人与双语显示** ： 双语副字幕跟随其样式预设的位置，叠加字幕固定锚定在主字幕上方，副字幕与叠加字幕也支持说话人前缀。导出时附加说话人名称可应用于 TXT、FCP 7 XML、OTIO 字幕标记和动态字幕，保持工程原文不变；颜色设置提供导出配置入口，双语列表标签与高亮更清晰。
- **字幕整体平移与关于页** ： 可调整选中字幕的整体时间，并检查媒体边界、字幕重叠和绑定副字幕空间；编辑器关于页集中展示版本、文档、教程和社区入口，便携页也可离线显示内置动画。
- **自定义接口与本地模型** ： 后处理提供三个可独立命名的自定义接口槽位，分别保存密钥、地址与模型；设置页始终保留全部槽位，工具箱只显示已填地址的额外槽位。127.0.0.1 / localhost 端点允许空 API Key，可用于连接测试、模型列表、字幕 AI 处理和自动后处理；本地模型示例使用 LM Studio 默认地址。翻译、校对、断句和 AI 整理分别记忆供应商。
- **Launcher 提示与自动烧录** ： 识别供应商说明与实际显示对齐，阿里云百炼标注推荐，DeepSeek 占位项明确提示不提供转写模型、禁用转写并引导使用字幕 AI 处理。自动后处理烧录直接使用转写原媒体，音频素材按绿幕视频生成。
- **界面文案与悬停提示** ： 统一「工程设置」「高级编辑」「调色板」「对齐到帧」等日常用词，精简菜单与装饰图标；编辑器和 Launcher 的气泡说明适配浅色、深色和窗口边缘，避免原生与自定义提示重复出现，补齐英文与控件间距。
- **长工程性能与基础波形** ： 几千条字幕工程中的全选、框选、范围选中、清除与撤销更快，拖动松手后即时反馈；基础波形改善反相和单侧声道素材显示，保持缓存体积。编辑器脚本压缩后较未压缩构建减少约 43%，便携页与本机编辑器继续共用功能，无需额外安装 Node。
- **错误报告与文档** ： 错误卡片和启动失败弹窗显示版本与发生时间，复制时保留完整信息；重整工作流、编辑、自动处理与 CLI 文档，更新 README、官网、下载及计费说明，改善导航、配图和窄屏阅读。
- **人工核对工具** ： 可从 JSON 自动生成统一核对清单，支持说明、命令、列表、表格、逐项备注、隐藏已确认项及导出结果；可忽略整组、完成后自动收起，状态与备注保存在本机。
- **版本更新文档** ： 发布前从 CHANGELOG 生成独立版本正文，发布时校验并读取文档；正式版可完整归纳 beta，小版本可附上同系列正式版的大更新，便于后续展示历史更新内容。

### 🔄 变更

- **esbuild bundle 不再提交进仓库** ： 编辑器与 Launcher 的构建产物（`web/*/boot/*-bundle.js` 及 `.meta.json`）改为本地生成、不入 Git，PR diff 不再被压缩产物噪声淹没，分支合并也不再在这两个文件上冲突。`pnpm install` 通过 postinstall 自动构建；Server 渲染页面前、Launcher 启动前与 `edit.py --blank` 前会校验产物新鲜度并自动重建（需要 Node 与 pnpm）；发布打包脚本与 release CI 在打包前显式构建，MAW.spec 对缺失产物直接报错。从源码运行现在需要一次性安装 Node.js 与 pnpm；发布包不受影响，仍然无需 Node。
- **段落标题序号改为 SVG 徽章** ： Launcher 五个分区标题（选择媒体 / 识别设置 / 转写后自动处理 / 日志 / 编辑器）的序号不再使用彩色 emoji（1️⃣ 等），改为内置 SVG 绘制的 keycap 徽章，全平台外观一致；同时移除 Linux 首次启动时下载 Noto Color Emoji 字体的逻辑，Linux 不再依赖系统 emoji 字体或联网下载，其余平台的序号样式也随之统一。

- **副字幕默认色值** ： 副字幕与拆分预览默认颜色更新为 `#eac953`；已有旧默认样式自动迁移，自定义色值保留。
- **特殊符号规则** ： 选项收敛为「无 / 双个符号 / 单双皆可」，不再单独提供「单个符号」。
- **桌面实验工程** ： 移除不再维护的 Tauri 工程及说明，日常编辑继续使用本机 Server 或便携 HTML；MOSE 方向与 `.mosp` 格式不变。

### 🐛 修复

- **ASS 多轨字幕堆叠** ： 主字幕与叠加字幕按实际文字尺寸排列，多行、特殊比例和同轨重叠参与避碰，空间不足时移入画面或等比缩放；副字幕跟随自身样式预设，同轨重叠依次错开，单独播放和主轨切换时保持位置，字号、强调及动画不受主/叠加组缩放影响。预览与导出保持相同位置和动画进度，无法安全排布时提示调整样式。
- **去空隙视频兼容与工程切换** ： 修复部分 HEVC 视频无法重组导出的问题，保留流复制；选择保存位置期间切换或解除工程绑定会终止旧导出，避免套用错误源媒体。打开新工程时清除旧视频导出能力，失败或取消后不重复报错。
- **多轨编辑与保存** ： AI 整理移除主字幕时同步禁用绑定译文；独立叠加轨的启停不再误改副字幕。拆分、主副轨交换与保存保留说话人及禁用状态，修复副轨独立或联动拆分颜色组后无法保存的问题。
- **文本输入与界面状态** ： 清空字幕后输入首字符不再出现光标错位；设置搜索跳转保留输入焦点，双语切换和 ASS 注释样式即时更新。窄窗口保留设置与 ASS 入口，Esc 关闭实际画面预览时保留字幕选区并恢复焦点，取消拖动不提交修改；界面翻译保留工程文字与表情包名称。
- **本地模型 JSON 输出兼容** ： 根据端点支持情况切换 JSON 输出约束，处理已知的空回复冲突；缺少闭合括号或尾逗号等有限格式错误可修复，回复中的思考内容自动剥离。空响应明确提示换模型或检查配置，字幕翻译与 AI 整理共用此行为。
- **转写与文件错误提示** ： 修复仅空格的媒体 token 绕过校验；任务密钥在进入日志、错误报告和批量清单前脱敏，保留诊断信息。创建或写入失败时说明权限、路径长度等原因并保留详情，避免误判为 LLM 服务失败。
- **Linux 打包版运行时与桌面集成** ： OCR / 本地 ASR 环境安装、模型下载、打开备份目录和完成通知不再受包内旧动态库或缺失模块影响；可正常调用宿主环境完成相关操作。
