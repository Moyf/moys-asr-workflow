# 多重字幕（双语字幕）规范

状态：MVP 设计与实现规范

## 1. 目标

在不干扰单字幕工作流的前提下，为编辑器增加主字幕 + 一条扩展字幕的双语编辑能力：

```text
主字幕 + 扩展字幕
       ↓
按段级时间码自动一对一匹配
       ↓
共享时间编辑、双轨波形显示、双列字幕列表
```

多重字幕是可选模式，默认关闭。已有主字幕但没有扩展字幕时仍显示可点击的多字幕开关；齿轮设置按钮仅在多重字幕启用后显示。扩展轨、列和导出项会在导入第二条字幕并开启模式后出现。

## 2. 产品边界

### 2.1 MVP 支持

- 主轨 + 一条扩展轨。
- 扩展来源为 `.srt` 或 `.mosp/.json`。
- 扩展文件只使用段级 `start`、`end`、`text`；扩展工程中的 `items` 不作为翻译字幕的字词时间码。
- 按 `300ms` 容差自动一对一匹配。
- 匹配预览、未匹配保留、手动绑定和解绑。
- 主轨/扩展轨/双列字幕列表。
- 一份共享波形背景上的主字幕 lane 和扩展字幕 lane。
- 正常联动移动、边界调整、成对删除、成对合并。
- `Alt` 临时解除一次拖动的联动，但不删除绑定关系。
- 绑定状态下从主轨发起 B、Ctrl/Cmd+Enter 或剃刀拆分，并用弹窗人工选择扩展文本断点；拓展轨波形右键也可单独按鼠标位置拆分。
- 多重字幕设置收纳在工具栏齿轮中，支持显示方式、主/副字幕语言类型、跨轨道吸附、同时选中绑定的主副字幕和交换主副字幕。“同时选中主副字幕”默认开启；点击有绑定关系的主字幕或副字幕时，会补选绑定的另一条字幕，但当前字幕编辑区仍以最后点击的字幕为准。单词型适合英语等按空格分词的语言；字符型适合中文、日文等按字符拆分的语言。列表字数、超长筛选和当前字幕面板会按对应轨道的语言类型计数。
- 选中单条扩展字幕后按 B，直接进入扩展字幕拆分流程。
- 开启多重字幕时使用齿轮中的“拓展字幕时波形高度”（默认 `168px`）；关闭后恢复“配置”中的波形行高。
- 基础波形开启多重字幕时，主/副两个 lane 会自动使用适中的增高高度；普通多行波形仍使用齿轮中的“拓展字幕时波形高度”。
- 主轨和扩展轨分别导出 SRT。

### 2.2 暂不支持

- 多条扩展轨的当前界面管理。
- 一对多/多对一的实际编辑行为。
- `jieba` 或其他 Python 分词器在浏览器中的调用。
- 合并双语文本为同一份双行 SRT。

工程数据使用可扩展的轨道与绑定结构，为后续能力预留空间，但 MVP 强制每个绑定组各包含一个主字幕和一个扩展字幕。

## 3. 多重字幕开关

- `multi_subtitle.enabled` 随工程保存，默认值为 `false`。
- 旧工程没有 `multi_subtitle` 时视为关闭。
- 已有主字幕时拖入新的 SRT 或 mosp/json，弹出：
  - 替换当前字幕；
  - 作为多重字幕。
- 没有扩展轨时点击“多重字幕”开关，会询问“是否选择导入第二条字幕以开启多重字幕模式？”。取消询问或取消文件选择都会保持未选中；确认并导入后沿用“作为多重字幕”流程并自动开启模式。
- “多重字幕”开关的提示说明当前工程可在存在多条字幕时开启模式，用于双语字幕编辑等场景；未启用时不显示齿轮设置按钮。
- 导入弹窗先居中选择行为，再在右下角使用“导入”或“取消”确认；已有主字幕时默认选中“作为多重字幕”，仍可切换为替换主轨；替换主轨、导入多重字幕和替换扩展轨都作为一次可撤销操作。
- 选择“作为多重字幕”后创建扩展轨、执行匹配预览并自动开启开关。
- 已有扩展轨时再次拖入字幕文件，只允许“替换扩展轨”或“取消”，禁止静默覆盖。
- 显式“加载字幕”入口继续保持替换主轨的原有语义。
- 关闭开关只隐藏扩展轨和相关 UI，不删除扩展数据、绑定和导出信息。
- 选中存在绑定关系的主字幕或副字幕时，共享波形中该字幕及其绑定字幕块右侧显示 🔗 标记。
- 多重字幕相关选项收纳在工具栏齿轮中；“跨轨道吸附”默认开启，关闭后恢复仅在当前轨道内寻找吸附目标。
- 多重字幕开关开启时，波形“每行高度”临时切换到“拓展字幕时波形高度”预设（默认 `168px`）；关闭开关后恢复切换前的“配置”值。
- “交换主副字幕”会交换主/扩展轨的文本、时间和绑定端点，作为一次可撤销操作。主轨专属的 `items`、表情包和颜色分组不会随降级到扩展轨的字幕段保存。
- 多重字幕启用时，视频预览工具栏显示“预览拓展字幕”；预览设置中可分别调整主/拓展字幕字号、字体和颜色。主字幕默认白色，拓展字幕默认黄色且小 2px，二者共用可拖动预览框。

## 4. 工程数据契约

顶层 `segments` 继续是主轨真源。新增的 `multi_subtitle` 为可选字段：

```json
{
  "segments": [
    {
      "id": "main-001",
      "start": 1000,
      "end": 3000,
      "text": "主字幕"
    }
  ],
  "multi_subtitle": {
    "schema": "moy.asr.multi_subtitle.v1",
    "enabled": true,
    "display_mode": "both",
    "main_split_mode": "word",
    "tracks": [
      {
        "id": "extension-1",
        "role": "extension",
        "name": "扩展字幕",
        "language": "English",
        "split_mode": "word",
        "source_name": "translation.srt",
        "segments": [
          {
            "id": "extension-001",
            "start": 1100,
            "end": 2900,
            "text": "Extended subtitle"
          }
        ]
      }
    ],
    "bindings": [
      {
        "id": "binding-001",
        "track_id": "extension-1",
        "main_segment_ids": ["main-001"],
        "extension_segment_ids": ["extension-001"],
        "start_offset_ms": 100,
        "end_offset_ms": -100
      }
    ]
  }
}
```

约束：

- 当前 MVP 中 `main_segment_ids` 和 `extension_segment_ids` 必须各只有一个 ID。
- 主轨和扩展轨的字幕段都使用稳定字符串 ID；拆分、合并、删除不得依赖数组下标。
- `start`、`end` 和所有现有 `items` 时间仍为整数毫秒。
- `start_offset_ms = extension.start - main.start`。
- `end_offset_ms = extension.end - main.end`。
- 扩展轨的 `items` 可以被忽略或清除，禁止用于翻译文本拆分。
- 不保存外部文件的绝对路径；只保存来源文件名或用户可见名称。

## 5. 自动匹配与手动绑定

### 5.1 自动匹配

扩展字幕段与主字幕段满足以下条件时才成为候选：

- 两个时间区间有交集；
- `abs(extension.start - main.start) <= 300`；
- `abs(extension.end - main.end) <= 300`。

候选冲突时采用开始时间差与结束时间差之和最小的候选，并保证一对一使用。无法匹配的扩展字幕保留为未绑定项。

导入预览至少显示：

- 扩展字幕总数；
- 自动绑定数量；
- 未绑定数量；
- 冲突数量；
- 当前容差 `300ms`。

用户可以保留已匹配结果继续导入，之后分别选中一条主字幕和一条扩展字幕执行“绑定”。从扩展字幕右键选择“绑定到主字幕”时，若只有一条时间重叠且尚未绑定的主字幕，会直接完成绑定；重叠主字幕已有绑定、或存在多个候选时，进入等待选择流程。选择已有绑定的主字幕会替换原绑定。解绑只移除关系，不修改文本和时间。

选中单条副字幕后按 `G` 可执行“绑定到主字幕”；若同时选中一条主字幕则直接建立关系，否则复用上述自动匹配或等待手动选择流程。按 `Shift+G` 可解绑当前副字幕，按 `H` 可将已绑定副字幕对齐到主字幕时间轴。副字幕右键菜单中的绑定、解绑、对齐项分别显示 `G`、`Shift+G`、`H` 快捷键。

### 5.2 扩展字幕类型

导入时根据文本自动判断，并允许用户修改：

- `continuous`：CJK 等连续书写文本，允许在字符边界断开；
- `word`：英语等空格分词文本，优先在空格或安全标点处断开，禁止切碎单词。

纯浏览器规则同时用于便携 HTML 和 localhost 编辑器，不依赖 `jieba`。

## 6. 联动时间编辑

- 正常拖动主轨或扩展轨的整条字幕时，绑定双方应用相同 delta。
- 拖动起点时，只同步双方起点；拖动终点时，只同步双方终点。
- 双方各自的相邻字幕、媒体起止范围和最小时长共同参与 delta 限制。
- “跨轨道吸附”开启时，拖动任一轨道的字幕或边界也会把另一轨道字幕的起点和终点加入吸附目标；该选项默认开启，可在多重字幕齿轮设置中关闭。
- 主轨的 `C` 合并、拼合字幕工具的自动起点/终点延展也会连带处理绑定的副字幕；自动延展按同一边界 delta 更新，保留双方 offset。
- 主轨的 B、Ctrl/Cmd+Enter 和剃刀拆分仍使用同一个绝对切点联动拆分；只有 Alt 临时独立操作会暂不修改绑定的副字幕。
- `Alt` 拖动整条字幕或边界时，只修改当前轨道的当前字幕；绑定继续存在，并重新计算受影响的 offset。
- 无移动的 `Alt+点击` 仍保持单字幕模式中的“切换禁用”行为。
- 删除绑定对的任一字幕时，默认成对删除，使用现有撤销恢复。
- 扩展 lane 在共享波形中位于底部，主字幕 lane 紧贴在其上方；行高较小时会自动缩小 lane，避免上下顺序反转或溢出。

## 7. 列表与波形

### 7.1 字幕列表

多重字幕开启后支持三种视图：

- 主轨；
- 扩展轨；
- 同时显示。

同时显示时按绑定关系对齐成行。未绑定项按时间插入，另一列留空。两列文本都可以独立编辑；时间操作仍按绑定联动规则执行。

### 7.2 波形

波形只有一份背景和一份派生缓存。现有按时间切分的多行波形窗口继续保留，每个窗口内部增加字幕 lane：

```text
共享波形背景
主字幕 lane
扩展字幕 lane
共享播放指针
```

关闭多重字幕时只渲染主字幕 lane，恢复单字幕的高度和操作路径。B、Ctrl/Cmd+Enter、剃刀拆分仍只从主字幕 lane 发起；拓展字幕可以通过波形右键菜单单独拆分。多重字幕开启且仅选中一条拓展字幕时，B 改为打开该拓展字幕的拆分弹窗，右键菜单中的拆分项显示 `B`。共享波形右侧用 `1` / `2` 分别标记主字幕 lane 和扩展字幕 lane。

## 8. 联动拆分与弹窗

绑定状态下从主轨发起拆分时，不立即修改工程，而是打开小型拆分弹窗；拓展轨右键“在鼠标位置拆分”也使用同一弹窗，但只显示拓展轨：

- 显示扩展字幕完整文本；
- 显示当前候选断点与左右文本预览；
- 鼠标移动时实时改变候选断点，并吸附到合法边界；
- 默认悬停自由移动候选断点；左键点击后锁定，标题提示“拆分点已锁定，再次点击后解锁”，再次点击解除锁定；锁定时 ✂️ 和下方左右文本预览使用强调样式；
- 左键或“拆分”按钮确认，Enter 确认，Esc 取消；
- 左下角“全部拆分后自动提交”默认开启：单字幕副字幕选完断点后直接提交，多字幕在主/扩展字幕的所有断点都确认后直接提交；关闭后需手动点击“拆分”或按 Enter；
- 默认开启“主字幕拆分使用字词时间码”且存在可用字词时间码时，主轨切点由主字幕字词时间码锚定，用户只调整拓展轨切点；没有可用字词时间码或关闭该设置后显示主轨交互区，波形入口传入的绝对时间固定为拆分点，两个轨道分别选择文字断点；
- 拓展轨右键“在鼠标位置拆分”只修改拓展轨。若该段已有绑定，会解除旧绑定，主字幕保持不变，拆出的两条拓展字幕可再分别绑定；
- 移动鼠标并点击选择拆分断点；字符型语言（中文等）按字符拆分，单词型语言（英语等）只在空格切分，确保不会拆碎单词。主字幕和副字幕的语言类型可在多重字幕设置中分别切换；
- 弹窗会在切点旁提示时间来源：波形入口固定使用指针绝对时间时显示“当前切分位置固定为波形指针位置”；主轨字词时间码推定切点时显示“当前切分位置由字词时间码推定”；
- 选择断点后自动移除相邻的 `，。,.` 和空白；单词型拆分会自动 trim 两侧空格；
- 任一侧为空、单词被拆碎或时间过短时禁止确认；
- 联动确认后主轨和扩展轨各拆成两条，生成两组新的一对一绑定；
- 整个过程必须是一次原子撤销操作。

### 8.2 主字幕波形拆分设置

- 设置中提供“主字幕拆分使用字词时间码”，默认开启。
- 开启时，波形剃刀、波形右键拆分和 B 的波形路径继续优先使用主字幕 `items` 的字词时间码；如果当前字幕没有可用的字词时间码（例如只有 SRT 文本），也会自动打开拆分弹窗选择字符间断点。
- 关闭时，这些波形拆分入口打开同一套字符间 ✂️ 拆分弹窗，由用户选择并确认主字幕断点；字幕列表中的文字光标拆分不受该设置影响。

### 8.1 联动合并

执行主轨 C 合并时：

- 主轨先确定合并时间范围；
- 扩展轨收集已绑定项以及与该范围相交的未绑定项；
- 按现有合并分隔符合并扩展文本和时间；
- 主轨和扩展轨各生成一条新字幕，并自动重新建立一对一绑定；
- 合并范围内没有扩展项时，主轨合并结果保持未绑定。

### 8.3 拓展轨独立合并

仅选中连续的拓展字幕块时，右键菜单提供“合并副字幕块”，裸按 `C` 也执行同一操作：

- 只合并拓展轨的文本和时间，不修改主轨；
- 合并操作支持撤销；
- 如果被合并的拓展段存在绑定，旧的一对一绑定会被解除，合并结果等待用户重新绑定。

## 9. 导出

- 现有主轨 SRT 导出保持不变。
- 多重字幕开启时增加扩展轨独立 SRT 导出。
- 暂不输出合并双语 SRT。
- 工程导出始终保留扩展轨、绑定、语言类型、稳定 ID 和开关状态，即使 UI 当前关闭多重字幕。

## 10. 验收标准

- 单字幕旧工程在开关关闭时的列表、波形、快捷键、拖动和主轨导出行为无回归。
- 拖入扩展字幕能完成替换/添加选择、匹配预览和未匹配保留。
- 主轨与扩展轨能在共享波形中清晰分 lane 显示，且不生成第二份波形缓存。
- 普通移动/边界拖动联动，`Alt` 能临时独立调整并保持绑定。
- 绑定、解绑、成对删除、撤销、联动合并均可用。
- 弹窗拆分能用鼠标选择字符型/单词型断点，保护完整单词并清理指定标点；字数统计按各轨道的语言类型计数。
- 主轨和扩展轨可以分别导出 SRT。
- 便携 HTML 与 localhost 编辑器行为一致。
- 自动化测试通过后，仍需在真实浏览器中手动验证拖动、播放、弹窗、双 lane 布局和导出。
