# MAW 2.0 新版本核对

## 2026-10-10
新版：

这个地方的 pointer anchor 锚点在中间而不是左边 🤔
![[MAW 2.0 新版本核对-img-261010_232122.webp]]
另外，像是「自定义色值」之类的选项也都有这个锚点歪来的现象。

从设置中打开帮助的时候，不自动关闭设置。

`在 [工程设置] 中配置当前工程的 FPS 和时间单位。`
这里的「工程设置」应该是 editor-settings-inline-action ，点击后打开工程设置的对应标签页。

`合并字幕时插入字符`
地下加上 hint 文本，并且带有 inline action 跳转到工程设置的 [时间与语言] 标签页。
「你可以在 [工程设置] 中配置字幕的语言类型。」

> 对了，再加一个 flash 闪烁功能，跳转过去之后在对应的设置项范围（settings-panel-section？你看一下加哪里合适）闪烁一下边框。
> 做成一个比较通用的可复用功能，各种跳转都可以用这个提示闪烁。

并且这样一来，哪怕是同时开着两个设置弹窗，点击的时候也会有一个闪烁的视觉效果，而不会让用户误以为什么都没发生。

> 另外，项目的一个规则：当我让你写 “在 [工程设置] 中配置” 的时候，这个 `[]` 都代表的是 inline action 这类点击可跳转的链接文本，不需要实际写入 `[]` 符号。

所以，像是现在的 `Configure the speaker mapping toggle and related options in [Project settings].` 里的 `[]` 也都可以去掉。

![[MAW 2.0 新版本核对-img-261010_233311.webp]]
右键添加左右字符的时候 skip 字词时间码匹配，因为这种情况下必然是不匹配的。

「全局设置/界面」中增加「消息提示位置」的配置，目前是「上方」，可以选择「上方/右上方/右下方」。

「### 字词拆成字幕」的弹窗风格和当前项目的整体弹窗风格不匹配，需要调整。尤其是两个按钮，太丑了。

❗ 另外，字词时间码启用时，多行波形的字词块应该要显示得矮一点，这样上方可以空出一点空间显示地下的字幕块。然后文本垂直居中显示。
相对应地，字词时间码显示时，原来的 cue block 也可以高一点点。
我还不太确定这样的显示效果好不好，先做一下试试，如果你有更好的想法也可以再调整。

勾选「自定义色值」的时候明显会卡顿一下，检查是什么原因导致的。
——难道是因为需要同时修改所有 block 的色值？这个应该有更聪明的办法吧，比如直接修改颜色 CSS 变量？
我看了一下现在好像是每个颜色字幕单独配置 `--color-bar: #c36c60; ` 的，改成用类似 `--subtitle-color-red` 的颜色变量会不会好一些，这样不需要每个 items 都重新刷了。

以及，现在切换双语字幕轨道也会卡顿一阵子，检查是什么原因，如何改善。

___

勾选了「显示标记轨道」的情况下，如果工程内没有字幕，那还是没法点击添加标记（没有 `waveform-marker-track`），得存在至少一个标记才会显示。
改成只要启用了这个，就显示，不管有没有标记。

问题反馈：编辑完标记的名字或者备注之后，要点两次「完成」按钮才会结束标记的编辑。
调整：没有备注的标记，哪怕勾选了「显示备注」也不额外显示内容。
另外，`markers-item-note` 不需要 margin-top。现在似乎加的有点儿太滥用了……不是说「所有的 UI 元素」都必须至少 8px 以上。只有必要的需要加。
类似地，`.editor-settings-nav` 的 8px gap 也可以去掉，改成 2px。
`editor-settings-field` 的 gap 也去掉，不需要。

`gap-remove-panel-body` 顶部的 padding 也太多了，2px 就可以。

___

以及，处于「这里只配置自动后处理；生成后会自动执行。」状态时，【烧录字幕】的媒体文件应该是不必填写的，因为肯定会是由原媒体转写之后直接调用对应的原始媒体。所以不用预先填写。
另外，如果原始媒体是音频，那么就视作是勾选了「绿幕视频」。
