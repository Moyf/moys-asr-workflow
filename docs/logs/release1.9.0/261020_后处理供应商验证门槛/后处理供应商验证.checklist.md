## 人工核验
<!-- id: manual -->

- [ ] **LM Studio 空 Key 验证后可以启用步骤**
  （操作）启动 LM Studio 的本地接口；勾选尚未配置的口播整理，在设置中选择自定义接口，填写回环地址和模型，API Key 留空，点击测试连接。
  （预期）测试成功后口播整理自动勾选，供应商记忆改为该自定义接口；关闭设置后取消再勾选不会重复弹窗。
  （说明）需要本机真实服务；浏览器 mock 测试不能证明模型服务可用。
  <!-- id: local-no-key -->

- [ ] **DeepSeek 反复勾选不会重复弹配置**
  （操作）为 AI 校对配置真实 DeepSeek Key 并测试成功；关闭设置，连续取消并重新勾选 AI 校对两次。
  （预期）步骤保留 DeepSeek 绑定，不重复弹出设置；Key 不出现在日志或提示中。
  <!-- id: cloud-repeat -->

- [ ] **取消设置后无关验证不会启用旧步骤**
  （操作）勾选未配置的口播整理，分别用关闭按钮、遮罩或 Esc 关闭设置；之后从设置按钮打开并测试另一个供应商。
  （预期）口播整理保持未勾选，不被后来的测试自动启用或改绑。
  <!-- id: dismiss-request -->

- [ ] **取消勾选和迟到回包不恢复旧选择**
  （操作）在后端响应较慢时勾选后立即取消或按 Esc；另一次测试连接未结束时关闭设置，再打开另一 AI 步骤配置。
  （预期）取消后该步骤未勾选且不会补弹设置；旧连接测试完成后不勾选或改绑新步骤。
  <!-- id: stale-request -->

- [ ] **演示模式刷新后保留本地模型就绪状态**
  （操作）浏览器打开 Launcher，测试一个空 Key 回环自定义接口；随后勾选另一个未配置步骤并关闭其设置，再重新勾选原步骤。
  （预期）原步骤直接勾选成功；自定义接口的名称、URL 与模型保留。
