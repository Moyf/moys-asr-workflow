## 审查结论

- 根目录纳入版本管理的普通文件从 29 个减到 22 个，相比整理前 37 个合计减少 15 个。统计排除 worktree `.git` 与被忽略的本地构建锁、缓存等输出。
- 共享函数的 AST 与迁移前一致；保留的 Qwen 函数仅 `main` 调整时长解析函数名与编辑器定位。其余入口的函数体仅在需要时调整编辑器路径；local、Tencent 函数体不变。
- Qwen 默认热词文件和 HTML 生成器仍定位仓库资源根；OpenAI 从共享贴纸模块导入配置，消除对整个编辑器的导入依赖。
- 源码 Launcher 使用模块命令，本地外部 Runtime 使用新包文件的绝对路径；冻结程序原有内部标志不变。实际从 spec 复制源镜像，在独立目录用 `python -I .../maw/asr/local.py --help` 导入通过；导入图不再包含 Qwen/OpenAI 入口或编辑器。
- 测试随逻辑所属模块迁移，保留已有断句、零时长修复、输出命名、临时媒体生命周期与错误分支断言；新增 7 个模块入口及 7 个内部处理器的帮助检查，不访问 API 或加载模型。
