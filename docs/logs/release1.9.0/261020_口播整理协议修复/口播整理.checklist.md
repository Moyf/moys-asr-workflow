# 英文口播整理修复核验

> 验证英文词项空格、只读上下文和共用时间码的重复词；自动化结果与人工试听分别记录。

## 实现与审查结论
<!-- id: conclusions -->

ASR 英文词项常自带前导空格，送模型的整句却去掉首尾空白，原实现会把本地造成的输入差异归咎于模型。现在仅兼容首尾缺失空白和划删边界的分隔空白，不放宽实际文字、标点与词内空格的匹配。

模型误输出本轮明确只读的上下文行时忽略这些行，不采纳其中的删除建议。仍严格拒绝缺目标、重复目标、未知 ID 和改写；切开词项的建议不执行，该行完整保留并标待回听，其他可靠整理可完成。

同一个词项包含多个单词时不能只剪一部分，提示保留并标待回听。独立的英文犹豫声 Uh、Um、Hmm 可经本地校验删除，否定和正文词继续受到保护。
