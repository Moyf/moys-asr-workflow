# MAW 1.10.0-beta.1 发布核验

> 这是当前 main 完整范围的预览版。自动化与 CI 通过后发布 beta；正式版等维护者完成以下人工核验并处理发现的问题后再发布。

## 实现与审查结论（只读）
<!-- id: scope -->
<!-- badge: fixed 已准备 -->

本版本汇总 v1.9.0 后的 Launcher、字幕工具、编辑器帮助、表情包烧录、工程文件烧录和 ASR 工作流改动。源码变更已合入 main；本次准备将包版本、Launcher 显示、英文快速开始、CHANGELOG 和便携编辑器同步到 v1.10.0-beta.1。详细人工步骤也可参考日志索引中的编辑器烧录、SRT 烧录、样式库与去空隙核验记录。

- [ ] **Windows beta 包版本和启动流程正确**
  （操作）从 v1.10.0-beta.1 Release 下载 Windows 完整包与 MAW-lite（若附件提供），分别解压到独立目录后启动 Launcher。

  （说明）记录实际下载的附件名；检查最终 Release 中的附件，不以 CI 打包日志代替下载验证。

## 人工核验：字幕烧录与编辑器
<!-- id: burn -->

- [ ] **工具箱可按工程样式烧录 `.mosp` 与 `.json`**
  （操作）在媒体工具打开烧录字幕，分别选择一个 `.mosp` 和 `.json` 工程；使用含字体、颜色字幕及叠加轨的样例烧录短视频，并与编辑器预览对照。
  （预期）两类工程均能完成烧录，字幕样式、颜色字幕和叠加轨与工程一致；空字幕过滤后其他字幕颜色仍对应原颜色组；输出画布尺寸与视频或绿幕设置一致。
  （说明）ASS 强调语法和字级动画仍使用编辑器导出的 ASS 文件验证。
  <!-- id: project-burn -->
- [ ] **视频烧录中的表情包位置与去空隙时间轴正确**
  （操作）在编辑器短视频工程开启表情包预览，分别选固定位置和字幕第一个字左侧；测试 GIF 与静态 WebP，再对有去空隙区段的工程执行重组后烧录。
  （预期）表情包与字幕同步；两种位置符合设置；GIF 循环播放，静态 WebP 可烧录，动画 WebP 显示暂不支持提示；去空隙后字幕和表情包按收缩时间轴移动。
  <!-- id: sticker-burn -->
- [ ] **关闭 ASS 时仍可按样式库烧录 SRT**
  （操作）关闭 ASS 模式，打开字幕帮助页，再选择样式库中的 SRT 样式烧录短视频；检查进度并尝试停止一次任务。
  （预期）帮助入口可打开相应说明；烧录使用所选 SRT 样式，进度可见，停止后任务结束且不留下误导性的成功状态。
  <!-- id: srt-burn -->

## 人工核验：Launcher 与字幕工作流
<!-- id: workflow -->

- [ ] **文稿匹配与已有字幕修正入口清楚且状态保留**
  （操作）分别查看媒体工具的文稿匹配和字幕处理的文稿修正，使用顶部跳转后切回原工具。
  （预期）无需已有字幕即可进入文稿匹配；已有字幕的文稿修正留在字幕处理；标签顺序符合界面说明，切换后原输入仍保留。
  <!-- id: transcript-flow -->
- [ ] **后处理供应商验证可启用步骤且不会恢复旧选择**
  （操作）在口播整理或 AI 校对中配置可用的远程或本地供应商并测试连接；成功后关闭设置、取消步骤或切换供应商，再观察状态。
  （预期）验证成功后对应步骤可启用；LM Studio 等本地接口可留空 API Key；取消或切换后，迟到的验证结果不会重新启用旧步骤。
  （说明）避免把真实密钥写入核验备注或截图。
  <!-- id: provider-state -->
- [ ] **云端识别下的文稿对齐可独立配置模型环境**
  （操作）保持云端识别方式，在工具箱打开对齐模型管理；检查依赖提示后返回并选择文稿样例运行对齐。
  （预期）对齐模型与运行环境可独立管理，原 ASR 识别设置保留；Windows 上不会把同名 Python 模块误当成 FFmpeg；模型环境可用时生成可打开的字幕工程。
  （说明）若外部模型或网络使推理未能完成，请记录为待处理并附脱敏错误，不要将入口可用当作推理通过。
  <!-- id: alignment -->
