# MAWE 1.x 命令面板人工核验

> 从 2.0dev 的 PR #410 回移；本清单面向 1.x 本机编辑器。

## 自动化证据
<!-- id: verified -->

Chromium 命令面板 5 项通过，覆盖搜索、快捷键隔离、最近使用和另存／导出。1280×800 下工具栏入口与面板相关间距均实测至少 8px；已检查布局截图。

## 人工核验
<!-- id: acceptance -->

- [ ] **输入法与焦点**
  （操作）在字幕搜索框按 Ctrl/Cmd+K，用中文输入法搜索命令，再按 Esc。
  （预期）输入法组词时不执行命令，关闭后焦点回到字幕搜索框。
  <!-- id: ime -->

- [ ] **另存、导出和 1.x 格式**
  （操作）打开带字幕的 1.x 工程，在面板执行「另存为」和「导出工程」，各试一次取消与成功，再在 1.x 编辑器重开输出文件。
  （预期）取消不新增最近使用；成功后可重开且字幕完整。另存改变保存目标，导出不改变当前目标。
  <!-- id: save-export -->

- [ ] **浅色主题与窄窗口**
  （操作）切换浅色主题并缩窄窗口，通过工具栏打开面板。
  （预期）入口与文字仍可读，结果可滚动，键盘可执行并关闭。
  <!-- id: layout -->
