- 同步主线后的定向 Python 测试运行 575 项、通过 547 项、跳过 28 项；跳过含需 POSIX FFmpeg / FFprobe 的回归。Chromium 相关 24 项通过。切换按钮与文本框间距实测 8 px，「生成处理前后对比结果」复选框与就地提示间距实测 3 px。
