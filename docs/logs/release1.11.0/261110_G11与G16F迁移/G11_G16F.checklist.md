## 人工核验
<!-- id: manual -->

- [ ] **核对媒体播放和切换时的预览刷新**
  （操作）在 Server 编辑器载入视频，播放、暂停、Seek、切换全屏，再替换为另一媒体并重复。
  （预期）字幕与播放头跟随当前媒体；ASS Canvas 在暂停和调整窗口大小后及时刷新，不显示旧媒体画面或旧字幕。
  <!-- id: media-playback -->

- [ ] **核对导入与导出路径**
  （操作）拖入字幕和媒体，导出 SRT、ASS、OTIO 与 FCP 7 XML，并在目标软件中打开其中一个导出文件。
  （预期）导入进度、文件名、时间码和字幕内容正确；取消导出不显示成功提示。
  <!-- id: io-exports -->

- [ ] **核对 ASS 逐句位置与帧预览**
  （操作）调整字幕锚点、比例、描边和阴影，拖动逐句位置，暂停后打开帧预览，再 Seek 并撤销一次调整。
  （预期）Canvas、帧预览和导出位置一致；撤销恢复原值，旧帧响应不覆盖新位置。
  <!-- id: ass-position-frame -->

- [ ] **核对 ASS 样式库跨窗口同步**
  （操作）在 Server 编辑器修改样式并等待保存，在另一窗口打开同一用户配置，重新载入样式库；再模拟离线或会话过期。
  （预期）保存完成后两窗口读取同一修改；离线时保留本地副本并显示相应状态，会话过期时提示重新打开。
  <!-- id: ass-style-sync -->
