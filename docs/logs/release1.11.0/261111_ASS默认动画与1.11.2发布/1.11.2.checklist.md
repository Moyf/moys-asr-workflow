## 人工核验
<!-- id: manual -->
<!-- badge: todo 待维护者确认 -->

- [ ] **干净配置的内置方案不自动添加入场动画**
  （操作）在隔离的干净配置中打开 1.11.2 → ASS 样式库 → ASS 输出方案，查看淡入淡出与放大出现；导出一条普通字幕。
  （预期）两个选项都不勾选；普通字幕无淡入淡出和缩放入场，导出的 Dialogue 不自动带 fad/t 动画标签。
  （说明）不要删除自己实际使用的样式库；也可在备份后通过界面重置内置方案。
  <!-- id: clean-defaults -->

- [ ] **已有方案设置不被升级覆盖**
  （操作）使用备份的旧配置，在升级前分别保存勾选或关闭的方案；升级 1.11.2 后重新打开样式库。
  （预期）原有开关与参数保持不变；曾默认勾选并保存的配置不会强制关闭，需手动取消一次。
  <!-- id: saved-choices -->

- [ ] **主动开关及单句动画仍可使用**
  （操作）开启 fad 或放大出现并导出；随后关闭两开关，分别输入 >>文字<< 和 {{文字}}，预览并导出 ASS。
  （预期）主动开启时逐句自动应用；关闭后只有标记句产生相应动画，普通句不自动添加，参数仍沿用方案。
  <!-- id: opt-in-markers -->

- [ ] **正式 Release 和附件可用**
  （操作）打开 GitHub 的 v1.11.2 Release，查看正文并下载适合当前系统的完整包；打开 Launcher 和编辑器。
  （预期）正文依次显示「修复版本说明 / 1.11.2」与「大版本更新特性 / 1.11.0」，基础说明只出现一次，图片可见；安装包可启动且显示 1.11.2。
  <!-- id: release-assets -->
