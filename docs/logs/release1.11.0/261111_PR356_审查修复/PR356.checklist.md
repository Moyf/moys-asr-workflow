## 实现与审查结论
<!-- id: implementation -->

用进程令牌 SID 替代环境用户名；默认根改为 ProgramData/MAW-runtimes-<SID哈希>/<runtime>，首个自建节点即私有。创建时设置受保护 ACL，读取/执行前校验所有者、祖先替换权限、重解析点及向后代继承的写权限。显式路径在跟随 junction 前检查。旧用户名哈希目录不自动复用，需重新安装。
