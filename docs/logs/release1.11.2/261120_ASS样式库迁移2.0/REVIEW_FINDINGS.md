# 2.0 ASS 样式库迁移复核

以 `2.0dev@58b408e4` 为基线，移植 [main 的样式库迁移变更](https://github.com/Moyf/moys-asr-workflow/pull/381)（`9d10ab50`）。迁移文件沿用同一格式，仍只写用户样式库。编辑器遍历 v2 工程各轨道检查单句样式快照，导入不改写工程。

独立复核没有发现阻塞问题。核对了 ESM 装配、用户样式库和各轨道快照的边界，以及前后端 65 个样式、64 个方案的容量。已删除两份指南残留的旧便携入口说明。浏览器验证使用本地服务器打开 v2 工程。
