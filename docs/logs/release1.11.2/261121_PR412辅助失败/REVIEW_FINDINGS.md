## 条目 10：拖动期间保存护栏

独立自审无 blocker / major，4 条 nit 逐条处置：

| 分级 | 发现 | 处置 |
| --- | --- | --- |
| Nit | `flushInlineEditsForSave` 的提前返回同时跳过「焦点在面板内」的文字快照同步分支，注释未提及。 | 接受。三个拖动入口都调用 `focusWaveform()`，面板文字在 `blur` 即提交（`editor-wiring-cue-panel.js:170-172`），拖动开始时不存在未提交面板编辑；即使 Tab 进面板，文字本身实时同步，只是快照/字码同步推迟到拖动后的首次 flush，不丢数据。 |
| Nit | 取消的拖动不重新武装防抖保存，已消耗的 400ms 定时器不重试，既有未保存改动要等 30s 间隔。 | 接受。与既有 ASS 定位拖动先例同形（`editor-project-save.js` 同文件）；提交路径经命令层刷新重新武装，仅取消路径有间隔窗口，内存不丢。 |
| Nit | 回归测试关闭 `autoSaveProject` 写入 localStorage 且不恢复，依赖 Playwright 每测试新上下文隔离。 | 接受。本 spec 无共享上下文 fixture，默认配置下每个测试独立上下文。 |
| Nit | 静默回归用 `≥1` + Set 约束请求数，容忍同内容重复 POST（如 checkpoint）。 | 接受。Set 仍钉死每条载荷为 `10200/18000`，内容不变；数量放宽只避免对合法重复保存脆弱。 |
