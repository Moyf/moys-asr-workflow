## 人工核验
<!-- id: manual -->

- [ ] **确认叠加字幕行、波形和面板选中同一条字幕**
  （操作）启用叠加轨。通过字幕列表和波形分别单选，使用 Ctrl 或 Shift 扩选。打开右键菜单，将一条可转换字幕移到主轨，再撤销。
  （预期）列表、波形和面板显示同一个当前目标，选中计数正确，撤销恢复到原轨和原时间范围。
  <!-- id: overlay-selection -->
- [ ] **确认使用 Enter 拆分和 Esc 关闭时只执行一次**
  （操作）通过波形快速编辑或字幕面板开始拆分，关闭自动提交。按 Enter 打开确认框，再按一次提交。打开文本工具和设置窗后分别按 Esc。
  （预期）首次 Enter 只打开确认，第二次才提交，撤销一次恢复。Esc 关闭最上方窗口，关闭后焦点可继续使用。
  <!-- id: keyboard-modal -->
- [ ] **确认设置、搜索与字词工具在重开后保持状态**
  （操作）更改主题及语言，搜索设置项并选择结果。输入字幕查询并调整颜色筛选。在工程设置打开字词时间码，试听一个词，保存并重新打开工程。
  （预期）提示翻译、筛选结果、字词选区和时间范围正确，每次操作只触发一次。
  <!-- id: settings-word-timing -->
- [ ] **确认工具栏菜单与去空隙面板可以反复打开和关闭**
  （操作）用鼠标和键盘打开工具栏下拉，尝试外部点击和 Esc，再重开去空隙面板并切换界面语言。
  （预期）菜单只开关一次，Esc 后回到原控件。去空隙面板保留既有交互与翻译。
  <!-- id: toolbar-gap -->

- [ ] **在真实 Server 编辑器重复打开工程并走一遍新手引导**
  （操作）用干净的浏览器配置打开本地 Server 编辑器。完成一次引导，然后分别加载两个工程，切换列表筛选并尝试关闭带未保存修改的页面。
  （预期）每次启动只有一份引导，字幕、波形和未保存提示绑定当前工程，切换筛选和取消关闭后界面可继续操作。
  <!-- id: editor-boot-and-onboarding -->

- [ ] **确认两页编辑器互相隔离，并核对 Launcher 的共用悬停提示**
  （操作）同时打开两个本地 Server 编辑器标签页，在其中一页打开工程、合并字幕并撤销。随后打开 Launcher，悬停有说明的按钮。
  （预期）两个标签页各有自己的工程和选区，撤销只影响当前页。Launcher 按钮只显示一份悬停提示。
  <!-- id: esm-entry-isolation -->
- [ ] **确认依赖候选新增和移走会使旧 Editor 产物过期**
  （操作）在干净的测试工作树构建 Editor，新建一个未被导入的临时源码文件，执行新鲜度检查并重建。再移走临时文件并重复检查。
  （预期）每次文件集合改变后，检查都提示过期；重建后检查恢复通过。浏览器仍从 Server 打开。
  <!-- id: editor-source-inventory -->
