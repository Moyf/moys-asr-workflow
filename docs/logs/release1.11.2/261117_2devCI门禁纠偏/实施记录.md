## 明确准入，而不是全量稳定标签

文件/ID 准入在 `scripts/ci_acceptance.py` 的 PYTHON/NODE；Node 的精确静态名称清单另在 `scripts/ci-node-admission.json`。每次执行保存 Python IDs、Node 文件/名称及实际报告，单次 Node 执行对照静态集合。

- data：`test_project_contract.py`、`test_project_io.py` 整文件；v2 migration 仅独占写入失败不覆盖、remember_media 保留格式两个明确 ID。整个 migration 文件含页面构建，不能当成无构建依赖纯单测。
- editor：recovery_save、project_save_state、v2_migration_save、editor_state、editor_commands 的 Node VM 文件，含保存取消/失败/脏状态保护。
- runtime：三个明确 packaging 路径安全/模块装配 ID，加 `ProjectBoundaryTests.test_server_import_and_save_future_schema_preserve_disk`；不运行完整 HTTP Server 类或 FFmpeg 夹具。
- docs/release/website/tools/build/launcher/ci：精确文件见清单；不是 common pack、全 Node、浏览器或真实媒体。build 专组先构建再测装配，不依赖另一个矩阵 job 的文件。

真实官网源文档从本分支 sync 脚本 curated map 读取，DEVELOPMENT、JSON_SCHEMA 与部分日志确是网站输入，不能将所有工程 Markdown 机械判轻量。网站同步后 diff 守住已跟踪生成副本，防止覆盖后虚假通过。
