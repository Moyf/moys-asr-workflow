# 暂停预览与编辑器启动

> 使用工程副本，准备一条带 AI 清理区段的字幕和一条可交换的副轨。

## 编辑器预览
<!-- id: editor -->

- [ ] **暂停时恢复与撤销副轨文字**
  （操作）启用 ASS 预览，将主副轨交换。在字幕仍可见的时刻暂停，右键波形中的清理区段并选择「恢复区段」，再撤销。
  （预期）恢复的文字立即出现在副轨预览，同一时刻的导出字幕含有这些文字。撤销后预览与导出均恢复原先的裁剪结果。
  <!-- id: paused-restore -->

## Windows Launcher
<!-- id: launcher -->

- [ ] **端口占用与已有编辑器复用**
  （操作）选择一个已被其他本地 HTTP 服务占用的端口，在空工程状态打开编辑器。再选空闲端口启动 MAW 编辑器，用相同端口再打开一次。
  （预期）第一次提示端口已占用。空闲端口能启动编辑器，再次打开时复用同一个编辑器。
  <!-- id: existing-server -->
