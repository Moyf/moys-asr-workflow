# 暂停预览与启动识别合并前复核

复核起点为 #429 的 `c89a8107`，目标分支已通过 `3d76e476` 合入 #427。

- **慢响应编辑器。** 大工程加载期间，健康检查允许请求用时 2 秒，随后识别编辑器身份却只等 0.25 秒。合法启动状态延迟 0.4 秒返回时，缺少 Windows PID 回退的 Launcher 会误报端口占用并停止刚启动的子进程。启动和复用编辑器时，首轮探测及身份读取现在都允许请求用时 2 秒，端口拒绝连接时直接启动服务。回环 HTTP 回归覆盖已有和新启动的慢响应编辑器。
- **Windows 对齐服务。** 发布包以 `MAW.exe --serve-alignment` 启动语音对齐。按子串识别 `--serve` 会把它当成编辑器。进程回退改为识别完整模式参数，沿用现有编辑器和旧启动协议的识别路径。
- **辅助浏览器矩阵。** #427 将具体文件分配给作业，#429 旧版按用例分片。集成后从保存的文件组生成矩阵。0 个文件时其他辅助层仍有一个作业，1–2 个文件用一个作业，3–99 个用两个，100 个及以上用三个。定向测试核对 0、1、2、3、99、100、118 个文件的分组数、非空组和完整覆盖。旧两组实现在 100 和 118 个文件时均未达到预期。

本地 Windows 验证通过 CI 契约 56 项、生命周期与预览缓存 36 项、暂停预览与清理 Chromium 7 项。Launcher 模块运行 345 项，344 项通过、1 项跳过。Editor 和 Launcher 构建及新鲜度、TypeScript 和文档检查通过。跨平台桌面启动仍待人工核验。
