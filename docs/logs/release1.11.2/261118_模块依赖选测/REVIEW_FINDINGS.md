## 验证与边界

执行器、影响图、准入映射、差集和报告用小型正反例验证。普通工程说明与纯 Node 文件通过真实本地入口运行；工具页浏览器实际 11/11，通过一次发现与同次结果核对。网站准备发布数据后，导航、检查和构建通过。旧执行器在“工程说明不附带发布检查”和“单片不重复发现”两条新回归上实际失败。

在同一基线源码树回放已保存的旧选择器和本次选择器，以下数量均是文件数，不是用例数：

| 改动 | 旧第一批 | 本次 |
| --- | --- | --- |
| 普通工程说明 | 4 Python | 1 Python，无应用准备 |
| 颜色过滤 | 3 Python、38 Node、3 browser | 0 Python、4 Node、3 browser |
| energy valley | 31 Python、2 Node、2 browser | 11 Python，无 Node/browser |
| 缩略图任务 | 66 Python、3 Node、8 browser | 18 Python、0 Node、2 browser |
| 保存入口 | 4 Python、6 Node、7 browser | 0 Python、5 Node、10 browser |

保存入口补齐实际项目生命周期消费者后比旧选择多三个浏览器文件。预设校验经过公共项目校验接口仍会选择 65 个 Python 文件；本批不以压低数量为由删掉真实依赖。一次本机同组三计划对照中，复用同源 AST 与调用索引使冷进程选择从 18.149 秒降至 10.400 秒，计划逐字段相同。该数字只说明选择器开销，不是 CI 总时长或所有修改的稳定提速比例。

缩略图真实浏览器文件也通过新入口执行，记录 1 项通过、2 项失败；测试和产品断言未被放宽，根因未定。该次不是框架全部通过的证据，也不以修复历史整库红灯为本批前置。原始报告保留，相关失败后续单独分诊。

CI 继续区分有限准入和辅助消费者。差集只扣除本次准入完整执行的文件；仅准入几个方法的文件仍整文件辅助运行，接受少量重复，避免增加方法级调度与维护清单。普通文档没有未覆盖消费者时不启动辅助作业。第一批同进程失败后仍会停止后续组，不宣称已实现完整集中报错或检查点接续。

## 合并前复核

- 分段拼接的 Python 路径读取按实际路径匹配。Launcher 后处理脚本恢复选择 `test_gui_web.py`，编辑器模板恢复选择 `test_editor_assets.py` 和 `test_waveform.py`。
- 有限准入回退按每个改动输入判断。Playwright 配置和工具页 spec 同改时执行十个有限准入组，工具页仍走独立辅助检查。
- Node 内联 Python 子进程纳入依赖图。ASS 默认值和脚本对齐的改动选中实际跨语言对照；预设校验保留 65 个 Python 文件，并选中调用公共项目接口的三个 Node 文件。
- 浏览器准备跟踪实际调用的夹具。cue-scroll 和 server-align 补齐应用及 Python 环境，工具页无需准备应用。

新增的五项回归在原实现出现九处断言失败。修正后 52 项定向测试通过，ASS 本地选测入口执行的 Node 文件 375 项通过，cue-scroll 真实 Server 浏览器用例通过。独立复核未发现剩余合并阻塞。普通工程说明、颜色过滤和保存入口选测范围保持原样。
