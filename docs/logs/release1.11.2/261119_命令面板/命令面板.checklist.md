# MAWE 命令面板 Phase 1 人工核验

> 首批 40 条常用命令。Chromium 自动化覆盖主流程；下面补充真实输入法、播放器和系统文件选择器的验证。

## 实现与自动化验证
<!-- id: implementation -->
<!-- badge: fixed 只读 -->

命令面板复用已有编辑器动作，快捷键徽章只提示、不重绑。面板打开期间不触发编辑器快捷键；不覆盖已有模态弹窗。

已通过：编辑器构建与新鲜度检查、注册表与脚本装配测试、空白 Server 的 Chromium 主流程。1280×800 下，Chromium 断言工具栏入口到上一行、到相邻设置按钮均至少 8px；面板内输入框到列表、结果项间、列表到底栏也均至少 8px。命令触发浏览器文件选择器的事件已通过自动化检查，真实系统对话框交互待人工核验。

## 人工核验：真实编辑会话
<!-- id: manual -->

- [ ] **输入法组词与 Esc 恢复焦点**
  （操作）聚焦字幕搜索框，按 Ctrl/Cmd+K；用中文输入法键入「全局设置」，在组词中按 Enter 上屏，再按 Esc。
  （预期）组词时不会执行命令；关闭面板后，回到之前的字幕搜索框。
  <!-- id: ime -->

- [ ] **文件与播放器沿用已有流程**
  （操作）从命令面板执行「打开工程」，确认出现系统文件选择器；打开带媒体的测试工程，再执行「播放/暂停」与「跳到结尾」。
  （预期）文件选择器可正常选文件或取消；播放器状态和播放头与原有操作一致。
  <!-- id: file-and-playback -->

- [ ] **另存为取消不会更新最近使用**
  （操作）用尚未执行过「另存为」的命令面板打开该命令，取消原生保存对话框；重开面板查看最近使用。再次执行并保存到临时目录。
  （预期）取消时不新增最近使用条目；成功写入后，「另存为」显示在最近使用中。
  <!-- id: save-as-recents -->

- [ ] **主题与窄窗口可读**
  （操作）切换浅色和深色主题，缩窄编辑器窗口，通过按钮打开面板，使用方向键浏览到列表底部。
  （预期）标题、选中态和快捷键徽章清楚可读；面板不遮住自身底栏，列表可独立滚动。
  <!-- id: appearance -->
