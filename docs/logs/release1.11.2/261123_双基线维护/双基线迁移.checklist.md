## 人工核验
<!-- id: manual -->

- [ ] **校对及重新断句保留可信词码**
  （操作）选择含停顿、零时长标点与词级时间的录音工程，校对合并原文后重新断句，另存并重开。
  （预期）原文合并处仍能查看对应词码，停顿与标点随真实词项保留，播放时字幕段有正时长。
  <!-- id: proofreading -->

- [ ] **文稿对照恢复重叠的禁用句**
  （操作）选取前后两条有完整词码的启用字幕，中间放一条有词码的禁用字幕。运行按文稿匹配，让一条文稿句合并前后两句。打开完整对照，先按匹配结果另存，再恢复该组并另存第二份。
  （预期）第一份把禁用句原样放在叠加轨；第二份将它放回主轨。已有叠加内容和源文件保留。叠加时段已被占用时应提示并停止写出。
  <!-- id: disabled-overlay -->

- [ ] **核对三轨预览和成片**
  （操作）开启主轨逐字换色，为两条轨分别设置手动位置，给说话人添加半透明底框。调整一个词的起点，暂停、播放并烧录短样片。
  （预期）预览和成片在同一词起点换色，副轨和叠加轨位置正确，支持的说话人底框连续显示。
  <!-- id: render -->

- [ ] **独立工程与历史产物各自对照**
  （操作）先匹配工程 A，再换独立工程 B 完成匹配。分别打开转写对比和时间码对比，再选回 A 的历史产物。
  （预期）两个窗口先显示 B 的原始输入和结果；选回 A 的历史产物后，比较对象均来自 A 的处理链。
  <!-- id: compare-source -->

- [ ] **长工程导出 FCP 7 图片字幕**
  （操作）用含整词换色的长工程，在 60 fps 下导出 FCP 7 XML 与透明图片。在剪辑软件中导入，定位到换色和淡化处逐帧检查。
  （预期）长时间保持同一画面时只用一张图片；翻色与真实字幕预览对齐，连续淡化仍逐帧变化。
  <!-- id: fcp7-karaoke -->

- [ ] **文稿处理后保留口播删词和手动恢复**
  （操作）先对包含重复词的工程做局部口播删减，手动恢复其中一处，再做文稿匹配；在完整对照中另存结果并重新打开。
  （预期）已删和已恢复的词在工程、SRT 和播放中相互对应。若改写使原来的删词位置无法确认，工具在写出前提示。
  <!-- id: cleanup-match -->

- [ ] **从 Launcher 保存成片及取消选址**
  （操作）从 Launcher 打开工程，烧录一次并取消原生保存，再保存到新 MP4。用完成提示打开成片和目录。
  （预期）取消后原文件不变，成功后提示持续可见并指向刚保存的成片。等待保存时若更换工程或媒体，旧任务停止。
  <!-- id: burn -->

- [ ] **检查实际识别和对齐环境**
  （操作）在具备对应条件的机器上，用指定 FFmpeg 对多音轨录音对齐，并用自动设备运行 Faster-Whisper；若安装依赖失败，在设置中复制报告。
  （预期）对齐使用指定工具和选定音轨；自动模式遇到缺 CUDA 运行库时改用 CPU，输出中没有重复片段。报告可定位失败原因且不会显示认证信息。
  <!-- id: runtime -->

- [ ] **拖动缩略图并跳出试听区间**
  （操作）对较长视频打开缩略图，开始生成时切换媒体；试听一句后在波形或字幕表跳转到另一处。
  （预期）显示新视频的画面，旧任务不覆盖新状态，跳转后也不会在旧试听终点停止。
  <!-- id: filmstrip -->
