## 验证证据与边界

- 工具箱从公开入口读入合成工程，核对 MOSP、SRT、输入原件和保存取消。真实 Windows WebView2 子窗接收 Launcher 快照，并通过测试选址另存，读回 v2 主轨正确。原生保存对话框的人手选址及非 Windows 桌面仍待人工核验。
- Windows 的对齐 worker 在空 PATH 下调用指定 FFmpeg 和 FFprobe，识别第二条默认音轨并输出 500 毫秒 PCM。74 项组合中 47 项通过、27 项跳过。真实云模型返回、真实缺库显卡和用户录音的人工听校另验。
- 半透明底框、逐字换色由真实 libass 渲染；Chromium 覆盖样式库导入往返、三轨开关、手动定位、结果链和对照窗。浏览器保存用底层真实编码和可读 MP4 验证。原生烧录与媒体任务组合 60 项中 57 项通过、3 项跳过。原生覆盖目标在发布前复核身份；外部进程在最后检查与系统替换之间的并发修改仍受平台文件接口限制。
- 早期缩略图 E2E 的 FFmpeg 子进程查询受本机沙箱限制，单项在可查询的环境中复验通过。通用编辑器组合首次因默认 Python 子进程启动超时，显式指定已锁定的解释器后 407 项通过。媒体任务进度测试两次在 0.3 秒观察窗口内未取得样本，改为真实子进程等待测试端确认后退出。
- 提交 `68cbe31c` 的准入检查通过。辅助巡检检出了工具数量、标题选择器和跨平台根目录夹具三类问题；`a8d0dfab` 调整对应验收。本机 3 项 Chromium 与 9 项 Python 通过。各次 CI 只对应其运行的提交，当前状态见 [#431 检查](https://github.com/Moyf/moys-asr-workflow/pull/431/checks)。
