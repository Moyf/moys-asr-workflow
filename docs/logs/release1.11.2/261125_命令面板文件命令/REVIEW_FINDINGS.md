# 2.0 命令面板文件命令修复

基线 `2.0dev@3cf512a2`。1.x [PR #457](https://github.com/Moyf/moys-asr-workflow/pull/457) 发现新建、打开和导入调用 DOM 点击，返回值无法区分取消与实际完成。2.0 同样复现：旧实现取消「打开工程」后仍写入最近使用。

2.0 使用显式 ESM 装配共享文件选择器适配；保留 2.0 的工程、迁移与保存语义，不移植 1.x Launcher 原生接线。选择器未打开时不记录历史，普通工具栏保留可重试路径。

本地最终 Chromium 18/18、Node 17/17，类型、bundle 新鲜度、文档和发布说明检查通过。Chromium 最终运行覆盖命令面板、工程接管和 v2 迁移保存；较早并行批次有一次浏览器启动超时，同一用例在最终批次通过。选择器取消、拒开使用浏览器事件或模拟接口；真实系统对话框和跨平台交互未人工验证。旧浏览器若静默忽略传统点击且不发事件，普通工具栏重试会释放等待，不把之后的工具栏操作误记为面板历史。

独立复核发现并修复两个边界：新的显式选择会结算旧的未处理等待，而不会打断已开始的导入；关联媒体和副字幕也经过共享 input 管理，不会误认领旧面板请求。补上经面板打开后 Server 接管、重载、历史与保存目标的直接覆盖。旧代码 1 条 Node、2 条 Chromium 新回归均按预期失败；最终 Node 17/17、Chromium 主批 21/21、副字幕入口 2/2，类型和 bundle 新鲜度通过。
