范围：基于 PR 373 的 `2e2e79be`，检查保存入口、文本焦点、2.0 迁移与自动化证据。

| 发现 | 处理 |
| --- | --- |
| 另存为等待写流时，用户可能开始新的波形拖动；序列化前再次提交面板会覆盖预览。 | 已修复：构建文件前再次结束当前拖动；单测覆盖写流等待期间开始的新拖动。 |
| 服务器保存失败后，确认导出恢复副本时可能遇到期间新开始的拖动。 | 已修复：确认导出后先结束拖动；单测检查首次构建、结束拖动和恢复副本构建的顺序。 |
| 自动保存定向测试共享工程，重复内容可能没有真正的待存改动。 | 已修复：每个用例使用不同的先前编辑，并检查写盘后重开。 |
| 拖动期间每次延期重试都计算整份 v2 工程指纹，长工程可能产生额外开销。 | 已处理：防抖回调先检查拖动状态；结束后再判脏。浏览器测试检查拖动期间不读取工程快照。 |
