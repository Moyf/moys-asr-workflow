# PR 349 工程样式与字体核验

> 使用真实工程的副本。目标分支为 2.0dev，候选合入 6589c283。

## 本轮行为与验证
<!-- id: evidence -->

轨道样式、单句覆盖和字体替换随工程保存。实际帧、ASS 导出、图片字幕和编辑器 ASS 烧录复用字形覆盖。

浏览器已覆盖样式联动、库读取失败、字体替换撤销、保存重开和说话人颜色。真实字体安装及目标播放器显示由下列步骤核验。详见[复核记录](REVIEW_FINDINGS.md)。

## 真实工程
<!-- id: real-project -->

- [ ] **字体安装后重查，替换可撤销并随工程保存**
  （操作）打开指定了本机缺失字体的工程副本。安装该字体后点击「重新检查」。再对另一处缺失字体执行统一替换、撤销、重做、保存并重开。
  （预期）重查识别新安装的字体。替换和撤销同步更新预览、轨道和单句引用，重开后保留保存时的字体。
  <!-- id: refresh-and-reopen -->

- [ ] **轨道样式联动，单句覆盖和说话人颜色同时生效**
  （操作）给主轨、副轨和叠加轨选不同样式。给一条字幕设置单句样式。更改一个已联动的库样式，保存并重开。开启说话人前缀，查看预览并导出 ASS。
  （预期）已联动轨道随库更新，独立样式和单句覆盖保留。预览与导出中的说话人前缀采用对应身份颜色。
  <!-- id: styles-and-speaker-colors -->

- [ ] **实际帧和烧录成片中的主字幕与叠加字幕均可读**
  （操作）选用主字幕自动折行、叠加字幕更早出现且带单句样式的一段真实素材。比较编辑器实际帧、导出的 ASS 和直接工程烧录的成片。在另一台目标机器打开 ASS 时确认其字体。
  （预期）两层同时出现时各自可见，直接工程烧录的主字幕居下。目标机器中的普通文字可读，字体回退符合当地安装情况。
  （说明）直接工程烧录使用默认主轨与叠加轨组合。显式选副轨的输出另行验收。
  <!-- id: burn-output -->
