- [ ] **原工程字幕 16 与 17 合并后可以保存并重新打开**
  （操作）在本分支 localhost 编辑器打开原工程副本，选中字幕 16 与 17，按 C 合并；保存副本后重新打开。
  （预期）不出现 color_ref.headIdx 保存失败；合并文字正确，后续副字幕颜色仍对应原字幕。
  （说明）优先核对原报错附近的绿、黄、红色组；不要用旧发布包或便携 HTML 验收本分支修复。
  <!-- id: original-merge-save -->

- [ ] **直接合并同组副字幕保留颜色且撤销可恢复**
  （操作）选中连续的同一颜色组副字幕，右键选择“合并副字幕块”；撤销一次，再重做一次，保存副本并重新打开。
  （预期）合并结果保留原颜色；撤销恢复原段数与颜色，重做恢复合并结果，保存及重开无引用错误。
  <!-- id: extension-same-group -->

- [ ] **混合颜色组合并不破坏外部幸存成员**
  （操作）在副本选择跨两个颜色组的连续副字幕合并，观察未选中的组成员；叠加轨存在颜色或表情包组时也做一次跨组合并，再撤销。
  （预期）混合组的合并结果不继承组标记，未选中成员仍显示原标记；保存无引用错误，撤销完整恢复原组布局。
  <!-- id: mixed-groups -->

- [ ] **副轨新增和删除不会使后续颜色组错位**
  （操作）在已有颜色组之前的副轨空白处新增一句，保存；删除一条副轨颜色 head 或删除与其绑定的主字幕，再保存并重新打开。
  （预期）新增后原组颜色不变；删除后幸存组成员保留颜色且保存成功，颜色不串到相邻字幕。
  <!-- id: insert-delete -->

- [ ] **关闭双字幕后主轨仍能合并和保存**
  （操作）关闭副字幕轨，选中两句连续主字幕按 C 合并，保存副本并重新打开。
  （预期）主轨合并正常，不发生空副轨访问报错；关闭的副轨保留原段数与颜色，不被意外联动合并。
