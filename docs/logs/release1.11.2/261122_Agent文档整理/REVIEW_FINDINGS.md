# 2.0dev Agent 文档整理自审

审查基线为 `2.0dev@6589c283`。检查根规则、技能、开发与调试入口、交接状态和 GitHub 操作范围。

| 发现 | 处置 |
| --- | --- |
| 共享工作树里的普通提交可能带入其他会话已暂存的文件。 | 在根协作规则保留暂存检查、按本次路径提交和保留他人暂存内容。 |
| 根文件把字幕流程统称为公开 CLI，非首轨仍需源码模块入口。 | 根文件指向字幕技能，由技能说明具体分流。 |
| 1.x 人工生成便携编辑器的例外容易被读成适用于 2.0。 | 将维护者要求和发布检查两种情形都限定在 1.x。 |
| 仅检查旧必需状态会漏掉尚未设置新准入检查的情况。 | 明确由维护者核对必需检查及旧状态，Actions 成功单独记录。 |

官网文档同步会将普通仓库链接改写到 main。两份旧排障页在索引中使用原始提交的固定链接，保留事故经过与验证证据。此次为文档更新，原有人工验收项继续按各自清单追踪。
