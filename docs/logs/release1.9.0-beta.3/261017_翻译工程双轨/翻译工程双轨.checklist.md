# 翻译工程双轨核对

> 工具箱、自动后处理中间与最终工程、译文核对下载；自动化通过与人工验收分开记录。

## 实现与审查结论
<!-- id: implementation -->

普通翻译与双语合并始终读取主轨原文，完整校验后覆盖编辑器固定副轨，没有才创建；不增加译文轨。主轨文字、词时间、样式和其他属性保留，对应主段的绑定 ID 保留并更新译文映射。失败、取消或任一翻译批次失败都不替换旧副轨；合并仅影响 SRT。回填仍按原模式替换少量主字幕。

## 修复与提交记录
<!-- id: changes -->

开发基线 `3fa96ed4`，提交 PR 前对齐 main `af141848`，实现分支 `fix/translation-editable-tracks`。实现、用户指南与 CHANGELOG 随本次修复提交。现有单轨产物不会自动改写；需要重新处理原工程。工具箱与自动链的双语合并开关仍各自独立，未在本次更改同步规则。

本轮 Windows 全套 2532 项通过，23 项因缺少可选依赖、真实夹具或平台条件跳过；严格包装契约 30 项、相关 Python 266 项和 Node 6 项通过。实际浏览器验证核对页下载，以及固定副轨预览、保存为文件后在新服务重开、双语 SRT 导出。构建、新鲜度、类型检查和 Ruff 通过；实际 Windows 包与冒烟证据见同目录修复记录。

初版完整套件的沙箱网络拒绝和原生异常仍作为历史记录保留，不宣称已定位原生异常根因；本轮通过临时诊断入口保留原生退出码并禁止系统崩溃弹窗，最终完整结束。未调用实际翻译 API，维护者真实日语工程仍待人工确认。

## 人工核验
<!-- id: manual -->

- [ ] **日语翻译后的所有工程可分别编辑原文与译文**
  （操作）用原始日语工程运行翻译成中文，勾选双语合并和保留中间产物；分别打开翻译阶段、双语合并阶段与最终 MOSP。
  （预期）主字幕为日语，副字幕为中文；两轨可分别编辑，原文字词时间码仍在。配套最终 SRT 包含中日两行。
  <!-- id: japanese-projects -->

- [ ] **合并行序只影响交付 SRT**
  （操作）分别选择译文在上、原文在上重新处理；打开 MOSP，再从编辑器导出双语合一 SRT。
  （预期）两次 MOSP 都是原文主轨加译文副轨；自动链配套 SRT 行序符合选择，编辑器仍可按其导出设置生成合并字幕。
  <!-- id: srt-order -->

- [ ] **译文核对下载保留双轨**
  （操作）处理时启用对比结果，在核对页修改一条译文，下载核对后 MOSP 并用编辑器打开。
  （预期）修改只出现在译文副轨，原文主轨和字词时间码保持；已有副轨、绑定和元数据保留。
  <!-- id: review-download -->

- [ ] **普通翻译与少量回填保持各自用途**
  （操作）不勾双语合并做一次普通翻译，再用包含少量外文的工程运行回填。
  （预期）普通翻译 MOSP 为双轨；实际回填仍把少量外文替换成译文，其他原文与字词时间码保留。
  <!-- id: translation-modes -->

- [ ] **再次翻译覆盖副轨且没有旧行残留**
  （操作）打开已有副轨的 MOSP，把旧副轨临时增添一条明显的旧字幕，再分别用工具箱和自动后处理重新翻译。
  （预期）输入为主轨原文；成功后轨道数不增加，副轨完整替换为新译文，无多余旧行；主轨文字、字词时间码和样式保持。
  <!-- id: overwrite-existing -->

- [ ] **失败或取消保留旧副轨**
  （操作）保留一份已有译文的工程，模拟翻译请求失败或在请求中取消；检查原工程及自动链继续使用的工程。
  （预期）原副轨保持，不提前清空，也不把部分新译文与旧译文混合写出。
  <!-- id: failure-preserves-secondary -->

- [ ] **保存重开后的预览与导出使用新译文**
  （操作）翻译成功后保存 MOSP，重新打开，查看首条副字幕预览并导出双语 SRT。
  （预期）预览与 SRT 都使用新译文；MOSP 内原文与译文分别保存，绑定 ID 及主轨词时间保持有效。
  <!-- id: reopen-export -->
