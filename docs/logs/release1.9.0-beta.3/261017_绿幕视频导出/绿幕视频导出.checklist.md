## 实现与审查结论
<!-- id: implementation -->

编辑器「更多导出 → 生成绿幕视频」支持关联源媒体的音频、视频工程，不要求开启 ASS 预览。沿用当前 ASS 字幕与视频任务生命周期，保留停止、切换媒体取消与流式保存。

全局设置「更多导出 → 绿幕视频导出」提供默认关闭的「附带音轨」，保存为本机偏好。输出 1080P / 30 fps；画面结束于最后字幕后半秒，附带音轨不会延长画面。编辑器使用源媒体选定音轨，没有该轨时静音。

Launcher 工具箱勾选绿幕后，右侧显示默认不勾选的「附带音轨」。音轨来自所选源媒体；默认静音绿幕仍无需媒体源。自动后处理保持默认静音。

## 人工核验
<!-- id: manual -->

- [ ] **音频与视频均可生成静音绿幕视频**
  （操作）分别从 Launcher 打开音频、视频工程，在「更多导出」点击「生成绿幕视频」并选择保存位置。
  （预期）均输出绿色背景 MP4，字幕样式与当前 ASS 导出一致，默认没有音轨；不要求打开 ASS 预览开关。
  <!-- id: manual-silent -->

- [ ] **编辑器附带音轨与设置保存**
  （操作）全局设置 → 更多导出 → 绿幕视频导出，勾选「附带音轨」，导出后重开编辑器。
  （预期）输出含选定源音轨，画面到最后字幕后半秒结束；勾选偏好保留。源文件无音轨时仍可导出静音绿幕。
  <!-- id: manual-editor-audio -->

- [ ] **Launcher 按需显示附带音轨**
  （操作）工具箱 → 烧录字幕，勾选「生成绿幕视频」，先默认导出，再选择音频或视频源、勾选右侧「附带音轨」并导出。
  （预期）选项默认关闭；静音模式无需媒体源，带音轨模式使用选择的媒体；尺寸选项仍可用，相关控件与提示间距至少 8px。
  <!-- id: manual-launcher-audio -->

- [ ] **导出停止与绑定失效恢复**
  （操作）长字幕工程发起绿幕导出后点击停止，随后重试；再测试导出期间切换媒体。
  （预期）停止后可以重试，切换媒体后旧任务取消，不保存混合旧字幕与新媒体的结果。
