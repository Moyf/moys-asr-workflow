# 工程音量与响度人工核验

> 覆盖固定增益预览、响度归一化、工程保存及烧录；自动化证据与人工验收分别记录。

## 实现范围
<!-- id: implementation -->

📣 面板提供工程固定增益、原始整段 LUFS、调后预计响度与真峰值、参考目标及归一化。工程增益用于预览和三条烧录路径；监听音量只影响试听。没有加入压缩或限幅。

## 自动化验证
<!-- id: automation -->

具体命令与结果见同目录设计与验证记录。自动化包括已知音频增幅、静音/无音轨、缓存/过期结果、参数验证、真实双音轨烧录与浏览器音频路由；仍需完成以下人工听感和原生操作核验。

## 人工核验
<!-- id: manual -->

- [ ] **预览增益与监听音量分别生效**
  （操作）打开有声音的视频，播放并展开 📣；比较 0、−6、+6 dB，再改变监听音量。
  （预期）声音按增益整体变化，进度与画面保持同步，反复打开面板没有叠加音量；监听音量不改工程增益。
  <!-- id: preview -->

- [ ] **归一化与峰值限制说明清楚**
  （操作）测量较安静的素材并按 −23 LUFS 归一化，再对动态较大的素材选 −14 LUFS；测试纯静音与无音轨视频。
  （预期）显示原始及预计 LUFS；峰值余量不足时说明未达目标，静音或无音轨不启用归一化；手动超峰值有提示。
  <!-- id: normalization -->

- [ ] **保存、撤销和换工程**
  （操作）调整增益，撤销/重做，保存并重新打开；分析中切换另一个工程，再导入本地媒体。
  （预期）工程保存增益与参考，旧工程缺参数时归零，切换后不显示上个媒体的测量；本地替换不误测旧服务器媒体。
  <!-- id: persistence -->

- [ ] **原生保存后对比成片**
  （操作）用相同工程增益分别导出整段、去空隙、带音轨绿幕视频；另调监听音量后再次烧录。多音轨素材逐轨播放。
  （预期）工程增益生效且只应用一次；监听音量不改变成片，原音轨与字幕/表情包时序保留。去空隙与编码后以成片实测为准。
  <!-- id: exports -->

- [ ] **目标设备与键盘操作**
  （操作）在日常使用的浏览器或桌面 WebView 中用键盘打开面板、调滑块、选择参考、Esc 关闭，并试听耳机/扬声器输出。
  （预期）焦点与控件可操作；不支持的增益预览有明确说明，媒体仍可原生播放；无意外静音或重复音路。
  <!-- id: platform -->
