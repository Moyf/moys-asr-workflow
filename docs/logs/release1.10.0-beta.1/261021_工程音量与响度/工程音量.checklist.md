# 工程音量与响度人工核验

> 覆盖固定增益预览、响度归一化、工程保存及烧录；自动化证据与人工验收分别记录。

## 实现范围
<!-- id: implementation -->

📣 可移动窗口提供工程固定增益、2×2 响度指标、预设或自定义参考及响度匹配。工程增益用于预览和三条烧录路径；监听音量只影响试听。没有加入压缩或限幅。

## 修复与提交记录
<!-- id: fixes -->

本轮依据维护者反馈改为非模态浮窗，参考默认 −14 LUFS，支持自定义目标、常规与扩大增益范围、监听百分比及精简布局；同时补齐 Python 脚本清单契约遗漏。处理状态、验证与提交记录见同目录 TEST_FEEDBACK_工程音量.md。保持 Draft，暂不合并。

<!-- id: automation -->

原实现的命令与结果见同目录设计与验证记录，本轮以 TEST_FEEDBACK_工程音量.md 记录为准。自动化包括已知音频增幅、静音/无音轨、缓存/过期结果、参数验证、真实双音轨烧录与浏览器音频路由；远端工作流须绑定修复后提交重新确认，不能沿用此前红灯之前的局部通过结果。仍需完成以下人工听感和原生操作核验。

## 人工核验
<!-- id: manual -->

- [ ] **预览增益与监听音量分别生效**
  （操作）打开有声音的视频，播放并展开 📣；比较 0、−6、+6 dB，再改变监听音量。
  （预期）声音按增益整体变化，进度与画面保持同步，反复打开面板没有叠加音量；监听音量不改工程增益。
  <!-- id: preview -->

- [ ] **归一化与峰值限制说明清楚**
  （操作）测量较安静的素材并匹配到 −23 LUFS，再对动态较大的素材选 −14 LUFS；测试纯静音与无音轨视频。
  （预期）显示原始及预计 LUFS；峰值余量不足时说明未达目标，静音或无音轨不启用匹配；手动超峰值有提示。
  <!-- id: normalization -->

- [ ] **保存、撤销和换工程**
  （操作）调整增益，撤销/重做，保存并重新打开；分析中切换另一个工程，再导入本地媒体。
  （预期）工程保存增益与参考，旧工程缺参数时归零，切换后不显示上个媒体的测量；本地替换不误测旧服务器媒体。
  <!-- id: persistence -->

- [ ] **原生保存后对比成片**
  （操作）用相同工程增益分别导出整段、去空隙、带音轨绿幕视频；另调监听音量后再次烧录。多音轨素材逐轨播放。
  （预期）工程增益生效且只应用一次；监听音量不改变成片，原音轨与字幕/表情包时序保留。去空隙与编码后以成片实测为准。
  <!-- id: exports -->

- [ ] **目标设备与键盘操作**
  （操作）在日常使用的浏览器或桌面 WebView 中用键盘打开面板、调滑块、选择参考、Esc 关闭，并试听耳机/扬声器输出。
  （预期）焦点与控件可操作；不支持的增益预览有明确说明，媒体仍可原生播放；无意外静音或重复音路。
  <!-- id: platform -->

- [ ] **浮窗持续可见且可移动**
  （操作）打开 📣 并拖到另一位置，在窗口外播放、暂停、定位媒体；缩小浏览器窗口，再用关闭按钮或 Esc 关闭。
  （预期）窗口保持可见，位置可调整，缩窗后控件仍可操作；关闭后焦点回到入口，不留下拖动状态。
  <!-- id: floating-window -->

- [ ] **自定义参考和默认值可保存恢复**
  （操作）新建工程确认默认 −14，切换三种预设与自定义 −18.5 LUFS，执行匹配、撤销和重做，保存重开；另打开已有 −23 参考的工程。
  （预期）自定义值和差值保持一致，保存重开与撤销重做不丢失；已有 −23 参考保留，缺字段工程才使用新默认值。
  <!-- id: custom-reference -->

- [ ] **常规范围与扩大范围不暗改工程值**
  （操作）在常规滑块使用 Home/End，勾选扩大范围再操作；载入 +18 dB 或 −20 dB 工程，检查扩大范围开关，再重置为常规值并取消扩展，随后撤销或匹配到范围外值。
  （预期）常规端点 −6/+12，扩大后 −60/+24；范围外值自动展开并提示，暂不允许收起，回到常规值后可取消；切换范围不暗中改变实际音量或制造工程变更。
  <!-- id: gain-range -->

- [ ] **信息布局与监听百分比清晰**
  （操作）调整监听音量并通过播放器改变音量；观察测量中的提示、四项指标和按钮；切换英文并缩小窗口。
  （预期）百分比随音量同步；测量中黄字，指标按 2×2 胶囊展示；左侧重新测量和橙色匹配按钮，重置独立靠右；两行说明无重复，控件无溢出或被挡提示，相邻区块实际间距至少 8px。
  <!-- id: information-layout -->
