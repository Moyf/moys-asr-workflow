# ASS 斜体字形边缘修复

Canvas 的文字排版宽度不包含全部斜体字形墨迹。原先行位图固定只留描边、阴影及额外两像素边距，较大字号、行末带右侧外伸笔画时会裁剪字形。此次使用既有测量器返回的 inkPadding 为位图补足边距，不改变排版位置或 libass 导出。

修复从独立产品补丁抽取，另让 raster 单测的模拟文字度量随当前 CSS 字号变化。没有引入像素 oracle 降本、字体 TTC 解析或其他 PR 的修改。

## 真实回归与边界

原有四项静态/斜体真实像素用例在修复后通过，但旧实现的原行内斜体用例也通过，不能用它证明原故障已检出。新增一个主/副轨 `//ffff//`、字号 240/180 的夹具，使用原有真实 Canvas 捕获、FFmpeg/libass oracle 与三像素边界断言；编辑器字号输入明确支持 1–512，两个字号都在支持范围内。

仅将 Canvas 实现还原为主线固定两像素边距后，该新增用例的主轨右边界差为 17 像素、副轨为 12 像素，均超过原三像素阈值；恢复修复后通过。它证明的是上述外伸笔画工况，不表示全部斜体曾经裁剪。

本地检查包括五项原 oracle 像素场景（四项既有、一项新增）、五项 raster 回归、TypeScript、编辑器构建及新鲜度。未修改 oracle、放宽阈值或加入重试；本轮未遇到 TTC 或机器字体断言失败。

环境边界：只读复用同锁 Node 依赖及 Python 开发环境；Node 24.19.0 低于当前 engine 要求，本地结果不能替代合规环境 CI。真实用户人工验收仍待完成，内联副本待发布前统一重生成。本分支仅本地提交，不推送、不创建 PR。
