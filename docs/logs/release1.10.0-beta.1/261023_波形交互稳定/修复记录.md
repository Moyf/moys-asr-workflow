# 波形交互稳定修复

缩略图控制器会在绑定和状态变化时通知布局更新；音频媒体及同高度状态变化并不需要重建波形行。此前仍调用完整 render，会替换已经显示的行、Canvas 和交互节点。现在避免状态刷新替换正在交互的波形节点；直接回归证明原重建路径存在，不把它扩写为每次选中、拖动或删除都会中断。

现在仅在缩略图实际高度变化时重建，并按旧行距记录、新行距恢复滚动锚点；同高度通知只刷新现有行中的缩略图。保留 PR 298 的自动保存隔离，避免删除场景重载时读到上一个场景已保存的工程。

直接回归独立验证音频/同高度通知不安排重建、真实高度增加和减少时恢复滚动锚点。将条件改回旧的无条件布局重建后，该回归在首个“不得破坏波形行”断言失败，证明它能检出原故障；该实验不依赖浏览器布局等待 helper。

本批删除、框选和几何消费者使用音频夹具，产品修复后不发生真实缩略图高度切换，因此不引入等待 helper 或扩大到无关测试初始化改造。视频缩略图真实增高/收起的锚点由直接回归覆盖，真实视频人工交互验收仍待维护者完成。

本地验证通过：编辑器重建及新鲜度、TypeScript 检查、90 项 Node 回归；Chromium 下 localhost / 便携页各五组删除场景、双端框选、横向滚轮保留 Canvas、Q 模式切换重绘次数，以及空隙点击、Ctrl 拖动创建、波形拆句撤销重做三项几何消费者。保留原始断言，没有 force 点击、retry 或延长断言超时。

环境边界：Python 只读复用开发验证环境，锁文件只多 test extra，未改变已解析包版本；Node 依赖在本工作树按锁安装。本机 Node 24.19.0 低于仓库要求的 24.22.1，安装工具报 engine 警告；上述结果仅是该本机环境的验证。首次浏览器运行因沙箱默认缓存路径无可执行文件失败，后续显式指定已安装 Chromium 后通过。本地通过不代表远端 CI 或人工验收完成。内联副本待发布前统一重生成。
