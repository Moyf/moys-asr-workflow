- [ ] **整体材质与排版符合审美方向**

- [ ] **手机布局与导航顺手**
  （操作）在真实手机打开首页，切换语言、展开导航，再进入更新页。
  （预期）标题自然换行、触控入口好点、没有页面横向溢出，更新版本条可横向选择。

- [ ] **交互与动效柔和可控**
  （操作）切换工作流与编辑器功能，使用 Tab 和方向键操作，并开启系统减少动态后重试。
  （预期）图文同步，焦点可见；减少动态时无位移与缩放，内容始终可见。
  <!-- id: motion-and-keyboard -->

- [ ] **明暗主题与英文易读**

  （预期）主题记忆正常，两种语言的主按钮与正文清晰，页面间主题一致。

- [ ] **版本索引与真实下载对应**
  （操作）在更新页选择较早版本，复制固定链接重新打开，再进入该版详情与下载。
  （预期）定位到对应版本正文，正文配图不挪位，下载与所选版本和平台匹配；预览不会冒充正式发布。
