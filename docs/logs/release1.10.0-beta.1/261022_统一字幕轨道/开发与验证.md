## 关键行为

- 主、副、叠加字幕共用 `tracks[]`，运行态、历史、恢复和磁盘存档只有一份轨道结构。轨道角色表达现有行为，来源元数据跟随轨道；隐藏语言或禁用轨道不会丢存档内容。
- v1/v2 只在导入边界迁移，v3 严格校验。保留未知字段、合法零时长标点、原媒体时间；错误、未来版本和新旧容器混用在修改当前工程或写文件前拒绝。
- cue ID 全工程唯一；独立绑定和组表引用稳定 ID。主副交换先检查其他语言关系能否全部映射，失败原子拒绝；不会静默删绑定或覆盖原轨颜色 / 表情属性。
- Python ASR、翻译、对齐、后处理、CLI / Server 与浏览器保存、SRT / ASS / FCP 等消费入口使用统一轨道选择。烧录 / FCP 组计划只选择活动、启用成员，同组只输出一次，去空隙映射不改源时间。Resolve / OTIO 的外部逐句贴图协议保持。
- 保存快照包含工程音量等持久设置。保存中继续编辑和迟到 ACK 继续遵守现有检查点、绑定和切换意图规则。

## 复审修复

复审发现并修复旧工程省略 ID 时对旧隐式 ID 的合法绑定、独立字段错误报告聚合、legacy ASS 缩放规范化及原输入错误路径。Python / JS 对相同样例对照，不用旧容器 getter 掩盖问题。重译活动语言保留原目标 cue 的未知属性；导入副字幕保留来源元数据、组值和稳定关系。包装运行目录包含新增格式与修改模块。

原有测试按作用域迁移：旧输入仍保留，canonical 运行 / 保存断言直接读取 tracks；保留文字、时间、颜色、像素容差、撤销和保存并发的原断言。修复测试夹具缺失依赖时使用真实共享工具，未新增跳过或放宽超时。

导出兼容性复审发现内部组表会误触 Resolve v2 协议，以及 OTIO 按整组跨度填满句间空隙。已在导出边界恢复 Resolve v1 和逐启用字幕区间，6 项直接回归、构建 / 新鲜度和类型检查通过；不改变明确使用组区间的烧录 / FCP 计划。普通换轨保留全局组归属的设计已明确写入方案；显式移出组仍有独立拆组语义。

真实浏览器另检出并修复换轨中的未定义变量、显式切组未分开前后成员、组值更新后字幕行缓存未失效。原失败 5 场景全部通过；换轨补充 cue / group ID、未知组属性和两次撤销完整工程相等断言，显式移出组保留原分段范围，行内更新保留 DOM 身份、滚动和像素容差。空副轨保存重开另行通过。纯 selector 迁移保持原始 legacy 输入，修改文件做语法和 Playwright 列表审计；完整 993 项浏览器套件未全跑，分批结果不冒充全浏览器通过。
