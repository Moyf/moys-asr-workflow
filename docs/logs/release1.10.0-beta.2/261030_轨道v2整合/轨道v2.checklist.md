# 轨道 v2 人工核验

> 2.0dev 破坏性格式升级；本页人工项尚未验收，自动化证据见同目录整合记录。

## 实现与自动化
<!-- id: v2-evidence -->

v1/v1.5 可读，保存为 v2 须另存新文件；最多一条副轨。详情见[整合记录](整合记录.md)。样式联动、三态开关和完整说话人功能仍待后续实现。

## 人工操作
<!-- id: v2-manual -->

- [ ] **旧工程迁移保留原文件**
  （操作）备份真实 v1/v1.5 工程；打开并编辑，先取消另存，再另存新文件并重开。
  （预期）原文件内容不变，新文件为 v2，字幕、时间、分组和绑定保持。
  <!-- id: v2-migrate -->
- [ ] **主副交换与撤销保留属性**
  （操作）使用带词时间、说话人和跨轨表情组的工程，交换主副轨，再撤销、重做、保存重开。
  （预期）身份与来源字段跟随原字幕；组和绑定正确，没有重复 ID 或无法保存。
  <!-- id: v2-swap -->
- [ ] **导出在目标软件中可用**
  （操作）分别导出 SRT、ASS、Resolve JSON 和表情 OTIO，在实际目标软件检查区间及素材。
  （预期）文字、颜色和表情符合选择；组连续区间、禁用成员和跨轨开关符合当前约定。
  <!-- id: v2-export -->
- [ ] **原生保存与跨平台包可用**
  （操作）在目标系统安装预览包，使用原生文件选择器打开、取消保存、另存并重新启动。
  （预期）取消不覆盖旧文件，成功后可继续保存新文件；重启可正确恢复。
  <!-- id: v2-package -->
- [ ] **副轨开启时拖动未绑定主字幕**
  （操作）打开副轨，解除一条主字幕的绑定，按住 Alt 连续拖动该主字幕，再撤销、重做。
  （预期）主字幕跟随指针经过完整距离；未绑定副字幕不移动，撤销和重做恢复各自时间。
  <!-- id: v2-unbound-drag -->
- [ ] **修复旧时间码并记住媒体关联**
  （操作）备份带零时长字幕的旧工程，在编辑器打开并作为副字幕导入；再从 Launcher 指定媒体并勾选记住关联。
  （预期）两种导入都成功，时间得到修复；记住关联只更新原文件媒体字段并保留备份，旧时间码不被悄悄改写。
  <!-- id: v2-repair-media -->
- [ ] **重译保留副轨属性并处理空字幕**
  （操作）准备主副轨使用不同颜色、贴纸、ASS 设置、禁用状态和说话人的工程，包含带绑定或独占组的空主字幕；重译并选择双语合并。
  （预期）工程副轨保留自身属性，双语导出成功，原工程及其绑定、分组不受改写。
  <!-- id: v2-translation-attributes -->
- [ ] **说话人颜色跟随口播文稿字幕**
  （操作）对带说话人颜色的原始 ASR 工程完成口播审查，并用对应录音生成文稿字幕。
  （预期）生成成功；来源同组的文稿字幕保留颜色与说话人，原 ASR 工程不变。
  <!-- id: v2-recording-speaker-color -->
- [ ] **AI 处理保留分组边界**
  （操作）准备含相邻同组与不同组字幕的工程，分别设置颜色和贴纸，运行 AI 重新断句及普通校对并打开结果。
  （预期）重新断句按分组边界处理；普通校对若提出跨组合并，受影响字幕原样保留并提示，其余字幕继续处理；原工程不变。
  <!-- id: v2-resegment-groups -->
