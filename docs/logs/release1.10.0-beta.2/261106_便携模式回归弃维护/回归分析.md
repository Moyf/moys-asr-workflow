## 结论边界

**根因未能确认。** 目前没有证据能把所述 CI 失败归因于 Linux `file://` 的 `localStorage` 跨 reload 行为，也没有证据支持 #336 引入了 MAW 源码缺陷，或排除测试竞态与 runner 差异。GitHub Actions 原始日志未能读取：`gh run list` 返回连接 `api.github.com` 失败；Paseo CLI `paseo logs df838d3f --tail 35 --filter text` 因本机 daemon 的 `uv_uptime` 权限错误失败。Paseo agent activity 只提供前 worker 的分析文字，不是可核验的 CI job 输出，故不将其中关于 runner、失败断言或次数的说法作为事实。

本机 macOS Chromium 对相关用例没有复现失败：`editor-text-tools` 整文件为 33 通过、1 跳过（storage reload 用例通过）；`warma-presets` 为 13 通过（多页 stale-save 用例通过）；`editor-bundle` 为 3 通过（两个 file 用例也通过）。这些结果仅说明本机未复现，不能替代 Linux CI 证据。

## 处理决定与测试范围

维护者已决定单 HTML `file://` 形态不再维护并计划在 2.0 移除。现阶段没有可复现的 MAW 源码缺陷可做小修；更改该形态的持久化后端会超出本次轻修范围。因此，仅跳过直接验证便携单 HTML 特有行为的用例，并保留同文件中的 HTTP/server 变体及其它未证明相关的测试。skip reason 统一说明弃维护决定，不把未证实的 Linux `localStorage` 假设写成事实。

本次 skip 清单：

- `tests/e2e/editor-text-tools.spec.mjs`：便携页 fade/SRT 用例；便携预设保存并 reload 用例。
- `tests/e2e/warma-presets.spec.mjs`：便携页多标签 stale-save 用例。
- `tests/e2e/editor-bundle.spec.mjs`：便携注入页用例；参数化传输中的 `file` 变体。`HTTP` 变体保留。

保留边界：同一 editor-text-tools 文件中主要验证 split/speaker 保存的用例仍保留；它验证编辑器功能，file 页面仅用于末尾的工程拖放复开，未证实与预设存储回归相关。用静态 HTTP server 打开便携 HTML 的 parity 用例也保留，因为它们没有 `file://` origin，测试目标是共享编辑器功能。`editor-menu-focus`、`media-controls-layout`、`cue-list-count-layout` 与 `cue-list-action-buttons-layout` 虽用 file 页面，但断言的是通用菜单/布局行为，本次没有 CI 证据把它们与预设存储问题关联，故不跳过。Launcher、检查清单和离线比较页的 `file://` 用法不是 MAWE 便携编辑器，不在本次范围。
