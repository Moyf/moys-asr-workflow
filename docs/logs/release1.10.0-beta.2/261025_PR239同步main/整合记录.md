## 同步后 Windows CI 修复

夹具改为构建独立旧格式工程，经真实 `migrateSubtitleGroups()` 和 `refreshSubtitleGroupViews()` 初始化后再安装。生产代码、63 项用例、像素分类、3px 边界阈值、动画和原时钟断言均不变。
