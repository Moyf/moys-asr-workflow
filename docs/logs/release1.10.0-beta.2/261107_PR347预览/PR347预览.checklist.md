## 人工核验
<!-- id: preview-manual -->
<!-- badge: todo 全部待执行 -->

准备本地服务器版编辑器、工程副本、可用模型配置及一段能听清对白的短媒体。记录供应商、模型、素材长度与结果差异，不在备注写密钥。共享译文或跨轨重名等特殊数据使用专门工程副本，先保存备份。

- [ ] **真实模型建议由用户确认后写入**
  （操作）选中两条字幕 → 右键 AI 功能执行加粗或翻译 → 等任务完成，继续编辑另一句 → 查看建议，只勾选一条应用，再关闭并重开建议窗口。
  （预期）返回结果不自动覆盖字幕或抢走输入；仅勾选项写入，未应用建议及草稿仍可查看；应用后可撤销。
  <!-- id: preview-real-model -->

- [ ] **翻译草稿校验随输入更新**
  （操作）对含已有译文的多句工程取得翻译建议 → 查看全部建议 → 将一条建议清空，再填写不同译文；将另一条改回已有译文；只勾选有效改动应用。
  （预期）已有译文默认不勾选；空白和无变化项不可应用，填写有效译文后可重新选择；输入焦点和草稿保留，写入的是编辑后的内容。
  <!-- id: preview-translation-draft -->

- [ ] **共享译文和已占用区间受到保护**
  （操作）使用两条主字幕共享同一译文、另有独立副字幕占用主句时间范围的工程副本 → 请求翻译 → 查看相关建议并尝试选择应用。
  （预期）共享目标不被单句译文覆盖，已占用区间不新增重叠译文；冲突原因可见，建议仍可复制，原字幕与绑定保持不变。
  <!-- id: preview-shared-overlap -->

- [ ] **新增译文保存重开后仍正确绑定**
  （操作）在含主轨、副轨和叠加轨的工程中分批应用两条新译文 → 保存为副本并重开 → 检查对应原句、译文及轨道，再撤销或重新应用核对。
  （预期）译文各自绑定到原句，未串轨、丢句或替换其他轨字幕；工程保存校验不报告新增重复 ID。
  （说明）跨轨 ID 冲突的直接覆盖以定向自动化为准；此项检查保存及重开的实际用户结果。
  <!-- id: preview-id-roundtrip -->

- [ ] **联动拆分取消及确认使用当前字幕**
  （操作）对一对已绑定双语字幕请求拆分建议 → 应用以打开联动窗口 → 取消，再查看并应用原建议 → 检查两侧断点后确认，随后撤销。
  （预期）取消保留原字幕、绑定及建议；确认后两轨和绑定一起拆分，仅在实际提交后移除该建议；撤销恢复原结构。
  <!-- id: preview-linked-split -->

- [ ] **过期联动窗口不消费后来建议**
  （操作）打开 AI 联动拆分窗口后，通过当前编辑流程可用的撤销或工程切换改变原字幕 → 再确认旧窗口；随后查看保留建议，丢弃后发起新任务。
  （预期）旧断点不写入已变化字幕，提示重新检查；旧回调不移除新任务的建议，待处理结果不会被新任务静默替换。
  （说明）若当前界面阻止窗口外编辑，记录实际限制；该二次校验场景由定向浏览器回归补充覆盖，不绕过界面伪称人工通过。
  <!-- id: preview-pending-identity -->

- [ ] **替换真实媒体后拒绝旧源对齐结果**
  （操作）通过服务器打开短媒体并选中一句启动字词对齐 → 任务返回前在编辑器本地替换另一段媒体 → 等待结果并再次检查 AI 对齐入口；再通过服务器重新打开正确媒体重做对齐。
  （预期）替换后旧结果不回写，也不能继续提交旧服务器源；重新建立正确媒体来源后才可对齐。
  <!-- id: preview-media-replacement -->

- [ ] **真实对齐结果可试听并正确保存**
  （操作）对真实短媒体的两句对白执行字词对齐 → 查看字词及时间建议，仅应用一句 → 逐词试听边界 → 保存副本后重开并撤销、重做。
  （预期）时间位于对应字幕区间，词序和文字匹配对白，无错句写回；未选句保留原结果，重开与撤销、重做后的时间及绑定一致。
  （说明）记录偏移、漏词或不合理边界；接口模拟通过不能替代此项质量判断。
