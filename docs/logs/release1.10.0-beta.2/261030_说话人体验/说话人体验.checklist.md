# v2 完整说话人体验 · 人工核验

> 基于 #15 身份核心；#40 集中交付界面、九色、ASR 接线和呈现。自动化与人工结果分开记录。

## 交付边界
<!-- id: speaker-scope -->

身份契约、迁移、重映射、保存与合并守卫属于 #15；本 PR 使用同一身份模型。普通分类色与说话人色独立，工程内同名同色人物不会自动合并。Python 基础 ASS 沿用主轨与叠加轨范围，完整多轨导出使用编辑器现有入口。

## 人工核验
<!-- id: speaker-manual -->
<!-- badge: todo 待人工核验 -->

- [ ] **身份管理与一次撤销**
  （操作）工程设置 → 颜色与说话人：开启说话人用途，选中字幕后使用空槽；改名、换色、调整快捷槽位，合并两个人，再逐步撤销与重做。
  （预期）空槽创建和分配一次撤销；改名换色不换人；显式合并更新字幕与槽位，撤销完整恢复。
  <!-- id: speaker-commands -->

- [ ] **三轨目标与用途隔离**
  （操作）在主、副、叠加轨分别分配身份；切普通颜色用途标色并按 0，再切说话人用途按 0；取消副轨选择后按数字键。
  （预期）只改当前明确选中的字幕；普通用途保留身份，说话人用途保留分类色；无目标不会创建人物或误改联动轨。
  <!-- id: speaker-track-targets -->

- [ ] **九色收起与 ASR 人数**
  （操作）使用含 0、1、5、6、9、10 位说话人的合成结果或实际素材，检查自动色数；使用扩展色后收起九色，保存重开。
  （预期）六人起自动九色，十人仍有十个身份；重复和空 ID 不误计数；收起后身份、扩展色、槽位和其他开关不丢失。
  <!-- id: speaker-nine-colors -->

- [ ] **同名同色筛选与未分配**
  （操作）创建同名同色的两个人，分别给三轨字幕分配；在列表筛选每个人和未分配，使用右键选择此人在当前轨道的字幕。
  （预期）按身份分别筛选，灰色与未分配可区分；列表、面板和右键显示一致，选择范围与菜单文案一致。
  <!-- id: speaker-filter -->

- [ ] **预览、导出与自定义色**
  （操作）分别切换预览姓名、导出姓名和标记用途；为人物设扩展色和自定义 HEX，切换 CSS／ASS 预览，导出 SRT、TXT、ASS 和时间轴格式。
  （预期）每个开关独立；同一字幕的姓名一致，未分配无旧人名；颜色不因收起九色或切换预览而丢失。无颜色表达能力的格式保留其既有边界。
  <!-- id: speaker-exports -->

- [ ] **窄窗、明暗主题与真实保存**
  （操作）在窄窗和明暗主题中打开管理区与九色菜单，使用长人名；用真实旧工程另存升级、编辑后保存重开。
  （预期）色槽保持单行并可横向滚动，控件间距清楚；身份色可辨，人物名称不撑破布局；原文件和已有字幕内容得到保留。
  <!-- id: speaker-layout-save -->
