# PR347 对齐语言与任务恢复独立自审

基于 PR head `c989d131`。独立审查者审查实现与测试后提出：

1. 英文界面的断线提示混用中文任务名，且界面语言切换后未刷新。已翻译任务名并在语言变化时重新绘制；定向测试覆盖两种语言。
2. 查询请求无响应时原方案无法进入有限重试。已限制单个在途查询，10 秒无响应后中止并进入重试；测试覆盖超时、无并发查询和迟到响应。
