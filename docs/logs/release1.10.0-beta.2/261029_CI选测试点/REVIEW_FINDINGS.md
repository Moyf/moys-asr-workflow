# CI 选测试点独立复核

基线：上游 main `7e463fb4`。该草案只识别文档／网站试点，未移植 PR 2 的媒体、长媒体、浏览器叶子映射或四片汇总。

## 发现与处置

1. 网站发布页面、文档副本和图片可能在同步或生成时被覆盖。若直接把这些路径判为轻量，网站构建可能未验证 PR 修改。已将受生成器拥有的目录排除；变更这些文件回退完整门禁。
2. 既有门禁增加 `needs: selection` 后，选择任务失败可能使原门禁跳过。已让原门禁总是启动，选择任务失败或输出不是明确的 `true` / `false` 时显式失败。
3. Windows 预览成功评论原先只读取 workflow 结论；轻量 PR 若跳过构建会误报生成了测试包。现按当前 run 的构建及上传步骤区分跳过、成功与失败，并声明 Actions 只读权限。

## 验证边界

本机使用真实 Git 合并、混合修改、错误基线、push 和重命名场景验证选测回退；官网同步、发布预览和构建，以及既有文档测试另行记录在 PR。选测所用 merge ref 和 required check 的托管行为需要 GitHub 实际运行确认；目标仓库分支保护设置未修改或核验。

`workflow_run` 使用默认分支的评论工作流；草案分支的 CI 不能证明修改后的评论逻辑已经在线执行。合并前评论仍可能由默认分支旧逻辑产生，需在实际启用后核验。历史耗时不作为本次提速证据。
