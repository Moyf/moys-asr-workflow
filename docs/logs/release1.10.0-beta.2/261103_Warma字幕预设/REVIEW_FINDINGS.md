# 独立复核与处理

以 `ca4eb54a` 为开发基线。Terra 和 Sol 独立追踪代码并交叉讨论；以下结论不代表已完成人工素材验收。

| 发现 | 处理 |
| --- | --- |
| 非法 `operations.wraps` 可导入，切换时抛错并保留旧预览 | 前后端校验包裹规则，切换预设前使旧预览失效；定向测试覆盖非法导入 |
| 便携页面顺序保存可覆盖另一页面的预设 | 保存时比较打开时的库，并在支持时通过 Web Locks 串行化；冲突提示重新打开 |
| 普通模式可加载含隐藏 ASS 包裹的预设 | 按内置样式 ID 判断，提示先开启 ASS 模式，保留原预设 |
| 删除整句后空字幕影响 ASS 排版及 SRT 再导入 | 保留工程行，ASS 与 SRT 输出跳过空字幕；首句对齐选择非空字幕 |
| 异步加载期间可选择旧预设，排队保存时库快照可能被后续加载替换 | 加载和保存时禁用库控件并忽略过期请求；保存固定预期快照，重开后不会把新表单标记为旧预设 |

不同 Server 进程并发写入同一预设库不具跨进程原子比较写入；常规同一 Server 多页面及支持 Web Locks 的同源便携页面有冲突保护。工具箱直接读取工程烧录仍沿用基础样式，与编辑器内 ASS 烧录区分。

复核者用独立纯函数验证：空主句与无主句时叠加字幕 ASS 输出相同；首个非空字幕对齐到 0。便携写锁延迟并跨页修改、保存期间重开以及 GET 逆序返回的受控复现均符合预期。核心回归在基线失败、当前实现通过；真实媒体与人工交互仍以核验清单为准。
