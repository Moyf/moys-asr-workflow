# 字幕处理预设与单句 ASS 样式核对

> 基于 main 的功能分支；自动化验证不能代替真实素材、播放器及人工交互验收。

## 实现与审查结论
<!-- id: implementation -->

文本处理支持保存替换规则和既有操作，确认预览后应用；单句 ASS 样式使用随工程保存的快照。独立复核及处理见同目录记录。

## 修复与提交记录
<!-- id: changes -->

预设库位于本机用户数据或便携浏览器存储；单句样式保存在字幕工程。ASS 特殊文本预设需要开启 ASS 模式。

`node --test` 定向检查 383 项通过；Python 受影响模块分组 139、229、111 项通过；浏览器新功能 9 项、既有文本处理 4 项通过；合成媒体 Canvas 与 libass 像素对照 1 项通过。均通过 `scripts/run_check.py` 运行。

## 人工核验
<!-- id: manual -->

- [ ] **预设可跨工程复用并安全处理选区**
  （操作）创建多条删除与替换规则，保存预设；在另一工程选中部分字幕，加载预设并检查预览后应用，再撤销。
  （预期）只修改当前选中范围，预览与结果一致，撤销恢复原文；无选区时不会扩大到全部。
  <!-- id: preset-selected -->

- [ ] **预设库可迁移并报告冲突**
  （操作）导出预设库，在另一页面导入；两个页面先后修改库并保存。
  （预期）导入前有替换确认，过期页面保存时提示冲突，不静默覆盖另一页面的修改。
  <!-- id: preset-storage -->

- [ ] **空字幕保留在工程而不干扰导出**
  （操作）用预设删除一整句的内容，保存工程，再导出 ASS 和 SRT 并重新导入 SRT。
  （预期）工程保留该空句；导出不出现空字幕条目，其他字幕的时间和叠加排布正确。
  <!-- id: empty-cue -->

- [ ] **三轨单句样式随工程保存并可撤销**
  （操作）为主、副、叠加字幕分别选择不同样式，保存并重开工程；拆句、合句和撤销后检查样式。
  （预期）三轨样式各自保留；拆分两句继承快照，合并取第一句样式；撤销恢复原状态。
  <!-- id: cue-style-roundtrip -->

- [ ] **真实素材的 ASS 预览、导出与烧录一致**
  （操作）使用带视频、不同字体、颜色及单句位置的工程，比较编辑器预览、实际画面、导出 ASS 和编辑器烧录结果。
  （预期）每句样式、颜色及位置符合设置；字体或播放器差异有明确记录。
  <!-- id: ass-real-media -->

- [ ] **新增界面在常用和窄窗口可操作**
  （操作）在常用和较窄窗口打开文本处理及当前字幕面板，测量新增行与相邻元素间距。
  （预期）控件无重叠，可滚动到确认按钮；新增区域与相邻元素间距至少 8 px。
  <!-- id: spacing -->
