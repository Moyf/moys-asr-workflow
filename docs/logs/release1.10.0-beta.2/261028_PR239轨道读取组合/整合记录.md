- 两处文本冲突分别在日志索引和共享工具门面，保留两边条目及 `subtitleGroupHelpers`、`trackHelpers` 的导出。没有覆盖原始 v1 输入或浏览器、Python 快照。
- 浏览器测试对六组输入继续逐字比较原 ASS/SRT 输出；旧 v1 JSON 快照作为历史证据保留。当前编辑器保存 v2，六份新增快照分别全量比较保存结果，并检查重开后二次保存、跨轨颜色和表情组、CueRef 与重名 cue ID 的绑定迁移。适配器仍验证直接读取 v1 不修改原对象。几何使用测试固定替身，不代表真实布局。
- P0 原行为是关闭 overlay 文字后仍收集其贴纸；PR239 当前行为排除关闭轨道的贴纸，重新启用后恢复。历史说明保留，当前语义另有断言；总开关与预览开关仍影响预览和烧录。

## 六组 v1 到 v2 快照差异审阅

- 共同变化：schema 从 v1 到 v2，增加 `subtitle_groups`；旧保存器写出的空 `color`、`color_ref`、`sticker`、`sticker_ref` 字段在 v2 去掉。测试外围的贴纸几何替身产生空 `preview.sticker`，该字段不作为真实几何行为证据。
- `color-sticker-groups`：主轨 red/main、叠加轨 blue/overlay 各自的 headIdx 迁为独立组表与成员 ID；组属性留在表内，范围由成员派生。副轨原输入的 sticker 和 `custom.nested` 由 v2 保留，旧浏览器快照缺失它们；此差异不是新增素材。
- `frames`：除共同变化外无额外差异，时间、帧和字词字段保留。
- `legacy`：除共同变化外新增主轨缺失 ID 的迁移报告，生成 `main-001`；旧快照也已有该 ID，报告记录原始输入中的缺失。
- `manual-ass`：除共同变化外无额外差异，逐句 ASS 信息保留。
- `three-tracks`：原三轨同名 `shared` 改为全工程唯一 ID，主轨保留 `shared`，副轨 `extension-1-cue-1`、叠加轨 `overlay-cue-1`；副轨 binding 同步指向新 ID，并记录两处映射。字幕、speaker 和字词内容保留。
- `unbound-secondary`：除共同变化外无额外差异，绑定、未绑定和 disabled 状态保留。上述逐路径比较基于原 v1 输出与新增 v2 保存结果，ASS/SRT 单独逐字检查。
