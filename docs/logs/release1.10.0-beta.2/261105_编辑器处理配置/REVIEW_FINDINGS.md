# 编辑器处理配置提交前复审

以 #324 的 `79651f2d` 和集成提交 `91203ed1` 为基线。独立审查复核了合并冲突、用户库读写、工程数据、步骤执行和 ASS 接入，未发现 blocker 或 major。

| 发现 | 处置 | 验证 |
| --- | --- | --- |
| 旧配方中的空包裹可能使其它步骤无法运行 | 迁移时跳过无内容的包裹 | Python 旧配方迁移用例 |
| 大量字面命中可能阻塞或生成过长结果 | 字面替换与正则共享可终止 Worker，逐次累加时限制输出 | Chromium 超时和过长结果用例 |
| 默认路径沿用旧文件名 | 优先读取 `editor-processing.json`，缺失时兼容旧库，首次写入以新文件的锁和修订号校验为准 | 默认路径测试在修复前因新文件缺失而失败，修复后通过 |
| 预览无法展开未变化字幕 | 增加「查看全部字幕」，保留原文和最终结果 | Chromium 全量预览用例 |
| 旧配方中自定义包裹 ID 被拒绝 | 迁移为保留左右字符的自定义包裹 | Python 旧配方迁移用例 |
| 旧库转换后可能超过原容量 | Python 与浏览器统一为 1 MiB 库上限，单字段限制保持独立 | Python 库大小与迁移验证 |
| 超长步骤可能写入工程覆盖并阻塞后续保存 | 保存覆盖前规范化步骤，失败时保留表单并显示提示 | 工程覆盖契约与 UI 保存路径 |
| 矮窗口下右键自定义包裹的输入框掉行 | 恢复独立弹窗的双列布局 | Chromium 矮窗口像素断言修复前相差 58 px |

PR 首轮 CI 发现编辑器指南的 ASS 章节链接已改名，以及本地 ASR 与 OCR 独立 Python 运行时缺少工程校验新依赖。已同步两处指南锚点和打包清单，使用 CI 同款文档与打包契约复验。英文拼合方向控件的标签间距也补充了像素断言。

便携页配置取决于当前浏览器的本地存储。发布前需统一更新仓库的内联便携页。真实素材的 ASS 画面与桌面实机体验在人工清单核验。

## PR #339 Greptile 反馈

- 仅选区预设设为用户默认后，重新打开与手动选用使用同一套范围规则。没有选区时阻止应用，用户主动改动表单的范围会保留。
- 英文模式翻译处理条数和无法完整保留字词时间码的条数。回归测试用实际带字词时间码的字幕执行空替换。
- 工程契约和官网镜像区分当前的 `editor-processing.json` 与旧文件迁移来源。

新增 Chromium 用例在修复前分别因选区复选框未勾选和警告保留中文而失败。

独立复审发现，用户库请求未结束时恢复工程继承可能选中缓存中的旧全轨默认。Chromium 挂起请求后复现了两条字幕都被改动。读取或写入用户库时现禁用「恢复继承」，请求结束后从当前库解析预设和范围。慢请求回归在修复前因按钮仍可用而失败。

拼合面板存在相同的读取窗口。独立 Chromium 实测中，远端用户阈值为 0 ms，暂时显示的 200 ms 被保存为工程参数并实际吸附了 100 ms 间隔。加载时禁用拼合确认和工程保存，加载或写入时禁用恢复继承，保留已编辑的表单值。新增用例覆盖等待状态和恢复后读取最新阈值。
