## 人工核验：工程安全与恢复
<!-- id: manual-project -->
<!-- badge: todo 待核查 -->

- [ ] **旧工程首次写出不覆盖原件**
  （操作）备份一个 v1 或 v1.5 工程，打开后修改一句，按保存并先取消另存；再另存到不同文件名后重开。
  （预期）取消时原件字节不变；另存文件是 v2 且修改存在，原件仍能用旧版本打开。
  <!-- id: legacy-save-as -->

- [ ] **未提交气泡输入能触发真实离开提醒**
  （操作）分别打开主、副、叠加字幕气泡及字词气泡，改字但不失焦，尝试刷新或关闭；选择取消离开。
  （预期）每种入口都提示未保存，取消后输入还在；改回原文时不产生额外脏状态，手动保存后可重开看到修改。
  <!-- id: pending-text-leave -->

- [ ] **撤销重做与保存点一致**
  （操作）保存一个 v2 工程后连续编辑、撤销、重做，回到保存内容；再编辑并保存重开。
  （预期）离开提醒按内容与保存点判断；变动高亮按既有规则保留到重开，不把高亮等同于有未保存数据。
  <!-- id: history-checkpoint -->

- [ ] **三轨元数据与身份跨保存保持**
  （操作）在主、副、叠加轨分别编辑、拆分与换轨，分配不同说话人，保存重开。
  （预期）时间仍为源媒体毫秒；稳定身份、组与绑定不丢失，同名同色不自动变成同一个人。
  <!-- id: tracks-identities -->

## 人工核验：颜色与字词手势
<!-- id: manual-edit -->
<!-- badge: todo 待核查 -->

- [ ] **相邻同色不同组的主副合并不丢色**
  （操作）分别给相邻两组标同色，主副交换后跨组边界合并；撤销、重做、保存并重开。
  （预期）合并结果保色但不错误吞并外部组成员，主副均可保存；不同色或混入未标记段时不继承颜色。
  <!-- id: color-cross-group -->

- [ ] **贴纸严格同组继承**
  （操作）对主轨与叠加轨分别建立同名但不同组贴纸，跨边界合并；再试同一组成员合并。
  （预期）跨贴纸组不继承；同组可继承，未参与合并的成员与其他轨道不串写。
  <!-- id: sticker-group -->

- [ ] **绑定挤压回拉恢复副轨颜色与字幕**
  （操作）拖动绑定主字幕挤压或暂时移除相邻副字幕，在同一次手势中反复拉回原位再松手。
  （预期）回原位恢复字幕、色组与绑定，不累计错位；无实效拖动不增加错误历史，保存正常。
  <!-- id: bound-drag-return -->

- [ ] **连续字词拖动不误开气泡**
  （操作）启用字词时间码，快速连续拖字词中心与左右手柄，试 Alt 独立边界、撤销重做；再正常双击字词正文。
  （预期）移动与伸缩按手柄语义执行，连续拖动不误开气泡吞动作；真正双击仍能编辑，Ctrl+Z 与重做结果正确。
  <!-- id: word-gesture -->

## 人工核验：预览与真实导出

<!-- badge: todo 待核查 -->

- [ ] **字幕姓名与轨道预览导出开关独立**

  （预期）开关不串写；姓名按真实身份，色值和正文符合当前模式，关闭显示不删除工程数据。

  （预期）自动与手动定位字幕都存在，位置、缩放与叠放顺序和预览一致，时间未漂移。
  <!-- id: positioned-export -->

- [ ] **剪辑软件导入图片 XML**
  （操作）分别导出仅图片和带源媒体的 PNG/WebP FCP 7 XML，在目标剪辑软件导入，检查复用图片与多轨字幕。
  （预期）支持的图片格式能联机并按正确时间放置；定义型 file 含 timecode，引用型 file 复用定义；记录软件版本及不支持的格式，不把 XML 检查当实际软件兼容通过。
