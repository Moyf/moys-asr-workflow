# 本地模型目录误判修复核验

> Launcher 本地模型两类目录问题（运行时根目录误判为已安装、切换模型串写目录）加「清除自定义目录」自救按钮；自动化已验证（Python 单测、Node 单测、构建与类型检查、pywebview 桥 stub 浏览器流程），真实 pywebview 桌面环境与真实模型目录的人工验收待完成。

## 实现与审查结论
<!-- id: conclusions -->

显式目录校验放在「权重存在性」检查之后：空目录仍报「目录为空」；选了运行时 / 缓存根目录（有嵌套权重、缺标记文件）报 `path_invalid`。Hugging Face 系引擎要求顶层或 `snapshots/*/config.json` 存在，且 `model_type` / `architectures` 与引擎关键词匹配（两个字段都缺时保守放行）；FunASR 系要求 `config.yaml` 或 `configuration.json`，YAML 可解析时要求非空 `model` 字段，读取失败放行；FireRed 保持原有清单检查不变；未知引擎不校验。选中 hub 缓存仓库根（snapshots 的上一级）时，状态行 path 解析到「含标志文件且有权重」的最新修订目录（中断下载残留的只有 config 的新修订会被跳过，落到次新的完整修订）；所有候选都缺权重时不给死路径，直接报 `path_invalid`。

目录条目只由输入与目录选择事件实时更新；切换模型不回写输入框值——程序性填充（扫描回显、状态回填）若被写回，会撤销用户「删空回到自动发现」的选择并错误持久化。另补上 `path_invalid` 缺失的状态文案键（此前误显示为「未检测到本地模型」），并在状态行追加后端 detail。

## 修复与提交记录
<!-- id: fixes -->

- `maw/local_models.py`：新增显式目录结构校验（`_explicit_directory_structure_error` 及 HF / FunASR 两个引擎分支），接入 `inspect_local_model` 显式目录分支，失败返回 `path_invalid` 并带「所选目录看起来不是该模型的模型目录（可能选了运行时/缓存根目录）」detail。审查修复：`_explicit_model_dir_with_marker` 把 hub 缓存仓库根选择的 status.path（与体积统计）解析到最新 snapshot 修订目录，避免「已安装但加载失败」；复查修复：候选修订必须同时有权重，只有 config 的新修订（中断下载残留）被跳过、落到次新完整修订，全部缺权重时报 `path_invalid`。
- `web/launcher/local/launcher-local-models.js` + `boot/launcher-state.js`：切换模型不回写输入框值（输入 / 目录选择事件已实时更新条目，写回只会把程序性填充的显示值持久化）；`renderLocalModelStatus` 补 `path_invalid` 状态键、追加 detail、清除按钮禁用态。审查修复：移除初版脏标记门控写回方案——删空条目后刷新回填的显示值会在切换时被写回，撤销用户的自动发现选择。
- `web/launcher/index.html` + `i18n/launcher-strings.js` + `boot/launcher-notify-backend.js`：新增「清除自定义目录」按钮（清条目、清输入框、立即保存偏好并刷新状态）；输入与选择目录时更新对应条目。
- 补充修复：校验实际选中的修订目录，向转写引擎传递已解析的目录；保存失败时避免覆盖用户后续切换模型或输入路径的操作。bundle 与 `.meta.json` 是构建产物不进 Git，本地已重建。

## 人工核验
<!-- id: manual -->

- [ ] **选运行时根目录不再误判为已安装**
  （操作）Launcher 选「本地模型」→ 模型选 Qwen3-ASR →「自定义模型目录」选择运行时根目录（内含嵌套的权重或缓存，但没有顶层 config.json，例如整个 local-runtime 文件夹）→ 看模型状态行。
  （预期）状态显示「指定模型目录无效：所选目录看起来不是该模型的模型目录（可能选了运行时/缓存根目录）…」，不再显示「已安装」，准备按钮不可用。
  <!-- id: runtime-root-invalid -->

- [ ] **无效目录可一键自救清除**
  （操作）在上一步的无效提示下点「清除自定义目录」，重启 Launcher 再看该模型。
  （预期）输入框清空、状态回到「未检测到本地模型」、按钮变禁用；重启后不再自动填回旧目录，恢复自动扫描。
  <!-- id: clear-self-rescue -->

- [ ] **合法自定义目录不受新校验影响**
  （操作）分别选择：顶层有 config.json 的模型目录；HF 缓存的 models--* 仓库根（snapshots 布局）；FunASR 系模型目录（config.yaml + 权重，如 SenseVoice）；FireRed 模型目录。
  （预期）四类目录都正常识别为已安装 / 可用，不出现新的误报；models--* 仓库根的状态行 path 指向 snapshots 修订层，实际转写能加载成功（不出现「已安装但加载失败」）；FireRed 缺标点包等原有提示行为不变。
  <!-- id: valid-dirs-pass -->

- [ ] **切换模型不再串写目录**
  （操作）Qwen3-ASR 填入合法自定义目录 → 切到 SenseVoice → 再切回；另取一个从未编辑过目录的模型直接切走。
  （预期）切回后 Qwen3-ASR 输入框保留原路径；SenseVoice 输入框为空，配置文件 localModelPaths 里没有给它的条目；未编辑过的模型切换不产生任何条目。
  <!-- id: switch-no-crosswrite -->

- [ ] **自动发现的路径不落盘**
  （操作）清空某模型自定义目录让缓存扫描自动发现路径（状态显示已安装）→ 重启后查看偏好里 localModelPaths。
  （预期）自动发现的路径只用于显示，不写入 localModelPaths；只有手动编辑或选择过的目录才落盘。
  <!-- id: auto-discover-not-persisted -->
