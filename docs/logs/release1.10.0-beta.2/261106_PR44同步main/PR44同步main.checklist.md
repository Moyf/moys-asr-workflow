## 人工核验
<!-- id: sync-manual -->
<!-- badge: todo 全部待执行 -->

核验前准备含视频、主轨、副轨和叠加轨的工程副本；另备可正常解码与损坏的媒体、已安装且有不同名称的字体，以及可用 Soniox 凭据。每项记录实际素材、入口及差异；凭据不写入备注。

- [ ] **三轨编辑、撤销与工程重开一致**
  （操作）本地编辑器打开三轨工程 → 分别修改文字、时间和位置，执行拆句与合句 → 撤销并重做 → 保存为副本后重开。
  （预期）修改仅作用于指定轨道和字幕；撤销、重做和重开后的内容、时间、位置与轨道归属一致，无串轨或丢句。
  <!-- id: sync-three-track-roundtrip -->

- [ ] **预设应用范围和单句样式可恢复**
  （操作）文本处理保存一组替换规则为预设 → 在另一工程选中部分字幕并预览应用 → 撤销；在当前字幕面板为三轨各一句设不同单句 ASS 样式，立即撤销并重做，再保存重开。
  （预期）预设预览与实际选区结果一致，未选字幕不变；单句样式各自保存，撤销恢复修改前状态。
  <!-- id: sync-presets-cue-style -->

- [ ] **多选字幕分配贴纸保持连续组范围**
  （操作）主轨选择相邻多句字幕 → 分配同一贴纸，播放覆盖区间 → 从该组中间一句清除贴纸，再撤销和重做 → 保存工程重开。
  （预期）贴纸覆盖所选连续字幕的时间范围，未选字幕不被加入；清除中间句后两侧组范围正确；撤销、重做与重开保留对应的分配范围。
  <!-- id: sync-sticker-selection -->

- [ ] **背景、贴纸和样式在真实预览与烧录中一致**
  （操作）编辑器给真实视频配置背景与贴纸，设置三轨文字和单句样式 → 检查预览 → 用编辑器烧录短片，逐帧比较字幕出现区间；另导出 ASS 并检查单句样式。
  （预期）背景、贴纸、字幕位置及样式符合设置，无遮挡错位或时序偏移；记录编辑器预览和实际编码结果的差异。
  （说明）副轨和单句样式使用编辑器导出的 ASS；直接烧录工程的基础主轨及启用叠加轨另行对照，不扩大原支持范围。
  <!-- id: sync-background-burn -->

- [ ] **字体别名在预览与导出烧录中正确匹配**
  （操作）通过本地服务器使用系统中已安装且具有中文名或英文别名的字体 → 在预览字体及 ASS 样式中选用对应名称 → 保存重开，导出 ASS 并烧录短片。
  （预期）工程保留所选样式，预览与烧录使用预期字形及字重；导出 ASS 的字体名称可归一化为本机可匹配的字体名，实际字形不因别名变化而回退。
  <!-- id: sync-font-alias -->

- [ ] **损坏素材不产生误导波形且可重新载入**
  （操作）本地编辑器打开损坏或截断的音视频并请求波形 → 查看错误提示 → 改载正常素材并重新生成波形，播放和拖动时间轴。
  （预期）损坏素材有明确失败反馈，不以空白或旧缓存冒充成功；换入正常素材后波形、播放位置和时间轴正常。
  <!-- id: sync-corrupt-waveform -->

- [ ] **Soniox 真实转写结果可进入三轨编辑流程**
  （操作）Launcher 或 CLI 选择 Soniox，用有效凭据转写短音频 → 打开生成工程并检查文字、时间和说话人 → 保存重开；再用无效凭据请求一次。
  （预期）成功结果可编辑保存，字幕时间和说话人对应实际音频；失败请求给出可理解错误，不生成伪成功工程或泄露凭据。
  （说明）需要实际联网及有效服务配置；未执行时保留未勾选，并记录缺少的环境。
