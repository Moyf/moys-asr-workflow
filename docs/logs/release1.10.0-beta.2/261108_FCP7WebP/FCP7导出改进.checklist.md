# FCP 7 导出改进人工核验

> 基于 PR 353；图片保存路径选择尚未实现，目标软件导入待人工确认。

## 实现与审查结论
<!-- id: implementation -->

图片字幕支持进度条、图片尺寸和自定义；范围和时间线为单选，帧率和字幕轨并排。动态字幕自定义宽高行只在选择自定义时显示。

图片模式仍保存到工程旁独立目录，不支持选择 XML 保存位置。PNG 仍为默认，WebP 需目标软件支持。

> 后续更新：导出形式现默认为 FCP 7 XML 工程；图片模式固定保存在工程所在文件夹下的新目录，图片与源画面的宽高比不同时显示提示。目标剪辑软件中的导入仍需人工核验。
