# WebP 图片字幕独立复审

范围：`feat/fcp7-webp-subtitles` 相对 `1caa69ee` 的全部变更，由未参与实现的审查者只读复核。最终结论：无未处置 blocker/major/minor，可以放行。

复核覆盖双底采样时钟、geq 覆盖度计算、alphamerge/unpremultiply、无损 WebP 字节复制、透明帧过滤及哈希去重；发布白名单、暂存目录和原子发布未放宽，动静分段与轨道分配算法无变更。内部函数/API 的 PNG 名称保留，用户界面与 manifest 明确实际格式。指南已区分路径兼容与目标软件 WebP 解码支持。

收尾条件均取得实际结果：

- 当前优化版 12 项渲染回归；1080p 两帧率 156 参考、4K/竖屏 48 参考、两小时静止首尾 4 参考通过，最大通道差分别为 3、3、1；27 张优化前后 WebP 解码字节完全一致。
- 正式 MAW.spec 构建的实际 EXE 经浏览器生成、发布并解码 14 张 WebP，标准及路径兼容 XML 均存在；独立启动/停止也通过，PIL._webp 并未漏包。
- 最终 Node 全量 1053 项通过；13 项 Chromium、相关 Python/HTTP/打包、类型、Ruff、官网均通过。旧翻译 key 导致的一项 Node 初次失败已真实修复并全量复验。

已接受的边界：WebP 素材约小 59%，本机相同三轨小样生成由约 4.8 秒增至 7.6 秒，不宣传加速；大型工程性能未测。VEGAS/Premiere 的 WebP 导入按维护者允许略过，之前 PNG 的导入证据不沿用。无需为旧 VEGAS 版本引入新适配或拆轨方案。具体命令、基线和 result.json 见同目录实施记录。
