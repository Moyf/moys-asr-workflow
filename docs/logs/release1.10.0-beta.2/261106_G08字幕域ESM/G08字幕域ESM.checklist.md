## 人工核验
<!-- id: manual -->

先在 G08-b 工作树启动 Server 编辑器：`uv run --no-sync python server-editor/serve.py "<你的测试工程>.mosp"`。建议使用工程副本，准备至少两条主字幕、一个带文字的副轨和关联媒体；后两项需要副轨及波形。若没有副轨，可在「工程设置 → 双语字幕」开启并点击「导入副字幕」。表情包分配另需在「全局设置 → 表情包」设置可用图片目录。以下操作入口沿用现有界面；G08-b 主要迁移模块依赖，并未新增一套 UI。

- [ ] **文本处理预设能打开、预览并应用**
  （操作）在字幕列表上方、搜索框右侧点击「字幕处理」（界面按钮不是「文本处理」）。在弹窗左侧「处理步骤」选择「左右添加字符」并点击「添加步骤」，填入左右字符（如「【」「】」）；右侧查看「处理后字幕预览」，勾选/取消「仅处理选中字幕」切换范围（需先在列表选中一条字幕）。点击「应用处理」，再用顶部「撤销」恢复。
  （预期）预览随步骤和范围更新；应用后的字幕文本与预览一致，撤销可恢复原文。
  <!-- id: text-process -->

- [ ] **工程覆盖预设与用户库操作正常**
  （操作）仍在「字幕处理」弹窗：左上「存为新预设」创建临时预设，再从「导入导出 → 导出当前预设」取得可导入的 JSON。点击「当前工程预设配置 → 更改 → 保存为当前工程默认处理」，关闭并重开弹窗；检查后可选「工程内继承默认预设」恢复。删除临时预设后，从「导入导出 → 导入处理预设」导入刚导出的文件，并在「处理预设」下拉框选择它。核验结束后再次删除临时预设。
  （预期）工程覆盖在重开后仍被选中，导入预设可预览和应用；无控制台异常。
  <!-- id: text-presets -->

- [ ] **主、副字幕的选择、拆分和面板编辑正常**
  （操作）在字幕列表或波形点击主字幕，再点击副字幕；当前字幕面板应跟随目标。选中后按 Enter 编辑文字；退出输入框后，在双语模式下用 ↑/↓ 在主、副轨之间切换当前焦点。选一条足够长的字幕，把指针移到文字的目标切点（不要停在输入框）后按 B 拆分；也可右键选「拆分」。最后按 Ctrl/Cmd+Z 撤销。
  （预期）面板目标与选中轨道一致；拆分后的文本和时间正确，撤销恢复原状态。
  <!-- id: cue-edit -->

- [ ] **叠加轨转换及颜色、表情包操作正常**
  （操作）点击波形工具栏「重叠」开启叠加轨；在一条主字幕上右键，进入「高级操作 → 转为叠加字幕」。对转换后的叠加字幕右键，用「标记颜色」色块分配颜色；有表情包图片目录时再点「分配表情包…」。在波形拖动叠加字幕块的边界，随后用顶部「撤销」检查恢复；需要核对导出时用顶部「导出字幕 → SRT」或「ASS」。
  （预期）叠加行、预览和导出结果同步更新；拖动及撤销后轨道与标记状态一致。
