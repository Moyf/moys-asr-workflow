# 文本处理弹窗

> 编辑器文本处理布局、预设管理和规则卡片的实测核对

## 实现
<!-- id: implementation -->

左列管理预设和步骤，右列选择处理范围并查看最终结果。单条预设和整库文件都会先校验并预览。单条导入追加到库中，整库导入确认后替换库和默认设置。工程默认沿用现有继承、留空和保存副本的语义。

## 自动化验证
<!-- id: automation -->

编辑器 bundle、脚本语法与顺序、TypeScript 检查通过。Chromium 相关三份 spec 共 51 项通过，最后的长列表、短窗和导入校验已定向复验。Node 字幕与时间码回归 381 项，Python 预设及资源契约 32 项通过。

## 人工核验
<!-- id: manual -->

- [ ] **步骤和预览独立滚动**
  （操作）打开含多条字幕的工程。添加足够多的步骤使左列出现滚动条，右列点击「查看全部字幕」，分别滚动两列。
  （预期）仅处理选中字幕的提示位于勾选项右侧。两列用细滑块和透明轨道独立滚动，弹窗高度和底部应用按钮位置保持稳定。
  <!-- id: independent-scroll -->

- [ ] **分别导出和导入单条预设与整库**
  （操作）另存一个预设，从「导入导出」分别导出当前预设和整个预设库。选中原预设，临时修改步骤，导入单条文件并确认。再选择整库文件，核对预览后取消。
  （预期）支持保存选择器时，可选择路径和文件名。单条预设加入库中，保留当前草稿和范围。整库预览显示原有默认标记，只有确认才替换库和默认设置。无效文件显示核验错误。
  <!-- id: import-review -->

- [ ] **自定义步骤的入口、预填和提示**
  （操作）直接点「字幕处理」。在无默认预设的工程首次打开，选择「修剪前后空白」，点击「添加步骤」。检查步骤列表末尾。
  （预期）未填写的替换卡片让位给修剪，已填写的步骤会保留。黄色提示紧跟列表，提示与最后一张卡片间隔至少 8 px。
  <!-- id: starter-and-hint -->

- [ ] **预览获得焦点时方向键保留字幕时间**
  （操作）选中一条字幕后打开「字幕处理」，在右列展开一条改动预览。焦点留在预览标题，按方向键与 Ctrl+方向键。
  （预期）当前字幕的起止时间和播放位置保持原值。
  <!-- id: preview-arrow-keys -->

- [ ] **预设操作分两行，工程配置在同一框内**
  （操作）在 1280 px 宽度打开「字幕处理」，再缩窄窗口。添加一条空白替换查看提示。
  （预期）常规宽度下两行预设操作右侧分别对齐编辑按钮与导入导出。行间至少 8 px，工程配置上方有分隔线。窄窗可换行。黄色添加提示和红色步骤错误均为 13 px。
  <!-- id: preset-controls-and-error -->

- [ ] **两个库的状态提示和单句样式同排**
  （操作）在 Server Editor 保存一个文本预设，打开 ASS 样式库对照同步提示，再选择一条字幕查看当前字幕面板。
  （预期）两个库在各自右上角用绿色显示「已与用户级配置同步」。当前字幕面板的单句 ASS 样式在轨道标题右侧，和文本框间隔至少 8 px。
  <!-- id: library-status-and-cue-style -->

- [ ] **单句样式选择后只显示一个相同选项**
  （操作）将某条字幕设为「SRT 渲染样式」，重新展开下拉框。再到 ASS 样式库修改该样式，返回下拉框。
  （预期）初次选择后只有一个「SRT 渲染样式」。库样式修改后，当前工程的原样式标为「工程内保存」，仍可主动切换到库里的新版本。
  <!-- id: cue-style-copy -->

- [ ] **工程预填菜单符合打开时的行为**
  （操作）设置用户默认预设。依次切换「工程内默认留空」「工程内继承默认预设」「保存为当前工程默认处理」，每次关闭再打开文本处理。
  （预期）三种状态分别打开空表单、载入用户默认、载入工程自己的步骤副本。保存副本后修改用户预设，工程继续使用自己的副本。
  <!-- id: project-defaults -->

- [ ] **替换和左右添加字符的卡片**
  （操作）添加「替换文本」，填查找文字并将替换栏留空。分别在启用和关闭 ASS 字幕样式的工程添加「左右添加字符」。
  （预期）查找和替换为各有简短标签，正则与区分大小写在下方的「选项」组。启用 ASS 时显示三组字符，关闭时只有普通字符组和一条启用提示。
  <!-- id: step-cards -->
