# 文本处理弹窗独立复核

基线为 `919f0f39`，复核覆盖当前反馈增量。独立 Chromium 便携页和 Node 探针复验通过。主实现方 Chromium 用例另外覆盖大量步骤与预览的双滚动、预设文件菜单、短窗以及中英文布局。

| 反馈 | 处置与证据 |
| --- | --- |
| 保存期间仍能取消导入 | 确认后的写入期间禁用取消和 Escape，并显示保存状态。延迟写入时点击确认，释放写入后才关闭对话框并替换库。 |
| 紧凑 JSON 合法但展开后超出存储上限 | 预览前共用持久化的尺寸检查。582,519 字节的输入展开超限时直接拒绝。保留现有拼合参数和库修订号。 |
| 导入预览遗漏范围和旧格式的包裹值 | 预览显示预设范围和实际包裹字符。独立验证旧格式的仅选中范围和非默认左右字符。 |
| 英文短窗可把列表压到 4 px | 两区有独立最小高度，弹窗空间不足时提供外层滚动。独立检查 18 组中英文视口，常规 1280×800 无外层溢出。长列表定向用例验证两区分别滚动且外层高度固定。 |
| 切换工程时文件仍在读取 | 独立延迟读取探针确认旧文件无法写入库，项目切换会关闭预览。 |
| 已配置 MASS 的步骤在 ASS 关闭时隐藏 MASS 选项 | 遵照确认的显示规则，卡片仅展示普通字符和一条提示。现有配置保留，重新启用 ASS 或停用该步骤后可继续处理。 |

## 续轮复核

基线为 `63150734`。独立审查执行了导入预览与处理步骤探针，并通读了更新差异。

| 反馈 | 处置与证据 |
| --- | --- |
| 单条导入后选择项与草稿错位 | 导入只追加库，保留原选项、草稿和范围。浏览器回归在接手续作快照上确认旧行为会跳选。 |
| 单条预览错误显示默认星标 | 星标只用于整库预览。核验前和核验失败时隐藏确认动作及覆盖提示。 |
| 空白的预填替换会阻挡随后添加的步骤 | 首次添加会替换尚未编辑的预填项。填写过的替换与后续步骤可以依次执行。 |
| 导入时 160 字符的重名预设无法追加数字后缀 | 维持现有名称长度校验。此极限重名情况经维护者确认接受。 |
| 预设操作在空间不足时换行 | 保留窄窗换行。导入导出保持在该区域行末。 |
