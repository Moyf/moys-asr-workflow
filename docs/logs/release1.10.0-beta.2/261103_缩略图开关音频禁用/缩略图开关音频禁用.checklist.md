# 「生成缩略图」音频禁用与文案精简 · 人工核对

> 基线 main@f3f45273（分支 feat/keyframes-copy-and-audio-disable）。自动化已全绿；浏览器视觉核对在 macOS Chromium（mock 后端）完成，pywebview（Windows WebView2 / macOS WKWebView）实机观感与真实转写链路待人工确认。

## 实现概要（只读）
<!-- id: implementation -->
- hint 文案精简：zh/en（`web/launcher/i18n/launcher-strings.js`）与 `web/launcher/index.html` 静态 fallback 同步缩短为「转写时生成秒级关键帧底图，供编辑器画面带使用；取消则跳过缩略图生成」。
- 音频禁用：`syncThumbnailFields()`（`web/launcher/forms/launcher-form-sync.js`）按当前媒体扩展名判定 `audioOnly`（沿用音轨探测同一套 `VIDEO_EXTS`），禁用复选框并切换 `#generateKeyframesField.unavailable` 置灰；不清空勾选。
- 联动点：`setMedia()`（选择/拖入媒体，`launcher-media-form.js`）与 `mediaPath` input 监听（手输路径，`launcher-notify-backend.js`）都调用 `syncThumbnailFields()`；启动与识别预设应用路径原本就调用它。
- payload 语义：`generateKeyframes` 仍上报 `.checked`（disabled 保留原勾选），音频转写由后端 `maw/thumbnail_cache.py` `load_or_build_base` 的视频探测早退天然跳过画面缓存（`probe_video` 无视频流 → `state: "unavailable"`）。
- CSS：`#generateKeyframesField.unavailable .check-field` 置灰（opacity 0.55 + not-allowed 光标）。
