## Editor CI 夹具修正

上游 PR 349 的 Editor CI run `42341908874`、job `128311271402` 报告 `editor-transactions.spec.mjs` 的两项测试在导入时因 `$.tracks[0].style.style_id` 找不到样式而失败。本地按相同测试复现两个失败；当前账户获取该 job 原始日志返回 HTTP 403，因此远端失败信息以上游报告为准。

两项测试先初始化工程轨道样式，再直接清空或替换 `DATA.styles`，但没有相应更新轨道引用。旧基线未生成本功能的轨道 `style_id`；此处悬空引用是测试构造出的无效状态，不能据此推断旧工程不兼容。空样式场景现同时移除轨道样式引用；自定义样式场景则将轨道绑定到有效快照。保留原有 redo、脏状态与完整快照相等断言，并明确检查对应引用。样式契约的 JavaScript 与 Python 测试仍拒绝不存在的引用，也覆盖没有样式字段的旧工程。
