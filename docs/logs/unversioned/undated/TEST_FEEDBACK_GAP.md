## 基线

- 当前 worktree 在本轮开始前没有源码未提交改动；未跟踪的 `.codex/` 目录保留不动。
- 仍使用 `moy.asr.gap_remove.v1`，通过可选的 `provenance` 向后兼容记录来源层；人工操作继续写入 `manual_corrections` 并进入 gap 撤销栈，同时追加 `manual_overrides`。最终 `gaps` 可附带派生的 `source` / `origins`，旧客户端可忽略这些未知字段。
- 右键波形背景菜单已有创建字幕和按音频位置拆分入口；空隙操作已有边界拖动、中键范围拖动和 Alt+点击切换路径。
