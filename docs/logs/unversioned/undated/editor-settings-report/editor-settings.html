D

表情包目录如何生效

  • 全局表情包页直接输入、读取并应用默认目录。
  • 项目表情包页可启用覆盖目录，清空覆盖后恢复默认目录。
  • 设置默认目录时，已有工程覆盖保持有效。
  • 保存工程仅写覆盖路径，不复制本机默认路径。
  • 切换工程后，在途旧请求不能覆盖新工程状态。
  • 便携编辑器可保存配置，读取本地图片需使用 Server。
