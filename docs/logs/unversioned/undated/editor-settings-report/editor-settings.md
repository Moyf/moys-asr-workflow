新增「项目设置」，集中随工程保存的属性。全局设置保留本机偏好，并提供功能区入口。

## 入口与层次

```tree
编辑器工具栏
  项目设置 | 在全局设置左侧
    时间与语言 | 时间单位、FPS、主副字幕语言类型
    字幕轨道 | 双语字幕、允许字幕重叠
    字幕样式 | ASS 模式、主副字幕样式
    颜色与说话人 | 工程颜色呈现、映射、名称、导出附加名称
    表情包 | 工程覆盖目录
  全局设置 | 本机偏好与工具入口
    基础 | 界面、功能区
    编辑 | 通用编辑、特殊编辑、拆分与合并
    预览与播放 | 播放与预览、自定义色板
    保存与输出 | 保存、字幕导出、更多导出
    扩展功能 | 表情包、彩蛋
  功能区局部面板 | 原区域的齿轮入口仍可使用
    波形区 | 波形外观、显示
    字幕编辑 | 显示、操作
    字幕列表 | 筛选、显示、跟随与浏览
    双语字幕 | 显示、联动、字幕管理
```

全局与项目窗口独立打开和关闭。功能区打开局部面板时保留全局窗口，Esc 关闭最上层可见面板。

| 主副字幕样式 | 全局字幕样式；工程与共享样式库 | 项目字幕样式；保持原样式库复用。 |

工程字段与个人偏好明确分开。ASS 模式和导出附加名称不再继承另一工程的旧浏览器开关。

## 表情包目录如何生效

```flow LR
全局默认目录 --> 当前有效目录: 工程未覆盖时使用
工程覆盖目录 -> 当前有效目录: 配置覆盖时优先使用
当前有效目录 -> Server 验证: 读取图片
Server 验证 -> 更新目录与素材: 成功
Server 验证 --> 保留原目录与素材: 失败
```

- 全局表情包页直接输入、读取并应用默认目录。
- 项目表情包页可启用覆盖目录，清空覆盖后恢复默认目录。
- 设置默认目录时，已有工程覆盖保持有效。
- 保存工程仅写覆盖路径，不复制本机默认路径。
- 切换工程后，在途旧请求不能覆盖新工程状态。
- 便携编辑器可保存配置，读取本地图片需使用 Server。

## 兼容、默认与例外

| 情况 | 结果 |
| --- | --- |
| 旧工程缺少 preview.ass_mode | ASS 模式默认关闭。 |
| 旧工程缺少导出名称布尔字段 | 导出附加说话人名称默认关闭。 |
| 工程未指定主字幕类型 | 根据字幕文字检测；原始 ASR split_mode 元数据保留。 |
| 双语未启用 | 不显示副字幕语言控件，功能区入口禁用并解释。 |
| 播放跳过空隙 | 入口在全局播放页，状态继续随工程 gap_remove 保存。 |
| ASS 样式库、自定义色板、特殊文本规则 | 保留本机共享，不复制为独立工程库。 |
| 字词时间码开关 | 保留波形齿轮显示组；仍是临时模式。 |
| 工作区 | 布局随工程，本机预设库仍可复用。 |
| 便携编辑器生成产物 | 本 PR 只改源码，内联副本待发布前统一重生成。 |
