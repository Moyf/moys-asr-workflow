- [ ] **渐进字幕连续显示且再次拆分准确**
  （操作）有字词码的重复词字幕 → Shift+B 渐进拆分 → 在右半句再次拆分并播放
  （预期）右半句保持完整显示文字和后缀原始词时间，后续拆分定位正确，两条字幕之间不闪空
  <!-- id: progressive-repeat -->
- [ ] **多字词与 Unicode 文字完整保留**
  （操作）含多字词或 emoji 的字幕 → 渐进拆分 → 保存工程并重新打开，再次拆分

  <!-- id: progressive-unicode -->
- [ ] **复制拆分与普通拆分各保留约定**
  （操作）同一句分别执行复制拆分和普通拆分，并试听原有词间静音
  （预期）复制拆分两侧保留全文且边界相接；普通拆分仍保留实际静音间隙

  （操作）绑定副字幕的工程 → 渐进拆分 → 撤销 → 重做 → 保存重开
