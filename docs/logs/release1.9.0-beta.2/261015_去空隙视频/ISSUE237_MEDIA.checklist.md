## 人工核验：去空隙媒体导出
<!-- id: manual-gap-export -->
<!-- badge: todo 待人工核验 -->

条目29/30已按限定范围实现并独立复核。仅已证明的H.264/H.265 IDR共同安全入口可切，首尾向外扩展并合并交叠；CRA/recovery等open GOP仅诊断并保守保留，不支持通用open GOP内部裁切、不自动编码。无实际可删区域明确无输出，不保存完整源副本冒充成功。

- [ ] **安全边界内视频正常播放，未知入口保守保留**
  （操作）长GOP/B帧视频 → 去空隙导出：准备闭合长GOP、B帧、普通open GOP、intra-refresh和HEVC CRA素材，含多段保留区间、短间隙和非零源起始时间；有输出时连续播放并跨拼接点跳转，无可删时检查结果
  （预期）已证明安全入口的输出无少帧、错误画面、接缝卡住或明显音画错位；未知入口保守扩展或保留，不靠K标记放行。open GOP仅诊断、不自动编码；完全无可删时明确无输出、无下载。
  <!-- id: gap-playback -->
- [ ] **长片预检可取消并清理资源**
  （操作）长片或慢盘媒体 → 去空隙视频导出预检：选真实长片及冷盘／慢盘，分别用少量保留片段和较多切点，记录启动到诊断／进度出现时间及内存、磁盘和等待；在诊断及流复制阶段分别取消后重试
  （预期）有进行中反馈，取消及清理后不留子进程、临时索引或导出锁，页面可继续使用。整体仍需全源索引和顺序流复制、O(关键包数)内存；250ms只算诊断活跃预算，不是端到端或系统阻塞I/O硬期限，记录真实资源和等待可接受性。
  <!-- id: gap-preflight-delay-cancel -->
- [ ] **去空隙视频 → 实际删减及未删除原因**
  （操作）去空隙视频 → 实际删减及未删除原因：分别选择部分gap未删、仅头尾可删而内部保留、全部无可删区域的素材；核对计划删除、实际可删、仍保留及原因，观察保存和关闭
  （预期）统计对应实际区间，内部未删有说明，预算／布局证据不足不误报codec全面不支持；部分可删仍输出。actualRemoved为0进入无输出完成态，零视频下载／写入、无匹配SRT按钮，清理确认后解锁并可关闭。
  <!-- id: gap-actual-removal-summary -->
- [ ] **配套字幕匹配实际输出时间线**
  （操作）去空隙视频导出完成 → 保存匹配字幕SRT：成功导出后核对实际区间和累计关键帧扩展，独立点击保存匹配SRT，配视频检查首段、多拼接点和尾段；导出期间修改文本／说话人作对照
  （预期）SRT按发起快照和实际视频时间映射计算，累计时差正确，不混入后续编辑，也不另做起点归零破坏匹配。原工程与现有精确去空隙SRT语义不变；SRT需独立点击，不自动连续弹第二个选择器。
  <!-- id: gap-matching-srt -->
- [ ] **含多音轨/多视频流的素材 → 去空隙视频导出**
  （操作）含多音轨/多视频流的素材 → 去空隙视频导出：用含多个运动视频流、多音轨及正duration文字字幕的受支持MP4/MKV/TS样本导出；切换轨道检查接缝音画、总时长与跨gap字幕，另记录复杂字幕及附件样本
  （预期）共同安全边界及各流时间正确，无倒退、少帧或重复GOP；正duration文本字幕缩短到实际显示区间。轨道存在和生成成功不代替播放验收；不由mov_text正确外推ASS动画、卡拉OK、PGS/data状态，未知布局和大TS关键包限制应说明。
  <!-- id: gap-multi-stream -->
- [ ] **保存取消与无输出状态正确结束**
  （操作）编辑器 → 去空隙导出面板：明暗主题分别完成成功保存、取消、保存失败、重试和无输出任务；观察清理中反馈，确认后关闭结果，再启动一次
  （预期）进度、诊断及完成态清晰、按钮有间距；成功保存后保留结果供关闭，失败能重试。cleanupComplete未确认时继续清理确认，随后释放监听和导出锁；无输出不触发视频／SRT保存。保留浏览器保存，目录打开暂缓。
