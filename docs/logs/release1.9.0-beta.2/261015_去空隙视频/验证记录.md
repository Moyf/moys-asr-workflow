# 去空隙视频：安全边界、诊断成本与验收边界

基线 `f01c6e6`；媒体实现及定向复核提交 `1c86887`。本记录描述可验证行为，不代表发布或人工验收已完成。

原先 concat 直接使用毫秒切点，长 GOP/B 帧素材可能出现重复、丢帧及播放时间异常。仅检查容器 K 标记和包时间戳仍不足：普通 x264 open GOP 实测可少 2 帧，intra-refresh 可在退出码正常时解码出错误画面。因此本批仅采用实际码流可证明的 H.264/H.265 IDR 入口，并继续核对显示边界、多视频轨共同切点及输出包时间。CRA/recovery 等开放 GOP 入口仅识别并说明，本批没有实现通用开放 GOP 拼接。

保留区间向外扩展后合并，未完全删除的区域按实际集合计数。计划删除、实际删除、仍保留包含明确的头尾裁剪，详情区分 leading/internal/trailing；“累积偏移”独立表示实际与原请求保留总长之差。实际删除为零时任务明确 completed/no-output，回收临时目录且释放槽位，不下载、不写入视频、不显示匹配 SRT 按钮。部分可删除时仍可输出，并说明保留区域。

匹配 SRT 使用发起时捕获的字幕和实际视频区间。已有工程及精确去空隙字幕含义保留。内嵌有正时长的文本字幕映射起点和持续时间；零时长事件保持点式策略，不由此声称 ASS 动画、卡拉 OK 或 PGS 状态也完整守恒。

## 额外诊断的资源成本

只在现有 packet 索引增加位置和大小，复用当前探测的编码与封装信息。对请求附近候选进行有界读取，复用单句柄和缓存；不新增整片解码、完整 payload 输出或额外整片扫描。

| 用例 | 结果 | 限定 |
| --- | --- | --- |
| 300 个真实 all-intra MP4 候选 | 累计读取 4518 B；重复查询全命中缓存 | 本机暖缓存小样本 |
| 1080p / 4K 大 IDR 包 | MP4 / MKV 分别只读约 541 / 805 B 头信息 | 画面主体通过 seek 跳过 |
| 大 TS 关键包 | 超 64 KiB 单点预算时不读取并返回未确认 | 不能冒称全部 TS 可安全裁切 |
| 120 秒 / 9.2 MB 真实长 GOP 视频 | 新增诊断 2 候选、4 次 read、26 B，约 0.69–1.12 ms | 全链路仍需完整源扫描和复制 |
| 10 万关键包合成规划 | 初版峰值 65.70 MiB；优化后 47.20 MiB，诊断前 47.07 MiB | tracemalloc 测量，非真实冷盘媒体 |
| 10 万包、完整 DTS 的超长首 GOP | 峰值 12.25 → 1.04 MiB | 避免无必要收集首组 PTS |

当前诊断上限为单点 64 KiB、总读取 8 MiB、1024 个候选、每点 128 个 NAL 和累计活跃 250 ms；容器元数据另有元素数量限制。预算耗尽是“未确认”，不代表安全，也不直接等于编码不支持。时间检查发生在读取之间，无法中断操作系统阻塞 I/O，250 ms 不是严格的端到端延迟承诺。

规划仍为 O(总包数) 扫描和 O(关键包数) 内存，索引另占临时磁盘；至少两次完整源读取的成本仍在。未测试真实 20 GB 冷盘、极长 all-I 文件或所有子进程峰值，不由小样本推断普遍提速。
