# PR239：主线同步与编辑视图保存语义

日期：2026-10-16。同步上游 `b8e8dce3`，包含 PR242、PR243 及后续断连横幅修复。PR239 保留六模块、独立稳定组、内容检查点与 2.0 入口策略；本记录不表示人工验收或版本发布完成。

## 视图偏好与保存检查点

`timed_text_edit_view` 延续 `rows | single`：缺失按 rows，默认 rows 省略写出。字段进入 canonical 分类、纯 `projectSnapshot()`、实际保存输出和 Python / 浏览器校验；非法类型或枚举在导入边界拒绝。v1 与 v2 使用同一接受规则，未知扩展继续保留。

视图选择直接更新工程偏好，经既有保存调度生效；未保存状态统一比较持久化内容与最近成功保存的快照。切换视图产生修改，切回保存值恢复干净。旧 `projectSaveFingerprint()` 和 `timedTextEditViewDirty` 不再承担判脏职责，不增加第二套保存真源。视图切换保留原交互语义，文本编辑草稿仍需应用才写入工程。

Server、文件句柄和另存为仅确认各自写入的快照。保存期间再次切换仍属未保存，失败或取消不推进检查点；工程 epoch 阻止旧工程请求确认或重命名新工程。仅写备份保留其发起时视图，但不确认当前工程已保存；备份按原文件导入规则恢复。

single 因字幕含内部换行等原因暂不可用时，只把运行界面降级为 rows，不覆盖工程选择；保存仍保留 single，切换工程读取新工程偏好。

## 同时保留的编辑与视频行为

PR243 的拆分样式、词时间、批量文本、波形布局、后处理及核验工具改进继续保留；与 PR239 的属性继承、稳定分组、全工程 ID 和 FPS 来源共同工作。视频预览仍有关键帧标记、铺满、隐藏三态，可关闭实时补间而只读已有缓存；Launcher 保留高精度预览开关、预设迁移及播放优先调度。

视频图片、解码结果及本机画面偏好不进入工程真源，也不因缓存刷新触发未保存提醒。会话高亮独立于保存检查点，保存不清高亮，重开或切换工程才开始新会话。

2.0（含预发布版）独立 HTML / 在线入口退役门禁继续生效，本地 Server 的打开、保存、备份恢复和导出保留；1.x 按过渡规则支持旧入口，内联副本待发布前统一重生成。
