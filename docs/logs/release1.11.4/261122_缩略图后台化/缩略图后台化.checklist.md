# 缩略图后台化核验

> 本地合成 H.264 测速不替代真实素材和安装包验收。

## 实现与验证
<!-- id: implementation -->
<!-- badge: fixed 只读 -->

单文件与批量转写不等待画面缓存。可见区补帧、后台缓存与播放共用原有优先级，后台任务受 Launcher 生命周期管理。

1000 秒合成视频的 200 个目标：在同样 8 个解码线程下，扩大后台批次前后为 16.39 秒和 14.55 秒，源时间戳一致。定向 Python 58 项、前端单测 22 项及真实 FFmpeg + Chromium 播放用例通过；未测真实云端转写和发布包。

## 人工核验
<!-- id: manual -->
<!-- badge: todo 待核查 -->

- [ ] **字幕就绪就能打开工程**
  （操作）启用高精度画面预览图，用尚无缓存的长视频转写。保存完成后立即打开工程并跳到中后段。
  （预期）能在后台全片生成结束前开始编辑，画面优先补当前视口，无需刷新。
  <!-- id: first-open -->

- [ ] **播放和窗口生命周期正确让路**
  （操作）后台生成时播放再暂停，随后切换到其他项目或关闭 Launcher；再打开原工程。
  （预期）当前画面随视口更新，换源不串帧；后台队列在退出 Launcher 时停止，已完成缓存仍可用。
