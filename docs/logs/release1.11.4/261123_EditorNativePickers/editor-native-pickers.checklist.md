# 编辑器原生选址：工程、媒体和表情包

> 适用范围：从 Launcher 授权打开的编辑器。

## 实现与本地状态
<!-- id: implementation -->
<!-- badge: fixed 已实现 -->

原生打开工程只能使用 Launcher 选择的工程和媒体；选完并确认后才切换。表情包文件夹选择只填入路径，「应用」仍执行现有验证。

保留独立 Server 的手填和浏览器选择，以及拖放与字幕导入。以 Draft PR 留存供评估；尚未决定是否合入 main，2.0 可能弃用这条 Launcher → 本地 Server → 浏览器的选址桥接方式。

## 自动化验证
<!-- id: automatic -->
<!-- badge: pass 已验证 -->

Python 定向服务测试覆盖选址授权、取消、媒体重定位只在保存时落盘、表情包选择不直接生效；159 项运行，3 项跳过。

编辑器类型检查、脚本语法与顺序、切换意图单测及 bundle 新鲜度检查通过。

## 人工核验
<!-- id: manual -->
<!-- badge: todo 待核查 -->

维护者已在本机试用并反馈无问题，未逐项回报，下列勾选项保留为可复核步骤。

- [ ] **全局默认与工程覆盖不会混用**
  （操作）从 Launcher 打开编辑器；打开全局设置的表情包页，点「选择文件夹」并选择含图片的目录，点「应用」；在工程设置打开「覆盖默认文件夹」，选另一目录并应用。
  （预期）先填入路径，点应用后才改变可用图片；工程覆盖优先，关闭覆盖恢复默认。选择行与上方标签、下方反馈至少各留 8 px。
  <!-- id: sticker-scopes -->

- [ ] **取消选择不改原设置**
  （操作）在原生表情包文件夹窗口点取消；分别试全局默认和工程覆盖。
  （预期）输入框、有效目录和素材列表都保持原样；能重新打开选择窗口。
  <!-- id: cancel-folder -->

- [ ] **媒体移走后可以继续打开工程**
  （操作）准备一个仍引用原路径的测试工程，把原媒体移到另一目录；在 Launcher 打开的编辑器里选工程，确认重定位并选回原媒体，再按 Ctrl/Cmd+S。
  （预期）媒体可播放，选中的工程在保存前没有写回、保存后记住新引用；再次打开不需重复选择。
  <!-- id: relink-media -->

- [ ] **取消媒体重定位保留正在编辑的工程**
  （操作）留一条未保存的字幕改动；尝试打开媒体缺失的另一工程，取消重新选择。
  （预期）仍在原工程，字幕改动留在页面，之后保存仍写原文件。
  <!-- id: relink-cancel -->
