## 人工核验项
<!-- id: manual-checks -->
<!-- badge: todo 待核查 -->

- [ ] **样式库改样式，工程内句子跟随**
  （操作）打开带字幕的工程 → 单句面板给几句主 / 副 / 叠加字幕选同一库样式 → 打开样式库窗口改该样式字号或颜色，不点保存按钮（自动保存）。
  （预期）这几句的预览立即变样；单句面板样式下拉不再出现「（工程内保存）」；底部不出现不一致提示。
  <!-- id: check-follow-basic -->
- [ ] **只改样式名不产生分叉**
  （操作）在样式库中只修改样式名称，不动其他参数。
  （预期）工程内使用该样式的句子不变样；单句下拉仍显示原名并选中该样式，不出现「（工程内保存）」。
  <!-- id: check-rename -->
- [ ] **旧工程打开不自动变样，按钮一键更新**
  （操作）用一个「选好样式后保存、随后（或另一窗口）改过样式库」的旧工程重新打开编辑器 → 打开样式库窗口。
  （预期）底部出现「工程内 N 句的样式与样式库不一致」和「用样式库更新」按钮 → 点按钮后句子变为库的当前样子，提示与按钮消失；Ctrl+Z 可一步撤回这次批量更新。
  <!-- id: check-stale-button -->
- [ ] **删除样式后句子保留快照**
  （操作）工程内句子选中某自建样式 → 在样式库删除该样式。
  （预期）句子保持原样子继续渲染导出；底部提示与按钮不出现。
  <!-- id: check-deleted-style -->
- [ ] **撤销其他操作不退回旧样式**
  （操作）跟随后再对字幕做一次可撤销编辑（如改文字）→ Ctrl+Z 撤销它。
  （预期）文字恢复，但句子样式仍是库的当前版本，不退回旧快照。
  <!-- id: check-undo-realign -->
- [ ] **导入 / 恢复副本 / 重新加载不自动同步**
  （操作）改过库之后，用「更多 → 重新加载」或导入一份样式库。
  （预期）工程内句子不自动变化；底部出现提示与按钮，可一键更新。
  <!-- id: check-import-noauto -->
- [ ] **换库后一次无关撤销不重写句子**
  （操作）工程选好样式后，用另一编辑器窗口（或导入一份改动过的库）改库 → 本窗口打开样式库窗口（触发强制重新加载）后关闭 → 对某句做一次文字编辑 → Ctrl+Z 撤销它。
  （预期）撤销只恢复文字；被恢复的句子样式保持本工程原样，不会悄悄变成重新加载后库里的版本。
  <!-- id: check-reload-undo -->
- [ ] **底部提示与按钮的间距与文案**
  （操作）构造不一致后查看样式库左下角；切换中英文界面各看一次。
  （预期）提示与按钮上下间距 ≥ 8px；中文「工程内 N 句的样式与样式库不一致」/「用样式库更新」，英文对应「N cues in the project differ from the style library」/「Update from style library」；e2e 已实测间距，此项确认观感。
  <!-- id: check-hint-layout -->
