# ASS 样式库迁移独立复审

基线：`main` ee2fe595；范围包括样式库导入导出、恢复、并发保护及旧库迁移。独立审查使用历史版本生成的默认库和临时目录，未读取实际用户库。

| 发现 | 处置与证据 |
| --- | --- |
| 历史样式库缺少后来新增的槽位、MASS 参数或 pop 动画组时，严格校验拒绝导入 | 已补允许的历史迁移并展示提示；四份历史库夹具通过直接校验和浏览器导入。 |
| 恢复过程中主库写入失败会覆盖之前的恢复副本；重复导入相同内容也会消耗恢复副本 | 服务端先暂存副本、成功写入后再替换；浏览器写入失败恢复旧副本；无变化时禁用确认。故障注入及浏览器回归通过。 |
| 管理器重新加载与导入预览重叠时，旧预览可能使用新的服务器版本号覆盖其他窗口的修改 | 导入前等待当前读取，成功读取推进页面修订号；导入时阻止并发重新加载。延迟 GET 的双窗口浏览器测试保留了两个窗口的样式。 |
| 已有服务器数据时浏览器缓存不可用，再遇读取失败可能用默认库替换内存，后续保存会丢失样式 | 重读失败保留上次可信的内存库与未保存修改；浏览器回归覆盖缓存写入失败、请求中断及恢复保存。 |
| 导入提交在途时可关闭对话框并编辑旧库，后续保存可能撤销导入 | 提交期间禁用取消与模式切换、拦截 Esc；延迟 POST 的浏览器回归检查界面始终保持模态。 |
| 导出可能在样式库读取完成前取到旧缓存 | 导出前等待已有的读取完成。 |
| 样式库底部次要按钮过多，导入摘要不够突出 | 恢复与重新加载收进「更多」；摘要独立显示，字体提示减弱。 |
| 迁移与合并逻辑耦合界面，难以单独检查历史格式和依赖映射 | 已提取为可直接测试的纯函数；浏览器仍覆盖完整交互。 |

2.0 兼容检查：双方当前共享库结构的普通样式、方案、动画与槽位可相互归一化；上游 2.0 目前仍将 65 样式截为 64，需将本次上限修复随 main 同步后再验收满额库。轨道样式草案未作为已合并能力。

未验证：两台实际机器之间的字体安装、授权及渲染差异；Linux / macOS 实际文件锁；远端 CI 与维护者人工验收。
