## 人工核验
<!-- id: manual -->
- [ ] **普通主字体不被意外替换**
  （操作）以微软雅黑或苹方打开含中英文、中文标点的已有工程，对比主字幕、副字幕、叠加字幕。
  （预期）可覆盖字符保持原字体；内容、颜色、描边、动画不丢失。
  <!-- id: primary -->
- [ ] **组合重音和缺字符号保持完整**
  （操作）用得意黑预览 `( •̀ ω •́ )y ╬`，对照实际画面和导出 ASS，切换粗体斜体及多轨重叠。
  （预期）重音不拆散，缺字使用显式候选；记录仍存在的 face 或塑形差异。
  （说明）本阶段不承诺逐像素一致。
  <!-- id: grapheme -->
- [ ] **emoji 提醒与原文保护**
  （操作）在任意字幕轨加入 `❤️ 🤔 👍🏽 👩‍👩‍👧‍👧`，切换 ASS 模式，聚焦黄色感叹号，再删除并撤销。
  （预期）警告随模式和内容更新；鼠标与键盘都能阅读；复杂序列不拆，工程和 ASS 原文未添加或替换 VS15。
  <!-- id: emoji -->
- [ ] **缺字体与跨平台边界可复核**
  （操作）在 Windows 和 macOS 使用缺失字体、可变字体与含复杂脚本的工程，检查实际帧与导出。
  （预期）不崩溃，不误称统一；无法管理的字体继续原引擎回退。
