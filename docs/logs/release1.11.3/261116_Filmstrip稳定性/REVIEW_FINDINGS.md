# Filmstrip 候选独立复审

## 结论

对代码与测试的独立只读复审未发现剩余 blocker 或 major。候选针对本机可复现的子进程输出完整性缺陷和重复元数据探测；线上慢 HTTP 的具体原因仍未确定，不以此宣称原 CI 失败已解决。

## 发现与处理

1. **后台测试夹具需提供元数据。** 协调解码改为复用缓存后，既有后台测试的假视频会触发真实探测并失败；已在该测试中提供 mock 元数据，保留原有“缓存拒绝时返回新帧”的断言。
2. **快速退出时 stderr 超限可能漏检。** 旧逻辑仅在子进程运行时检查 stderr；已增加退出后大小检查，并用强制子进程先退出的测试分别覆盖 stdout 和 stderr。
3. **播放检查只读方案有并发风险。** 读取已提交快照可能漏看另一进程尚未提交的播放租约，使解码提前开始；该方案及其测试候选均已撤回，原有锁与租约语义不变。

## 核验边界

- `fstat` 不查询子进程共用文件游标；测试保留 stderr 尾部、8 MiB 上限及真实子进程取消、超时与回收的覆盖。
- 元数据复用检查了取消和源文件替换；本机实测减少重复 ffprobe，但没有证据说明该优化消除了线上请求等待。
- 首次失败、受控对照及环境差异见 [验证记录.md](验证记录.md)；完整 trace 留在本地临时区。
