## 去重保留了什么

1. 保留HTTP编辑器执行顺序、工程导入/导出/撤销断言；删除的只是两个已skip消费者的HTML准备。
2. 生产compileSources不变，缓存只保存不可变编译文本及inflight Promise；每次load仍独立VM，失败清理允许显式重试。
3. 保留editor/launcher参数化传递依赖的metadata、metafile、hash和实际code变化断言；Python账目完整性与清单外依赖验证均保留。
4. 118模块统一inert import smoke保留，各域专属顺序、桥和静态import约束不删。

新增loader测试自身也执行编译，因此54→29只针对同一批27消费者，不应宣称完整suite恰好减少25次。前后Node墙钟62.62s和67.73s受负载等影响，没有证明提速。
