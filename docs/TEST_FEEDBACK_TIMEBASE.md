## 处理结论

- 时间基准和 FPS 位于全局设置的通用操作卡片；帧吸附和时间码分隔符与其同属「时间基准」分类。
- 毫秒字段继续保留用于兼容；帧模式额外维护整数帧字段，并在切换 FPS 时保持媒体毫秒位置后重算帧字段。
- 帧吸附默认开启，仅在帧模式可用；关闭时帧模式仍按帧执行编辑，但鼠标指针保留连续定位显示；毫秒模式不会启用帧吸附。
- 分隔符只替换秒与帧之间的最后一个分隔符，前三个时分秒分隔符仍为 `:`；解析同时兼容旧的 `;`、`,`、`/` 输入。
- 所有构建 JSON 的路径在序列化前重建多字幕 binding offsets，避免保存时出现段时间偏移校验错误。
- 修改时间码分隔符后立即重建字幕列表，列表中的时长/时间码会同步更新。
- 进入帧模式或在帧模式修改 FPS 前，若工程存在字幕数据则弹窗说明批量映射及不可恢复的毫秒取整影响；取消会恢复原设置。
- 波形基础模式新增 2 秒显示窗口，多行模式新增 2 秒每行长度；细网格只在各自的 2 秒档位显示，帧模式按当前 FPS 划分，毫秒模式每 100ms 划分，颜色弱于秒分隔线。
- 生成器尽力写入 `media_metadata.video_fps` 与 `video_fps_ratio`；FFprobe 不存在、输入为音频、帧率不可解析或探测失败时静默省略，不影响原有转写流程。编辑器只把该字段作为首次切入帧模式的默认 FPS，旧 `.mosp` 无此字段时继续使用 30 FPS。
