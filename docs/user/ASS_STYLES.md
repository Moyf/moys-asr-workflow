# ASS 样式、预览与导出

ASS 用于带字体、描边、位置和动画的字幕交付。先在编辑器「管理 ASS 样式」选定输出方案与关联样式，再导出 ASS。普通编辑步骤见 [编辑器指南](EDITOR_GUIDE.md)。

## 样式库与默认槽位

localhost 编辑器与 Launcher 共用 MAW 用户数据目录下的 `ass-styles.json`。便携 `file://` 页面无法访问本机 API 时，使用浏览器 `localStorage` 副本。

样式库保存字体、字号、颜色、描边、阴影、对齐、边距和输出方案。ASS 导出使用默认输出方案；Launcher 烧录 SRT 使用单独的 SRT 渲染样式。烧录已有 ASS / SSA 则使用该文件内嵌样式。

![ASS 样式库：左侧选择样式、输出方案和默认槽位，右侧调整样式并查看预览](../assets/1.6.0/ass-style-library.webp)

*样式库示例（1.6.0）：左侧关联输出方案，右侧检查字体、描边、对齐和边距，修改后保存样式库。*

工程记录的源视频宽高写入 `PlayResX / PlayResY`。字号按 1080p 参考存储，再按输出高度换算；工程仍需保留，导出的 ASS 不能完整还原编辑状态。

新建样式库的内置主字幕为字号 86 / 描边 6 / 垂直边距 88，副字幕为 64 / 2 / 36；默认预设下副字幕位于主字幕下方，可通过副字幕样式的对齐与边距调整。默认方案启用 250ms 淡入淡出。Windows / macOS / Linux 默认字体分别为 Microsoft YaHei / PingFang SC / Noto Sans CJK SC，已有用户样式与字体不被覆盖。描边、阴影与背景底框颜色支持不透明度，预览与导出同步使用。

## 播放器预览

「ASS 字幕模式」默认关闭。关闭时使用 CSS 字幕预览，可拖动预览框；开启后文字改由 Canvas 按导出参数在原生分辨率绘制（描边以整层合成，无 run 交界接缝），按 ASS 方案显示文字和逐句动画，位置由 ASS 对齐与边距接管，不使用 CSS 框的拖动几何。`\frx` / `\fry` 的 3D 透视旋转以轴向透视缩短近似呈现（无透视斜切）。

ASS 模式保留显式换行；多条字幕共同排布时，超宽文字按 ASS 画布与样式边距折行，不使用 CSS 预览框的宽度。「字幕样式」中的主副字幕选择器与样式库同步。浏览器预览用于检查，最终仍应在目标播放器或烧录结果中确认字体与效果。

### 逐句位置与缩放

开启「ASS 字幕模式」后，先点击画布中的主字幕或叠加字幕选中，出现边框与四角大小 handle 后才能拖动；未选中时没有定位边框，第一下手势只选择。拖动边框改变 X/Y，拖动四角 handle 等比改变字号比例；也可在视频画面内滚动鼠标滚轮缩放当前选中的单句。按住 Ctrl、Alt、Shift 或 Command 时保留浏览器与系统快捷操作。文字块锚点始终使用全局 ASS 样式的对齐方式，显示缩放和视频黑边会换算到源画布 PlayRes 坐标。

缩放比例以倍率表示，例如 `1.22` 表示原大小的 1.22 倍，范围为 `0.10–5.00`。主字幕的大小或位置发生变化后，文本编辑区右侧才显示对应控件：倍率在 X/Y 左侧，「重置大小」只恢复大小；「重置定位」只清除位置。叠加字幕选中即显示倍率输入，可直接从字幕行设置缩放，位置控件在拖动后才出现。两组控件互相独立，不增加编辑区的垂直占位。只缩放时仍使用全局自动排布，不创建位置覆盖；选择或原地点选不写位置、不新增撤销。

新输入、方向键微调和拖动保存的 X/Y 均为整数，界面也以整数显示；小数坐标的已有工程会原样保留，直到用户主动编辑位置。倍率显示两位小数，默认 `1.00` 不保存。一次拖动或一次连续滚轮操作各为一次撤销；Esc 或窗口失焦取消拖动。按住拖动期间暂停其它编辑、选择与播放快捷键；撤销或重做快捷键先取消当前拖动，不消耗已有历史。数字输入、微调、重置支持撤销/重做，保存 `.mosp` 后重开恢复。

有绝对坐标的句子不跟随主字幕组避碰或方案移动动画，可与其它字幕重叠，也允许落到画布外。只有大小覆盖的句子继续参与自动排布和整体适配。淡入淡出、文字变换与颜色仍生效；整体缩放同样作用于句内字号、字距、描边、阴影和字号动画。与震动叠加时围绕保存的基准锚点抖动，拖动不会把瞬时抖动偏移写入工程。

这项能力应用于主字幕和叠加字幕；副字幕保持现行排布。叠加字幕设置 `pos` 后导出为固定 `\pos` 事件，可与主字幕及其它叠加句重叠；只设置 `scale` 时继续参与主/叠加组的自动排布与整体适配。拆分后两句继承各自独立的位置和倍率；合并取最左句的覆盖（左句使用默认时合并也使用默认）。普通 CSS 预览和 SRT 忽略此设置。Canvas、Server 实际帧、导出的 ASS 及烧录已有 ASS 共用同一定位与缩放结果；最终字体和文字效果仍以目标播放器为准。

### 实际画面预览

localhost 编辑器开启 ASS 字幕模式后，可从波形工具栏的「📷 实际画面预览」打开独立对照窗，以 FFmpeg / libass 渲染当前 ASS 方案；「工程设置 → 字幕样式」及样式库也提供入口。快捷入口仅在具备实际帧预览能力时显示。已由服务器绑定的视频使用源画面；纯音频或尚未加载视频时使用 1080P 绿幕画布，仍按播放头时间渲染字幕，右上角提示可从「更多导出」导出绿幕视频。便携页面和仅上传到浏览器的视频继续使用即时预览。

- 「自动渲染实际帧」默认开启；「暂停时在播放器画面显示实际帧」默认关闭，需先开启自动渲染才显示。关闭对照窗且未启用播放器叠加时，不在后台自动渲染。
- 开启播放器叠加后，暂停或 seek 停止时显示实际帧；播放或拖动播放头时恢复即时预览。关闭自动渲染后，只在点击「渲染当前帧」时更新，可在播放中手动捕获。
- 窗口支持原尺寸查看。字幕、样式或位置变化后，旧帧标记已过期；较早的渲染结果不会覆盖新的状态。实际帧时间可能与播放头略有差异。
- 缺 libass 时提示并回退即时预览，可配置支持 libass 的 FFmpeg 后重试；缺字形会提示字体与字符。即时预览对字体回退、换行和复杂动画有近似，实际帧更适合对照交付效果。

实际帧的主副字幕显隐与说话人跟随预览设置，导出选项独立；首句导出延长到 0 不会提前显示预览字幕。实际帧为源尺寸（绿幕为 1920×1080）无损 PNG，最终烧录仍受视频编码影响。

## 主、副与叠加字幕

- 主字幕使用输出方案关联样式。
- 副字幕共用「副字幕样式」槽位，可独立设置字体、字号和水平对齐。
- 叠加字幕使用 Overlay 样式，继承主字幕的字体与字号。

主字幕与叠加字幕按实际文字尺寸从下向上排列，叠加字幕固定锚定在主字幕上方；多行、特殊文字比例、说话人前缀和同轨重叠字幕都参与避碰。间距随文字尺寸计算，不能用样式行的「边距 + 1.2 × 字号」推算最终事件位置。空间不足时主/叠加组移入画面或等比缩放。副字幕作为固定层，保留自身样式的对齐与边距，不参与该组的移动或缩放；同轨多条副字幕从各自实际边界向上错开。副字幕过大或无法可靠排布时提示调整样式。

主字幕的 `\move` 带动主/叠加组移动，副字幕保持固定位置，单独播放、早于主字幕开始或晚于主字幕结束时也沿用该位置。各句的 `\fad`、`\fade`、`\t` 保留自己的动画时钟；固定副字幕的行内强调字号和动画目标也不乘主/叠加组比例。预览与导出使用同一排布规则，实际位置由事件中的 `\pos` / `\move` 指定，不能仅根据样式行的垂直边距判断。

字幕出现或结束时会重新计算当前活跃字幕的排布，动画变化也可能产生新的位置分片。ASS 导出因此可以把一条源字幕拆为多条连续的 Dialogue 事件；分片覆盖原时间范围，不增加同时显示的字幕数量，也不重新开始淡入淡出或变换进度。多轨绑定与编辑操作见 [双语字幕](MULTI_SUBTITLE.md)。

## 特殊文本格式

字幕文本里这类给 ASS 用的成对标记语法（如 `**重点**`、`++文字++`、`>>淡入淡出<<`、`!!原地震动!!`、`{{放大出现}}` 等）统称 MASS（Markdown-ASS）。

开启 ASS 模式后，「全局设置 → 高级编辑 → 特殊文本」可选择「无」「双个符号」或「单双皆可」，默认单双皆可。旧的「单个符号」设置会迁移为「单双皆可」，其他显式选择保留。强调、下划线、删除线、缩小和放大可分别关闭；关闭后保留对应原符号。

| 双符号写法 | 效果 |
| --- | --- |
| `**重点**` | 强调 |
| `__文字__` | 下划线 |
| `~~文字~~` | 删除线 |
| `--文字--` | 缩小 |
| `++文字++` | 放大 |

颜色、强调样式和比例在样式库「基础样式」下方的「特殊文本样式（MASS）」配置。内置主样式强调色为 `#ffaa00`、比例 1.3，副样式强调比例 1.1；缩小默认 0.8 倍、放大 1.5 倍，比例步进 0.05。强调范围 1.0–1.5、缩小 0.1–1.0、放大 1.0–3.0。组合标记的比例相乘，主副及叠加字幕按各自关联样式显示与导出。SRT 保留这五类格式标记原文。

选中主字幕后，右键「左右添加字符」可插入上述双符号，或使用「淡出淡入」「音符」及自定义字符。「文本处理（批量）」提供同组预设与应用前预览，可多选并按选择顺序从外到内嵌套，也可叠加自定义字符；重复应用同一组合不会再次包裹。符号规则控制解析方式，不改变预设插入的文字。

普通拆分会保持已识别样式的配对：跨样式正文拆分时，两段分别闭合，同类单双符号的重叠样式合并为等效单层配对；在样式符号内或紧邻符号下刀时，完整符号跟随其正文。淡入淡出、原地震动与放大出现拆分后两段均补齐 `>>…<<` / `!!…!!` / `{{…}}`（合并时同理折叠回一个完整外壳）。关闭对应识别规则后按普通文字拆分；渐进拆分和复制拆分保持各自原有文本规则。

### 配对规则

成对符号只与同宽度的同类符号配对：单个符号认单个符号，双个符号认双个符号，`*文字*` 与 `**文字**` 不会互相匹配；符号紧挨同类符号时（如三连星中间的 `*`）不参与配对，避免把边界切错。

样式可以嵌套，同一文字被多层标记覆盖时按最内层显示。例如 `>>** //The *editing* //process**<<` 从外到内是淡出淡入、强调（`**`）、弱化（`//`）、强调（`*`），`editing` 同时落在弱化与强调范围内时按强调渲染（最内层用了单个 `*`，需「单双皆可」才识别）。

`>>…<<` 是不对称的句级标记：只认行首 `>>` 与行尾 `<<`，不像其它符号那样在任意位置成对，详见下节。

找不到配对另一端的孤儿符号按普通文字原样显示；下划线、删除线、缩小、放大与弱化遵循同样的配对规则。

### 单句渐入渐出

在整条字幕文本开头写 `>>` 表示淡入，结尾写 `<<` 表示淡出；`>>文字<<` 同时淡入淡出。「单双皆可」也识别单个 `>` / `<`，选「无」则保留原文且不应用单句动画。

单句标记使用输出方案中淡入淡出的时长，即使全局动画开关关闭也生效，并覆盖该句的全局 `\fad` / `\fade`。ASS 导出写入对应 `\fad`，即时预览与实际帧使用同一规则。SRT 导出同样按当前符号规则剥除这些开头/结尾标记，即使 ASS 模式关闭也如此；要保留作为普通文字的 `>` / `<`，请选「无」。

### 单句原地震动

在整条字幕文本两端各写 `!!`（如 `!!文字!!`）表示该句在原地抖动：按固定 60ms 间隔、约 PlayRes 高度 1/216 的振幅，沿四个对角相位往复。周期从该句起点计算，不因其它字幕开始或结束而重新起算。整句外层标记可以叠加：`++!!喂喂喂嗯!!++` 同时放大与震动，`>>!!文字!!<<` 和 `!!>>文字<<!!` 都同时淡入淡出与震动；「单双皆可」下的 `>!!文字!!<` 和 `!!>文字<!!` 也可组合，SRT 按规则清理后输出正文。右键和批量添加字符保留已有整句外层，再包裹正文；例如给 `++!!文字!!++` 添加强调得到 `++!!**文字**!!++`。通过右键或批量面板应用整句效果（淡出淡入、原地震动）时，符号恒包裹在现有全部符号最外层（如给 `**文字**` 添加震动得到 `!!**文字**!!`），同一对符号不重复包裹。句内局部的 `!!` 不会触发整句震动。

ASS 的一条事件只能有一个定位标签，因此震动只在导出时把该句拆成多条连续 Dialogue，各自写入 `\pos`；工程数据与编辑操作不受影响，标记保留在原文中，仅 ASS 与 SRT 导出剥除。拆分会把该句参与的整体移动 / 整组位移按片取样冻结（每片取片起点位置），淡入淡出与 `\t` 变换使用相对时钟跨片连续、不重播；与「逐句定位」叠加时围绕保存的锚点抖动。Canvas 即时预览按同一模式逐帧偏移，实际画面预览与导出结果一致。该标记仅解析主字幕；副字幕与叠加轨不消费。要与普通感叹号区分：只有完整整句外层中的双感叹号且中间至少一个字符才视为标记，可嵌套在整句字号等外层之内。

### 单句放大出现

在整条字幕文本两端各写 `{{` `}}`（如 `{{文字}}`）表示该句以「放大出现」入场：文字从起点倍率缩小落定到正常字号，倍率、入场时长和加速度取自输出方案「逐句动画 → 放大出现」的参数（默认 1.4 倍、250ms、线性）。与单句淡入淡出一样，即使全局开关关闭，句级标记也复用这组参数；打开开关则每一句自动应用。导出写为事件内两段标签（显式起点 `\fscx\fscy` 加一个渐变回正常缩放的 `\t`），起点倍率基于样式自身的横向/纵向缩放；Canvas 即时预览用同一插值公式，观感与导出一致。

`{{…}}` 只认整句两端的双花括号且中间至少一个字符；「符号规则」选「无」时保留原文、不解析动画。句级标记之间可按任意嵌套顺序组合（如 `>>!!{{文字}}!!<<` 同时淡入淡出、震动与放大出现），右键和批量面板的「放大出现」恒包裹在现有全部符号最外层，SRT 导出同样剥除该标记。

## 烧录视频

已关联视频的 Server Editor 可从工具栏「烧录视频」生成带字幕的 MP4；「去空隙导出 → 重组后烧录视频」使用精确裁剪后的时间轴。两者都会重新编码，进度窗口可停止任务。

开启 ASS 模式时使用当前导出方案；关闭时先生成当前 SRT，再与 Launcher 工具箱共用转换逻辑，采用样式库默认槽位指定的 SRT 烧录样式。转换后的 ASS 画布与源视频分辨率一致，字号按 1080p 参考高度换算；关闭 ASS 不会误用 ASS 输出方案。更换工程或源媒体后，旧任务失效。

「帮助」中的「ASS 字幕样式」「双语字幕」「导出与烧录」「标记与区段」提供精简操作指引，对应设置与工具窗也可直达。

「单双皆可」下，左右添加字符会把 `>文字<` 包为 `>++文字++<`；已有 `>>文字` 或 `文字<<` 再添加淡入淡出时，只补缺失的一侧，得到 `>>文字<<`。选择「双个符号」或「无」时，单个 `>` / `<` 仍按普通文字处理。

## 颜色与说话人

ASS 能表达的文字色和描边色会导出；编辑器的独立下划线颜色效果不能完整映射。启用说话人导出后，名称写入事件 `Name`，颜色可用局部标签保留。播放器显示的说话人名称不会写回 `segments[*].text`。

CSS 预览框的位置与大小不是 ASS 位置真源。需要改交付字幕的位置时，在 ASS 样式库修改对齐与边距。

放大出现与自定义 `\fscx` / `\fscy` 渐变同时使用时，预览按 ASS 的先入场、后自定义渐变顺序合成。自动排布使用保守缩放边界，可能额外预留空间，以覆盖动画中间时刻的最大尺寸。
