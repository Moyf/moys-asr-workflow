## [1.6.1] - 2026-09-23

### ✨ 提升

- 接入阿里云百炼新模型 `qwen-audio-3.1-asr-flash-filetrans`（Qwen-Audio-3.1-ASR） ；注意 3.1 按 Token 计费（北京输入 ¥0.8 / 百万 Token、输出 ¥2.7 / 百万 Token），与 3.0 的按秒计费不同。
- 自动后处理工具链中增加了「烧录字幕」的步骤，可以流水线将字幕烧录进视频
- DeepSeek 后处理默认模型更新为 `deepseek-flash`（旧 `deepseek-v4-flash` 已由官方停用），并支持选用 `deepseek-v4-pro`。
- **烧录字幕可选视频编码器并支持自定义编码参数** ： 手动烧录新增「视频编码器」选择，自动模式会探测当前 FFmpeg 可用的硬件编码器并按序尝试，全部失败时回退 CPU；面板同时提供画质 CRF、编码预设和音频码率三个 FFmpeg 参数。
- 波形字幕拖动优化：中缝精确对齐并支持跨可见行联动拖动，拖动指示线跟随实际边界；左右手柄改用系统左右箭头，选中态与框选轮廓贴近字幕块边缘。

### 🔄 变更

- Launcher 部分文本更新和简化，列表重排序。增加独立的计费样式。
- Launcher「本地模型运行时」：运行环境目录不允许包含中文等非 ASCII 字符，填写后红字提示且不会保存。
- Launcher 首页新增「支持」入口，点击可查看B站小店赞助二维码；「项目官网」入口更名为「Github」。

### 🐛 修复

- 修复 Premiere FCP 7 XML（实验性）导出去空隙时间线时，视频 / 音频片段的摆放位置会随空隙数量累积偏移。
- 修复点击「停止媒体处理」后偶发无响应：取消请求发生在进程启动前后的竞态窗口时，现在也能正确终止正在运行的 FFmpeg 进程。
