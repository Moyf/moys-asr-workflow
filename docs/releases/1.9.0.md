## [1.9.0] - 2026-10-18

1.9 聚焦「从转写到成片」的编辑与交付：新增标记轨道、字词时间码、视频画面带与 ASS 单句缩放，去空隙、烧录、绿幕等导出可以直接在编辑器完成，AI 口播整理、重新断句与文稿对齐覆盖更多脏录音场景。

### 🚀 全新特性

- **标记与区段** ： 波形行新增独立标记轨道，可添加旗标、拖出区段、移动或调整边界，支持跨行拖动与撤销 / 重做。管理窗支持名称、备注搜索高亮、待复核筛选、按筛选结果全选与批量删除，批量操作可一次撤销；标记可关联复核区段启用或取消去空隙静音，作为独立来源随工程保存。预设收敛为八色并保留自定义色值，确认后的标记以半透明显示；标记编辑默认关闭，可用 `M` 切换。标记随工程保存，并可随 OTIO 导出。
- **AI 口播整理** ： Launcher「文稿匹配」可启用 AI 整理：文稿只作证据、不替换字幕文字，改说和独有内容保留，明确的重录废片等可逆移除，拿不准的生成待复核标记。可独立选择并记忆供应商、填写补充要求，参考文稿可选；重录选优保护信息更完整的连贯版本，可靠字词码下可移除句内废词；支持离线 HTML 对比、实时输出与停止操作。无法可靠核验时转为待复核，取消后不写出整理结果。
- **AI 重新断句** ： 按完整意群与阅读节奏重新选择断点，原文、标点与词级时间由本地重建；支持每条字幕最大字数，超长结果自动沿合法边界补拆，中文优先在完整词语与原有字词时间码边界拆分并局部重平衡，保护小数、比例、版本号及数字单位。整理与断句兼容模型输出的思考块、代码围栏与空行，失败时显示具体定位信息。
- **编辑器内烧录视频** ： 新增两个入口直接调用 FFmpeg (libass) 把当前工程 ASS 字幕烧录进视频并保存为 MP4：工具栏「烧录视频」按原始时间轴烧录完整源视频，「去空隙导出 → 重组后烧录视频」按保留区间重新编码并烧录（收缩时间轴）。编码自动探测硬件加速、失败回退 CPU，导出中可查看进度并随时停止。
- **去空隙视频 / 音频导出** ： 可按当前保留区间导出重组视频或 WAV 音频。视频尽量流复制，并按安全关键帧边界保守保留画面，同时提供匹配实际时间线的 SRT；内嵌文字字幕随视频同步裁剪，开放 GOP 等无法确认的切点明确提示，完全落在已移除空隙内的字幕会被整体丢弃。音频保留源采样率、声道与采样精度。结果窗口显示实际删除及仍保留的空隙，没有可安全删除的内容时不生成源视频副本。
- **视频画面带** ： 波形与字幕区域上方显示可隐藏的画面带，缩放时自动调整密度并逐步补齐，点击和拖动沿用定位与帧吸附；可切换铺满画面带或隐藏，铺满模式可关闭实时补间。转写先生成覆盖全片的关键帧预览减少等待；Launcher 负责生成独立基础缓存并报告进度，图片不存进工程，缓存失效或生成失败不影响字幕保存。

### ✨ 提升

- **ASS 主字幕单句缩放** ： 选中主字幕后可拖动四角控点或在视频画面内滚动调整整体大小；倍率、位置可独立保存、重置和撤销，缩放后的字幕继续参与自动排布。
- **特殊文本样式（MASS）** ： 强调、下划线、删除线、缩小、放大、`//注释//`、`!!震动!!` 与 `>>淡入淡出<<` 可组合，并支持配置符号规则、颜色与文字比例；主字幕可逐句选中后拖动定位 X / Y，与全局锚点样式配合。样式库区块更名为「特殊文本样式（MASS）」并提供语法说明；即时预览和样式库改用 Canvas 渲染，描边、行内强调和缩放文字更平滑。
- **拆分合并的符号补全** ： 拆分带特殊文本样式的字幕时两侧各自补齐完整符号对（含嵌套样式与整句淡入淡出的两侧包裹），渐进拆分（`Shift+B`）与复制拆分（`Ctrl/Cmd+Shift+B`）连续显示并保留字词时间码；合并相邻字幕自动折叠交界处重复符号，字符型与单词型一致。右键可为字幕左右添加预设或自定义字符；导出 SRT / TXT 等纯文本时自动剥除成对标记，右键新增「清理文本样式」一键移除。
- **ASS 样式库与实际画面预览** ： 内置样式右上角新增「重置」恢复出厂默认，样式库同步失效（403）时明确提示刷新页面；localhost 编辑器可用 FFmpeg / libass 生成实际字幕帧对照预览，独立窗口与暂停画面叠加分别控制，缺 libass 时回退即时预览。
- **字词时间码编辑** ： 可在波形中查看、试听、移动、调整和合并字词时间码，或将完整字词码转换为独立字幕并撤销；编辑文字时可同步字词文字，不再要求字数相等。单行波形将字词与整句上下分层，字词块可拖动并显示完整文本气泡。
- **纯文本编辑** ： 独立入口与批量操作分开，顶部查找支持循环定位、大小写与正则切换，展开后可单项或全量替换；查找替换与编辑视图并排，整体编辑新增行号列，时间范围变化以胶囊色块 diff 展示。批量替换与文本处理共用查找规则，文本处理可组合多个样式与自定义包裹；工程记住编辑视图，可选修改后移除字幕前后空格。
- **工程与全局设置重组** ： 随工程保存的时间、语言、字幕轨道、ASS 样式、颜色与说话人、表情包目录集中到工程设置，双语拥有独立标签页；全局设置按用途分组并可搜索，点击结果定位并闪烁提示。可关闭表情包功能、配置默认目录、切换消息提示位置。
- **翻译与双语** ： 翻译工程的中间与最终 MOSP 保留原文主字幕和可编辑译文副字幕，再次翻译完整覆盖副轨，「双语合并」只影响 SRT；翻译对比 HTML 可手动修改译文并下载核对后的 MOSP。翻译为中文时结合工程语言来源判定，新增「跳过已是目标语言的字幕」开关。开启双语后可直接编辑空副轨或导入副字幕，副字幕跟随样式预设位置，导出 TXT / FCP 7 XML / OTIO 可附加说话人名称。
- **文稿驱动对齐（实验性）** ： Launcher「生成时间码」和 CLI 可直接从准确文稿与录音生成字词时间码工程及 SRT，跳过 ASR；口播对齐也支持从原始 ASR 工程或录音开始，复用候选与试听，集中确认文字差异和多次重录后生成文稿工程、SRT 与报告。匹配与字幕 AI 处理支持实时输出与停止，取消后保留输入。
- **绿幕视频** ： 编辑器「更多导出」与 Launcher 工具箱均可生成绿幕视频，尺寸可选 1080P / 2K / 4K，可选择附带源音轨；ASS 实际画面在缺少视频时使用绿幕预览并提示导出入口。
- **LRC 歌词导入** ： 可通过「加载歌词」或拖入 LRC 添加主 / 副字幕，支持多时间戳、偏移与乱序整理。
- **自定义接口与本地模型** ： 后处理提供三个可独立命名的自定义接口槽位，`127.0.0.1` / localhost 端点允许空 API Key；翻译、校对、断句和 AI 整理分别记忆供应商。Qwen3-ASR、MOSS、Faster-Whisper 等本地模型在 Hugging Face 连接失败后自动回退 ModelScope；根据端点支持切换 JSON 输出约束，有限的格式错误可自动修复并剥离思考内容。
- **性能与界面** ： 几千条字幕工程中的全选、框选与撤销明显更快，编辑器脚本压缩后减少约 43%；错误卡片显示版本与发生时间，关于页集中展示版本、文档与社区入口。Launcher 与编辑器统一品牌配色（深色炭灰配橙、浅色中性白配红）；工程未保存时文件名旁显示琥珀圆点；人工核对清单升级 v2，支持忽略分组、完成后自动收起与导出结果。
- **官网更新记录** ： 官网新增历代正式版的图文更新与实际下载入口，正文由 CHANGELOG 统一生成，并提供正式版更新数据接口供后续软件检测更新；发布前可从 CL 生成分版本更新文档。

### 🔄 变更

- **断句与标点统一配置** ： 「断句与标点」设置同时用于转写和文稿匹配，默认清单为 `，。？！；,.`，断句末尾默认保留 `？！`；新增英文分号默认断句。
- **LLM 单批请求失败降级** ： 校对、翻译、重新断句和自定义任务遇到单批网络中断、超时或 HTTP 408 / 429 / 5xx 时保留该批原字幕并继续；全部请求失败、鉴权或配置错误仍中止。
- **ASS / SRT 内置样式默认值** ： 「ASS 默认样式」为 86 / 6 / 180，「ASS 副字幕样式」为 64 / 4 / 100，「SRT 渲染样式」（原「SRT 默认」）为 80 / 2 / 124、描边 6；主字幕强调色为品牌色、比例 1.3，默认启用 250ms 淡入淡出。已有显式样式和已保存数值不受影响。
- **默认颜色与符号规则** ： 新工程副字幕默认黄色调整为 `#f9ca1f`；特殊符号选项收敛为「无 / 双个符号 / 单双皆可」。
- **从源码运行需要 Node 与 pnpm** ： 编辑器与 Launcher 的构建产物不再提交进仓库，`pnpm install` 自动构建，服务器与 Launcher 启动前校验并自动重建；发布包不受影响，仍无需 Node。
- **桌面与平台调整** ： Launcher 分区标题改用内置 SVG 徽章，Linux 不再下载 emoji 字体；移除不再维护的 Tauri 桌面实验工程；macOS 上 Qwen3-ASR 的「自动」设备选择改为 CPU，MPS 可显式选择。

### 🐛 修复

- **烧录与命令行** ： 烧录时转换出的 ASS 以实际视频分辨率作为脚本分辨率，修复文字比预览大数倍的问题；新版 FFmpeg 可正常读取去空隙重组后的滤镜文件；打包版编辑器进行媒体处理时不再反复弹出命令行窗口。
- **工程与媒体关联** ： 子目录工程按实际位置保存媒体相对路径，旧工程可有限查找父目录中的原媒体；打开新工程时先停用旧保存目标，过期的保存与接管响应不再改写当前工程；较早媒体的异步加载不再覆盖后来打开的工程；带工程参数启动时不再复用其他 Launcher 会话的旧编辑器服务。
- **多轨编辑与保存** ： 拆分、主副轨交换与保存保留说话人及禁用状态，修复副轨拆分颜色组后无法保存的问题；AI 整理移除主字幕时同步禁用绑定译文；普通拆分保持 ASS 样式配对、淡入淡出及词时间码。
- **AI 处理稳定性** ： 整理与断句失败保留模型回复与请求记录，自动链跳过失败步骤并沿用步骤前字幕；重新断句后未参与处理的字幕保留原颜色；回填替换超过半数字幕时跳过并保留独立译文；结果链最前面保留原始输入，对比页仅供查看。
- **导出兼容** ： 修复部分 HEVC 视频无法重组导出的问题；相对路径工程无法导出 OTIO 的问题；选择保存位置期间切换工程会终止旧导出，不套用错误源媒体。
- **波形与界面状态** ： 单行波形横向滚动复用画布，`Q` 切换字词码只刷新必要内容；修复视频缩略图挤出字幕块、叠加轨切换后位置跳动；清空字幕后输入不再光标错位；关闭设置等窗口后焦点不再交回按钮导致空格误触发；纯文本编辑里清空字幕行的删除提示不再偶发缺失。
- **平台与提示** ： 仅空格的媒体 token 不再绕过校验，任务密钥进入日志与错误报告前脱敏；创建或写入失败时说明权限、路径长度等原因，不再误报为 LLM 服务失败；Linux 打包版的本地环境安装、模型下载与完成通知不再受包内旧动态库影响。
