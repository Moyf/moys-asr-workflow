## [1.11.1] - 2026-11-11

### 🐛 修复

- **图片字幕 FCP 7 XML 导入达芬奇全片离线** ： 旧实现仅表情包分支的 <file> 节点携带 <timecode>，图片字幕与图文分支缺失，达芬奇把整个序列判离线；现统一为所有 defining file 节点生成 timecode，盘符 URL 编码统一为小写盘符 + %3a（达芬奇对大写形态整段报离线，PR/VEGAS 解码等价），并新增达芬奇兼容契约测试防止回归。
- **打包版 Launcher 赞助二维码裂图** ： 「支持 MAW」弹窗的二维码在打包版中一直是裂图、无法扫码（源码运行正常、e2e 全绿）：1.10 引入赞助入口时页面引用了 `assets/support-qr.png`，但打包清单没带上这张图片。现已在打包清单补齐，并新增打包契约测试——打包页面引用的仓库文件若未被打包清单覆盖，CI 直接红。
- **Windows 中文用户名无法安装本地运行环境** ： 修复 Windows 用户名含中文（如「測試用戶」）时安装本地运行环境报「命令失败（退出码 1）」的问题：qwen-asr 依赖链里的 nagisa/DyNet 用窄字符 API 打开随包分发的模型文件，中文用户路径按系统默认代码页解释，实际存在的文件被误判为打不开。现在安装前自动把运行时目录转换为 8.3 短路径（同一物理目录的英文别名）；8.3 名称生成被系统禁用时改用公共目录 `C:\ProgramData\MAW-runtimes-<SID哈希>\<runtime>`（按进程令牌 SID 隔离，创建时设置私有 ACL，并在读取或运行前检查目录链权限），也可用新增环境变量 `MAW_RUNTIME_ASCII_ROOT` 指定无中文的公共运行时根。verify 失败且路径仍含非 ASCII 时给出明确自救提示。OCR / MOSS 运行环境走同一机制，一并受益。

### 🪒 工具

- **维护者 PR 看板** ： 支持悬停卡片以 Markdown 预览 PR 正文，长正文可在浮层内滚动；正文随列表一起获取，悬停无需额外请求，也支持键盘阅读。旧服务未提供正文时明确提示重启，不再误报为空正文；首次读取及刷新显示不定进度条，避免重复刷新，失败保留原有卡片。

- **视频 OCR 术语提取（独立实验工具）** ： 扫描画面并聚合术语候选，可追加 AI 语义筛选，再在带证据红框的确认页筛选、勾选和导出热词表；支持分组、图片导航、导出预览及精简显示。当前仅源码独立入口，尚未接入 Launcher 工具箱或发布打包。

- **本地工具页体验统一** ： 核对清单、转写/时间码对比、PR 看板与 CHANGELOG 编辑器沿用 Launcher 深浅主题，改进窄屏布局、分组热区、搜索重置和结果反馈，文字不小于 11px；新增工具功能与状态介绍页，使用说明可在页内阅读并保留源文件入口，支持 Markdown 高亮语法。保留各工具的数据、导出与保存流程；文案重写已过期、不再维护，波形工具台暂停维护，历史原型暂不处理。
