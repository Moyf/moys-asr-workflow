## [1.11.3] - 2026-11-12

### ✨ 提升

- **报错信息同步输出到开发者工具控制台** ： 编辑器的报错类提示卡（失败 / 操作不可用）与 Launcher 的错误面板现在会同时把一份副本输出到浏览器 DevTools 控制台，带 `[MAWE][hint]` / `[MAW Launcher]` 前缀便于过滤；失败提示还会附上原始错误对象（含堆栈）、错误码与诊断信息，Launcher 侧输出前先做密钥脱敏。提示卡消失或被关闭后，控制台副本仍可回查，反馈问题时附上控制台内容能显著加快定位。成功 / 中性提示不进控制台，同文案短时间连发只记一次，不刷屏。
- **安装依赖时自动换源重试** ： 镜像源抽风（如清华源对个别包间歇性返回 403 限频）不再让整个运行环境安装直接失败：镜像测速现在给出排序候选列表，安装命令失败且命中网络类错误（HTTP 403/429、超时、连接中断等）时自动切换到下一个镜像重试（最多 3 次尝试，跳过测速已失败的源），每次换源在安装进度里给出「镜像 X 安装失败（原因），切换到 Y 重试……（第 N/3 次尝试）」提示。全部候选用尽时，错误信息列出已尝试的源与各自失败原因摘要，并附「可设置环境变量 MAW_PIP_INDEX 指定源」的自救指引；「No matching distribution」等确定性错误换源无效，保持直接报错不重试；PyTorch 轮子源（extra index）不可达仍走原有安装前探测 + 明确报错路径。本地 / OCR / MOSS 三个运行环境共用同一安装管线，一并生效。
### 🐛 修复

- **MOSS 运行环境跟随设置的自定义安装路径** ： 设置里改「安装位置」后安装 MOSS Transcribe-Diarize 仍强制装到 C 盘默认目录（中文用户名下还会落到 `C:\ProgramData` 公共目录）：此前运行环境路径重构把 MOSS 切到独立配置键后没有任何写入方，设置字段对 MOSS 完全失效。现在 MOSS 在未单独配置时跟随「安装位置」字段的路径派生同名 `-moss` 独立目录（与本地模型环境互不叠装），仍可用环境变量 `MAW_MOSS_RUNTIME_ROOT` 单独指定；中文路径的 ASCII 化校验保持不变。
- **带颜色的双语工程合并后无法保存或丢色** ： 修复主字幕合并联动副字幕、直接合并副字幕，以及相关删除、新增和时长整理操作造成颜色组引用失效的问题；叠加字幕合并同样维护颜色与表情包组引用。同色字幕即使属于不同颜色组，合并后也会保留原颜色；不同色或含未标记段时不继承颜色，后续字幕的颜色组不再错位。

- **断句与标点设置持久化** ： 「⚙️ 设置 → 断句与标点」的五个数值（停顿断句、短句合并、单句上限与英文按词断句两项）此前完全不会保存，改完重启即丢；现在修改后自动保存到本机 `.env`，重启后恢复，留空仍表示跟随模型默认，识别预设覆盖这些字段后同样保存。
