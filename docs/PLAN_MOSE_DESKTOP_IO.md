# MOSE 桌面文件与路径能力开发计划

## 目标

在 MOSE 中统一工程、媒体和表情包的真实路径管理，覆盖打开、拖放、新建、另存为、最近工程、自动保存、备份、导出、外部修改与关闭确认。Windows x64 首发。普通 Server 与便携 HTML 继续使用浏览器能力，工程仍遵循既有 `.mosp` / `.json` 契约。

当前基线（2026-10-09 核对）：`merge/starlit-main`，HEAD `45432ce114c8424d93e9a341bea43b72fea081ee`，工作区干净。主 Electron 窗口已有打开工程、文件关联、单实例、下载对话框和后端生命周期管理；Server 已有工程加载/原子保存/最近工程/备份/媒体/缓存/导出。Preload 仅开放 `chooseProject`、`state`；新建与另存为依赖浏览器文件句柄；拖入的浏览器 File 不写入工程路径；表情包目录只支持输入路径。

## 架构及契约

编辑器通过可选 `MaweHost.desktop` 调用桌面能力；Preload 使用 `webUtils.getPathForFile` 登记真实文件；主进程负责原生对话框、有效路径引用和桌面生命周期；Server 负责工程校验、保存、媒体准备与缓存。保留现有 `MaweHost.files` 浏览器接口，不把 FileSystemFileHandle 伪装成 Electron 接口。

桌面能力包括：注册拖入文件、选择工程/媒体、打开工程、新建/保存/另存为、选择并验证表情包目录、重新关联媒体、导出落盘、打开/定位/复制路径、工程状态与关闭事件。结果统一区分成功、用户取消、失败，失败带稳定错误码。文件引用只在当前窗口会话内有效；renderer 不直接指定任意保存目标。

仅桌面模式提供受主进程保护的操作：

| 路由 | 行为 |
| --- | --- |
| `POST /api/desktop/project/open` | 按选定工程路径加载，可覆盖媒体并容忍媒体缺失/歧义 |
| `POST /api/desktop/project/save` | 新建、当前保存、另存为；校验完整工程、原子写入、绑定与最近工程更新 |
| `POST /api/desktop/media/attach` | 使用用户选定路径准备媒体并绑定，不因媒体更新而替换字幕工程 |
| `GET /api/desktop/project/status` | 返回当前绑定、工程代次、磁盘修订和媒体状态 |

新增操作密钥仅存在于 Electron 主进程与 Server 子进程之间，不添加到页面请求头、renderer、命令行或日志。既有页面令牌继续认证普通桌面页面 API。普通 Server 隐藏桌面接口；不增加任意路径读写或 shell IPC。

## 分阶段实施

1. **路径桥接。** 用同一工程切换入口接入文件按钮、拖放、文件关联、单实例和最近工程；保留打开/副字幕导入选择；工程与媒体同拖时按用户选定媒体加载；表情包目录增加原生选择器，失败/取消不替换原有效目录。最近工程在成功加载后才更新，按规范化完整路径去重。
2. **工程保存。** 新建在选择保存位置并初次写入成功后才绑定；空白页首次拖入不自动弹窗，首次 Ctrl+S 选路径；Ctrl+S、自动保存、备份和素材导出始终使用当前绑定。另存为成功后切换保存目标，旧文件不变；同目录媒体改用相对文件名，跨目录媒体使用绝对路径。保存失败保留旧绑定和脏状态。磁盘写入成功而最近设置写入失败时，应明确区分两者。
3. **媒体恢复。** MOSE 可打开媒体缺失/同名歧义但字幕有效的工程，提供重新定位或稍后处理；普通 Server 保持原有严格策略。重新关联保留字幕、时间码、标记、工作区和未保存修改，仅更新媒体字段；复用 FFprobe/FFmpeg/sidecar，区分源文件和播放缓存；按工程代次丢弃过期异步结果；缓存生成失败不阻断字幕编辑和保存。
4. **文件操作生命周期。** 工程、媒体、表情包、备份和导出文件提供路径复制/打开所在目录；关闭、退出、新建和换工程共用保存并继续/不保存/取消；退出确认完成后再关闭后端。每两秒检查当前工程修订和媒体存在状态，检测摘要包含内容，即使大小及时间戳不变也能发现工程内容修改。外部修改暂停覆盖保存，只提示重新加载/另存为/保留当前编辑。导出区分取消、失败和落盘成功，并让成功项可定位。
5. **回归与打包。** 按本文件验收矩阵及 `docs/TEST_FEEDBACK_MOSE_DESKTOP_IO.md` 执行；前端脚本修改重建并提交 `editor-bundle.js` 与 `.meta.json`，不手改 bundle、不默认重建 `blank-editor.html`。核验浏览器模式、真实 Electron 与带 MAW.exe 的独立 staging 套件；更新 CHANGELOG 与 MOSE 文档，不推送、安装覆盖或发布。

## 验收矩阵

| ID | 场景 | 通过标准 |
| --- | --- | --- |
| A1 | 拖入工程、编辑、保存、重开 | 保存回原路径；最近列表不重复；媒体恢复 |
| A2 | 同名不同目录工程 | 各自保存目标正确，最近列表不混淆 |
| A3 | 导入为副字幕 | 当前绑定不变；导入工程不加入当前最近记录 |
| A4 | 工程和媒体一起拖入 | 使用指定媒体，保存重开后仍有效 |
| A5 | 损坏/工作区 JSON、错误版本、取消 | 原工程和修改均保留，错误说明正确 |
| B1 | 新建、保存、重开、备份 | 正确绑定、记录最近项目并继续使用备份 |
| B2 | 首次拖入后取消首次保存 | 内存工程保留，无虚假文件或最近记录 |
| B3 | 跨目录另存为，再自动保存 | 只修改新文件，媒体引用有效 |
| B4 | 只读、锁定、写入失败 | 不切绑定、不标已保存、不损坏原文件 |
| B5 | 新建/另存为后的素材导出 | 使用当前新绑定；满足素材条件时可用 |
| C1 | 表情包选有效/空/无效目录及取消 | 成功显示扫描数；失败和取消保留原有效值 |
| C2 | 媒体导入/重新关联后保存重开 | 路径持久，字幕等工程字段不变 |
| C3 | 媒体缺失或候选歧义 | 字幕仍可编辑，可手动定位，不猜测绑定 |
| C4 | 换媒体/音轨/sidecar | 无错误缓存复用或重复缓存目录 |
| D1 | 外部改写或删除工程 | 提示并暂停覆盖保存，保留磁盘版本 |
| D2 | MOSE 自己保存 | 不误报外部修改，修订基线更新 |
| D3 | 有修改时关闭，选择三种动作 | 保存才关闭；不保存才丢弃；取消保留窗口；只提示一次 |
| D4 | 关闭时保存失败/取消 | 窗口、后端和修改保持 |
| D5 | 导出成功、取消、失败、并发导出 | 反馈正确，成功可定位，任务结果不串用 |
| E1 | 快速换工程，旧异步任务晚到 | 旧结果不能污染当前工程或保存目标 |
| E2 | 普通 Server 与便携 HTML | 文件操作仍可用，无桌面桥接报错 |
| E3 | 桌面接口越权/伪造引用 | 普通 Server 拒绝；没有任意路径写入或 shell IPC |

路径覆盖中文、空格、emoji、扩展名大小写、同名异目录、跨盘符。目录不可写、服务端中断、损坏缓存、取消选择均核对回滚。关闭握手超时提供等待/取消，不默认丢弃工程。

## 验证和交付

分层核对：新增接口与状态机单元/契约测试；现有新建/保存/拖放/导入浏览器回归；真实 Electron 的 Explorer 拖放、原生目录/保存选择、跨目录另存为、关闭保存、外部改写；完整套件 staging 启动。截图检查中英文、明暗主题、键盘操作，并实测新 UI 相邻间距至少 8px。真实 Electron 手测不能由 Playwright mock 代替。

按阶段运行对应定向测试。全量结束后运行：`npm run build:editor`、`npm run check:editor`、`npm run typecheck`、`npm test --prefix desktop`、`node --test tests/test_editor_host.mjs`、`uv run --no-sync python -m unittest tests.test_local_editor_server tests.test_project_backups tests.test_media tests.test_media_cache tests.test_packaging_contract`、相关 Playwright E2E、`git diff --check`。实际依赖/权限/桌面环境导致无法运行时，记录为阻塞或未验证，不能标记通过。

完成交付：本计划、进度账本、桥接与服务端实现、测试、生成 bundle/元数据、CHANGELOG、MOSE 文档、可测试的完整本地套件，以及逐项通过/未验证结果。测试实际失败须连同下一步记录；不推送、不创建 PR/tag/Release、不做破坏性安装。
