## 验证记录

语法 / 单元、资产契约、浏览器交互、字体 / 间距及截图检查均已完成，详见最终验收。打包 / 发布不在本次范围。

### 字号

修改 `web/editor.css` 和快捷键设置接线，为操作名称添加专用样式；Server 页面 `getComputedStyle` 实测为 13px。截图将在分组布局完成后统一检查。

### 分组 / 阶段汇总

新增七个原生 details/summary 分组。Server 页面核对 60 个命令全部且仅归入一个分组，数量为 4/17/16/11/3/7/2；默认全部展开（按追加反馈调整），浏览器点击导航分组后出现 open 属性。前两项代码完成，待最后一轮浏览器回归、截图及间距验收。

### 过滤

模板新增文字过滤、按键检索和清空过滤；支持操作名称、显示按键的文字匹配，按键检索使用当前绑定精确匹配。Server 浏览器点击检索后按 B，实测仅返回 split 项。过滤时展开命中组，清空时恢复原展开集合。完整文字 / 自定义绑定 / Esc / 无匹配场景待回归。

### 冲突提示

`message` 统一添加错误状态样式；Server 浏览器实测冲突提示颜色为 rgb(239, 68, 68)。同时修正冲突名称：无论被修改命令在清单前后，都显示另一条冲突命令。新增单元断言覆盖该场景。

### 浏览器回归发现及修复

首轮五项浏览器测试通过四项，发现快速展开后立即输入过滤时，details 异步 toggle 事件导致展开状态丢失。改为渲染前同步读取 DOM 展开状态，过滤视图不写回原展开集合；待重跑该回归。

### 追加反馈

分组改为默认全部展开。自定义样式按实际绑定与默认值比较，包含清除绑定和更改别名；不是按历史是否点过录入判断。新增浏览器断言覆盖改键出现标记、恢复默认移除标记。待验证。

### 自定义样式 / 阶段汇总

追加反馈的默认全部展开及自定义标记已通过五项浏览器回归，包含恢复默认移除标记。字体、分组、过滤和冲突颜色均已完成。新增冲突 toast 正在验证：复用现有 MaweHint warning 提示，显示 4 秒。

### 恢复默认按钮

按追加反馈，逐项恢复按钮只出现在 is-customized 项。恢复后按钮和徽标一起移除。待浏览器验证。
