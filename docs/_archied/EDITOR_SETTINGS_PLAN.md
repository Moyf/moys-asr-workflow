# 编辑器设置整理实施计划

本文件以维护者 2026-10-08 的最新要求为准，取代早期仅整理全局设置的方案。设置分支以字词 PR 为基底，只提交设置相关改动。

## 目标结构

- 项目设置：时间与语言、字幕轨道、字幕样式、颜色与说话人、工程表情包覆盖目录。
- 全局设置：界面、功能区、通用编辑、特殊编辑、拆分与合并、播放与预览、自定义色板、保存、字幕导出、更多导出、表情包、彩蛋。
- 局部面板：波形外观 / 显示，字幕编辑显示 / 操作，字幕列表筛选 / 显示 / 跟随，双语显示 / 联动 / 字幕管理。

## 行为与范围

1. 全局与项目窗口独立管理。功能区打开局部面板时保留全局窗口。工作区配置保留工具栏入口，不加入功能区索引。
2. 字幕选择与定位各自分组；字幕拖动统一边界交互设置。拖动播放指针默认启用并隐藏开关。
3. 特殊编辑集中微调、静音空隙、帧吸附、时间码分隔符和 ASS 特殊文本规则。
4. 播放跳过空隙移到播放与预览，但继续随工程的 gap_remove 保存。
5. ASS 模式、导出说话人名称和主字幕语言从当前工程读取，不受旧本机偏好覆盖。旧工程缺失两个新布尔字段时默认关闭。
6. 默认表情包目录是本机偏好，工程 sticker_root 是覆盖。验证成功后应用，失败保留当前素材；切工程废弃旧在途请求的发布。
7. OTIO 通用参数只有一处配置，普通与去空隙菜单跳转到同一页，格式专用单次参数保留原确认窗。

## 验收与交付

运行规定 Node / Python 测试、类型检查、相关 Playwright 和 diff / LF 检查；Python 使用 uv run --no-sync。自动化、实际浏览器、截图与至少 8px 间距分别记录。更新契约、帮助、指南和 changelog；使用 HTML 报告对照 PR 前后结构，并在 PR 评论中链接报告。仅提交源码，不生成 blank-editor.html，不合并 PR。
