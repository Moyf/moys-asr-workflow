MOSE 新增 UI 核对清单

逐项查看本轮 Electron 文件与桌面体验中新增或改造的可见界面。勾选框仅供本机核对，不会提交或同步状态。

这次截图里的媒体、工程路径菜单是在桌面文件体验的“路径定位”阶段加入的；原实现使用了单独的 <details> 和按钮样式，没有复用编辑器已有的 .dropdown-menu / .dropdown-item。现在三处路径菜单已改用统一菜单组件。截图中的「另存为…」则是原有工具栏菜单，可作为样式参照，不是这次新增的菜单外观。

顶部与路径菜单

媒体文件路径菜单 新增控件

媒体文件名旁的「⋯」菜单：打开媒体所在文件夹、复制完整路径。只有 MOSE 桌面版已关联真实媒体路径时显示。

重点看：菜单外观与「保存工程」下拉一致，位置不遮住文件名，两个操作清楚可点。

工程文件路径菜单 新增控件

工程名旁的「⋯」菜单：打开工程所在文件夹、复制完整路径。未保存到磁盘的工程不显示。

重点看：与媒体菜单保持相同触发器尺寸、菜单行高、圆角、边框和悬停反馈。

最近一次导出定位菜单 新增控件

桌面导出成功后出现「定位上次导出」，可打开导出所在文件夹或复制文件完整路径；下次导出成功后更新目标。

重点看：尚无成功导出时保持隐藏；连续导出时不串到旧文件。

表情包目录原生选择与路径操作 新增控件

表情包目录弹窗增加「选择文件夹…」，并提供打开目录与复制目录路径；手动输入和原有「读取」验证仍保留。

重点看：取消选择不改旧路径；验证失败不清空当前有效目录。

备份目录操作 新增操作

工程备份设置增加「打开备份文件夹」和「复制备份目录路径」。不改变现有备份开关、间隔和数量设置。

重点看：没有已绑定工程时相关动作应禁用或隐藏，不误开别的目录。

原生文件对话框与桌面确认

打开工程、加载媒体与选择目录 现有入口增强

沿用编辑器中的「打开工程」「加载媒体」「选择文件夹」入口，在 MOSE 中改由 Windows 原生选择器返回真实路径；取消时保持当前内容不变。

重点看：文件类型、中文/空格路径、取消、损坏工程和路径失效提示。

新建、首次保存与另存为 现有入口增强

首次保存、新建工程和另存为使用系统保存对话框；保存成功后标题、工程绑定、自动保存和最近工程记录切换到新文件。

重点看：取消或写入失败时仍保留当前内容与旧保存目标。

关闭窗口、退出和切换工程确认 新增流程 UI

有未保存改动时提供「保存并继续 / 不保存 / 取消」；保存取消或失败时窗口应继续保持打开。

重点看：关闭请求只提示一次；保存完成前不会退出。

工程被外部修改或删除 新增状态 UI

检测到当前工程文件变化后暂停自动覆盖保存，让用户选择重新加载、另存为或保留当前编辑。

重点看：重载前二次确认；选择保留时编辑仍可继续，自动保存保持暂停。

媒体丢失与重新定位提示 新增状态 UI

媒体文件不可用时提示原因，字幕工程仍可编辑；用户可通过原有「加载媒体」重新关联。

重点看：媒体缺失不阻止保存字幕；重新关联不覆盖未保存的字幕编辑。

桌面导出完成反馈 现有导出增强

等待系统保存窗口实际落盘后报告成功；取消不显示失败，写入失败显示原因；成功后可定位或复制路径。

重点看：连续两次导出各自对应正确结果，旧完整文件不被失败任务覆盖。
