# 编辑器设置结构梳理

本记录基于当前编辑器源码的设置入口、分组与存储契约；波形面板的三组划分已实现，其他调整仍是建议。梳理范围为编辑器的全局设置、区域设置、工具窗和导出配置。

## 当前结构

全局设置共有 11 个页面，导航上分为 5 类。

| 导航分类 | 页面 | 当前内容 |
| --- | --- | --- |
| 基础 | 界面 | 主题、强调色、界面语言 |
| 基础 | 通用操作 | 点击字幕的选择与跳转、播放中点击暂停、分组选中；波形指针拖动、边界联动、快捷键时间基准；按键微调幅度；空隙区段操作方式 |
| 媒体 | 视频预览 | 主副字幕与表情包预览；鼠标悬停预览、JKL 播放方式、跳转时长 |
| 媒体 | 字幕样式 | ASS 模式与特殊文本规则；主副字幕的字体、大小、颜色和背景；ASS 样式库入口 |
| 媒体 | 字幕颜色 | 颜色预览方式、自定义色板、颜色到说话人名称的映射、预览名称与分隔符 |
| 编辑 | 时间基准 | 毫秒 / 帧、FPS、吸附到帧、时间码分隔符 |
| 编辑 | 拆分与合并 | 编辑状态下的拆分按键、使用字词时间码拆分、合并字符、拆分标点、字幕语言类型 |
| 工程与输出 | 导出 | SRT 首条从零开始、按颜色的文件保存方式、说话人文件名后缀、导出附加说话人名称 |
| 工程与输出 | 保存 | 自动保存与间隔、工程备份与间隔、版本数量、打开备份文件夹；可用性受工程绑定影响 |
| 扩展功能 | 表情包 | 素材根目录、表情包 OTIO 的原始引用 / 便携模式 |
| 扩展功能 | 彩蛋 | 字幕忍者、音效、刀光及参数 |

区域设置和其他入口的分布如下。

| 入口 | 当前层次与内容 |
| --- | --- |
| 波形 ⚙️ | **波形外观**：来源、频谱颜色、振幅与响度适配；**显示**：基础模式窗口 / 多行模式行长与行高、分组标记、禁用字幕显示、字词时间码；**播放**：跳过已移除空隙 |
| 当前字幕 ⚙️ | **显示**：跳转按钮、时间操作、表情包；**操作**：Esc 是否取消编辑 |
| 字幕列表 ⚙️ | **筛选**：字数阈值、拆分后临时保留、点击自动滚动、隐藏禁用字幕；**显示**：序号、时间码、表情包、字数 |
| 双语字幕 ⚙️ | 显示方式、主副语言类型、双语时的波形行高、跨轨吸附、绑定对选中、绑定时同步时长、轨道徽标；末尾为导入和交换操作 |
| 工作区配置 | 布局配置的保存、另存、重置、删除及导入导出；Server 与便携模式提供的操作不同 |
| 静音空隙工具窗 | 扫描参数、检测与调整、禁用空隙内字幕及相应阈值；空隙操作方式另在全局设置，播放跳过另在波形 ⚙️ |
| 拼接 / 合并与延长工具窗 | 当前批量操作的参数、方向及执行入口 |
| 标记与区段工具窗 | 标注的管理、筛选与编辑 |
| ASS 样式库与实际画面窗 | 样式与输出方案编辑；实际帧自动渲染、暂停时叠加、尺寸查看 |
| 导出菜单与确认窗 | OTIO 的 SRT / 表情包 / 标记选项在菜单中；FCP 7、Lottie、OGraf 的格式参数在各自确认窗中；原时间线与去空隙菜单各有一份 OTIO 选项入口 |

## 优先优化的地方

### 1. 明确设置的生效范围

「全局设置」按入口命名，但其中既有用户偏好，也有工程属性。当前区域设置也混合不同范围：字词模式在打开另一工程时重置，空隙跳过跟随工程决定，波形布局涉及工作区。

建议在有歧义的选项旁注明「当前工程」「个人偏好」「临时显示」，并在工作区页面说明布局是否被保存到工程或本机。先让用户能判断改动影响哪里，再考虑是否改名为「设置」。无需因此更改现有存储行为。

### 2. 给区域设置一个可发现的总入口

目前全局设置没有汇总波形、字幕列表、当前字幕与双语设置。用户进入全局设置寻找字词显示或列表时间码时，很难知道它们在另一个 ⚙️ 中。

建议在全局设置增加「区域设置」索引或跳转链接，点击后直接打开相应区域面板。控件继续由原位置负责，避免两处配置产生同步和解释负担。

### 3. 梳理编辑与播放的边界

「通用操作」内容最多，包含点击、拖动、按键微调和空隙修正；「视频预览」又包含 JKL 和跳转时长，但「播放中点击暂停」在通用操作，「跳过空隙」在波形区域。

建议将「通用操作」归入编辑分类并改为「编辑操作」，保留明确的「选择与定位」「波形拖动」「按键微调」「空隙修正」组。将「视频预览」改为「播放与预览」，把播放习惯集中说明；波形的「播放」组保留常用跳过开关，并提供播放设置跳转入口。

### 4. 让局部面板使用一致的分组逻辑

字幕列表的「筛选」组包含「点击字幕后自动滚动」，这属于浏览行为。建议拆成「筛选」「显示」「跟随与浏览」；临时保留拆分结果仍放筛选，自动滚动放浏览。

双语面板目前把外观、语言、联动和修改内容的命令平铺在一起。建议分为「显示」「联动」「语言」「字幕管理」，导入与交换放末尾。双语波形行高与常规行高应互相提示，避免用户调错当前模式。

当前字幕的「显示 / 操作」分组已经清楚，可作为其他局部面板的参考。

### 5. 让名称和导出分类覆盖真实内容

「字幕颜色」实际上还管理说话人名称，可改为「颜色与说话人」。「表情包」中的 OTIO 引用方式属于输出策略，可在导出页的 OTIO 组配置，素材页提供跳转入口。

导出页建议按 SRT、ASS、OTIO、动态图形归类，并与各格式的确认窗互相链接。当前普通与去空隙菜单中的四个 OTIO 开关应继续共享状态；长期可提供一个公共「OTIO 导出选项」入口，减少菜单内重复排布。单次导出的轨道、尺寸等参数继续在确认窗中呈现。

## 建议推进顺序

1. 补区域设置索引、范围说明和容易误解的名称，减少寻找成本。
2. 整理编辑 / 播放页面及字幕列表、双语面板的内部组，保留现有行为。
3. 整理导出分类和共享选项入口。
4. 设置数量继续增长时，再考虑搜索；命中结果应能定位页面和具体选项，并说明模式或工程绑定导致的不可用状态。

以上建议无需一次性实施。保留现有「常用局部显示在区域 ⚙️，操作习惯在设置页，批量处理参数在工具窗，单次输出参数在导出确认窗」的分布，优先修正分类边界和入口发现性。
