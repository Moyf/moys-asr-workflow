# 编辑器设置结构与范围

此表记录设置整理后的实际结构。页面位置用于查找，生效范围依据读写代码和保存契约确定。

| 入口 | 页面 / 分组 | 范围 |
| --- | --- | --- |
| 项目设置 | 时间与语言：单位、FPS、主副字幕类型 | 当前工程；语言缺省按文字检测 |
| 项目设置 | 字幕轨道：双语、允许重叠 | 当前工程 |
| 项目设置 | 字幕样式：ASS 开关、主副字幕样式 | 当前工程；样式库供本机复用 |
| 项目设置 | 颜色与说话人：呈现、映射、名称、导出附加名称 | 当前工程 |
| 项目设置 | 表情包：覆盖默认目录 | 当前工程 |
| 全局设置 | 界面：主题、强调色、界面语言 | 个人偏好 |
| 全局设置 | 功能区：波形区、字幕编辑、字幕列表、双语 | 导航；不修改工程 |
| 全局设置 | 通用编辑：字幕选择、定位、字幕拖动 | 个人偏好 |
| 全局设置 | 特殊编辑：微调、静音空隙操作、帧吸附、分隔符、特殊文本规则 | 个人偏好 |
| 全局设置 | 拆分与合并：快捷键、字符、标点 | 个人偏好 |
| 全局设置 | 播放与预览：内容、JKL、跳转、暂停、悬停 | 个人偏好；播放跳过空隙是工程状态 |
| 全局设置 | 自定义色板 | 个人偏好 |
| 全局设置 | 保存：自动保存与版本备份 | 个人偏好；是否可用取决于保存绑定 |
| 全局设置 | 字幕导出：SRT、ASS配置入口 | 个人偏好；ASS 样式 / 说话人设置指向工程页 |
| 全局设置 | 更多导出：OTIO、格式专用入口 | 个人偏好；单次参数仍用确认窗 |
| 全局设置 | 表情包：默认目录 | 个人偏好；工程覆盖优先 |
| 全局设置 | 彩蛋 | 个人偏好 |
| 波形区 ⚙️ | 波形外观、显示 | 本机 / 工作区；字词显示为临时状态 |
| 字幕编辑 ⚙️ | 显示、操作 | 本机 / 工作区显示偏好 |
| 字幕列表 ⚙️ | 筛选、显示、跟随与浏览 | 本机 / 工作区显示偏好 |
| 双语字幕 ⚙️ | 显示、联动、字幕管理 | 显示与联动是偏好；导入 / 交换修改工程 |
| 工具栏工作区配置 | 布局编辑、预设、导入导出 | 工程布局与本机预设库 |

项目设置在全局设置左侧，两个窗口独立保留。功能区禁用尚未启用的双语入口，并在卡片内解释。局部面板按既有互斥规则打开，Esc 关闭最上层可见面板并回到目标区域按钮。

ASS 模式通过 preview.ass_mode 保存，导出附加名称通过 preview.subtitle.speaker_labels.export_enabled 保存；缺省均为 false。主字幕类型通过 multi_subtitle.main_split_mode 保存，单轨同样有效。ASR 的 split_mode 元数据保留。默认目录不写入工程；sticker_root 仅表示工程覆盖。

已补充检查：ASS 特殊文本规则归入全局特殊编辑；色板继续全局复用；工作区与 ASS 样式库不因入口调整改变共享机制。截图、间距与测试结果见 [实施记录](EDITOR_SETTINGS_IMPLEMENTATION.md)。
