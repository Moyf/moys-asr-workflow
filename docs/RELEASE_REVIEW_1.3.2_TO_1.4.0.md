# MAW 1.3.2 → 1.4.0-beta.4 变更回顾

本文按功能线整理 `v1.3.2` 发布后到 `1.4.0-beta.4` 的主要调整，方便回顾产品行为、默认值和发布边界。相同功能分支中“增加功能”与随后修复该功能的细项，已合并为一个功能条目，不再按提交逐条重复记录。

## 版本范围与总体结论

- `v1.3.2` 是本次整理的起点；之后连续发布了 `1.4.0-beta.1`、`1.4.0-beta.2`、`1.4.0-beta.3`，本次为 `1.4.0-beta.4`。
- MAW 仍然是“本地媒体 → ASR → SRT / `.mosp` 工程 → 浏览器编辑 → 导出”的收窄工作流；Server 版编辑器是当前主要使用形态。
- 单文件 HTML 编辑器和 `blank-editor.html` 继续保留兼容出口；Launcher 中同步生成 HTML 的选项暂时隐藏，在线编辑器和 Server 版是后续功能验收重点。
- 本地 Qwen3-ASR / FunASR 仍标记为 Beta。模型依赖、模型权重和 Launcher 冻结包分离，避免普通发行包膨胀。

## 1.3.2 基线

`1.3.2` 已具备快速上手教程、命令行入口、字幕列表双击定位、基础字幕跳转与拆分合并操作，以及 Server 停止接口。后续工作主要围绕以下方向展开：

1. 把编辑器快捷键和字幕时间编辑做得更适合连续剪辑；
2. 增加后处理工具箱与本地 ASR 实验流程；
3. 建立主字幕 / 副字幕的双语编辑闭环；
4. 统一 Server、单文件 HTML、Tauri 和在线编辑器的前端装配与版本显示；
5. 增加保存校验、发布打包和跨平台运行时的可靠性保护。

## 快捷键与字幕编辑

- 完善字幕列表双击、`Enter` 内联编辑和文字光标定位；字幕列表拆分优先遵循鼠标所在文字位置，字符型和单词型字幕分别使用对应断点规则，避免拆分点漂移到错误字符之间。
- 增加字幕时间的方向键微调、`Shift` 方向键贴合边界，以及更稳定的播放头刷新和字幕预览刷新。
- 调整 `WASD` 跳转：播放过程中以当前播放头所在字幕为参考；播放头落在字幕间隙时使用前方或后方相邻字幕，而不是继续沿用上次点击的字幕。
- 增加可配置的 JKL 播放模式。默认“倒放和正放”使用 `1×`、`2×`、`4×`、`8×`、`16×`，`J` 向倒放方向切换，`L` 向正放方向切换，`K` 停止并重置为 `1×`，停止状态再次按 `K` 以 `1×` 播放；倒放时速度控件显示负值，但不反向播放声音。旧的“慢速和倍速”模式仍可选择。
- 去掉视频预览 `40vh` 高度上限，修复设置、帮助等按钮抢占焦点后空格无法控制播放的问题；点击设置后仍可直接按空格播放或暂停。
- 增加 `Ctrl/Cmd+Shift+A/D` 直接粘合前后字幕，增加 `Esc` 跳过新手指引；更新新手引导文案，使其指向帮助入口和可配置的拆分按键。
- 修复 `Alt` 拖动字幕块的挤压语义：挤压副字幕只影响副轨；挤压主字幕时按绑定关系带动副字幕，松开或拉回时两条轨道可以恢复一致。
- 增加加载视频、音频、工程和 SRT 时的阶段进度提示；启用或禁用字幕后立即刷新视频预览。
- 增加频谱颜色开关，默认关闭并保持旧的纯色波形；默认优先使用媒体旁最细的 `.ReaPeaks` 波形层，没有时回退到 MAW 自己生成的缓存。
- 修复取整产生的 1ms 字 / 词时间码重叠。打开、保存和服务端接管工程时会自动修复字词级的小范围异常；真正的字幕段重叠仍然保留严格校验和定位提示。
- 统一生成稳定字幕 ID，修复旧工程、浏览器和 Server 在媒体接管或保存时产生不同 ID 的问题；同时保留副字幕 `items`，支持主副交换后再次恢复。

## 多重字幕与双轨编辑

- 增加默认关闭的多重字幕双语 MVP：可将 SRT、`.mosp` 或 JSON 作为副字幕导入，自动按时间容差匹配；支持主轨、副轨和双列字幕列表、共享双 lane 波形、副字幕独立导出，以及主副字幕交换。
- 建立主副字幕绑定闭环：`G` 绑定、`Shift+G` 解绑、`H` 同步时长；绑定时自动同步时长默认开启，可在齿轮设置中关闭。普通点击以最后点击的轨道为当前编辑目标，显式 `Ctrl/Shift` 多选仍可用于有意的绑定替换。
- 主副字幕支持联动移动、边界调整、成对删除、联动合并和拆分；主字幕联动操作会按绑定关系带动副字幕，副字幕独立操作不会反向修改主字幕。冲突时会裁剪或删除冲突副字幕并解除绑定，保证工程可以保存。
- 多重字幕波形空白区域支持按 lane 创建字幕：`N` 和 `Ctrl/Cmd` 拖动会根据鼠标所在轨道创建主字幕或副字幕，创建虚影直接出现在对应 lane；空白波形右键按当前时间点分别显示主、副字幕拆分入口，没有对应字幕时入口置灰。
- `B` 会根据指针位置选择拆分对象：没有主字幕但命中副字幕时拆分副字幕；在副字幕列表悬停已选项时，直接按文字光标位置进入副字幕拆分弹窗，并遵循副字幕自己的字符型 / 单词型设置。拆分逻辑会优先使用真实文字位置，不再只依赖时间码估算。
- 多重字幕下按 `↑` / `↓` 可在主轨和副轨之间切换当前焦点；有绑定时优先切换到绑定项，没有绑定时选择时间重叠或距离最近的字幕。波形 `Shift` 框选同时支持主轨和副轨。
- 增加副字幕预览背景色、字体、字号和颜色设置，扩展预览设置面板宽度并在主副字幕设置之间增加分隔；统一界面文案为“副字幕”。副字幕禁用项沿用主字幕的斜纹背景，并修复禁用 / 隐藏后的预览刷新。
- 共享波形的主副轨道编号徽标改为可选设置，默认关闭；开启后显示 `1` 主轨、`2` 副轨。绑定字幕仍显示 🔗 标记。
- 增加多重字幕列表与预览选择、时间快捷键、播放跳转、A/D 边界回退、右键解绑和字幕忍者反馈等 parity 修复；边界字幕按 `A` / `D` 仍能定位到第一条 / 最后一条。

## 后处理工具箱与 ASR

- 增加可链式后处理工具箱：文稿匹配、固定文字替换、LLM 校对、重新断句、中英翻译、自定义文字任务和受限 FFconcat 媒体重组。工具箱支持独立选择工程或 SRT，输出带操作后缀的新文件，不覆盖源文件。
- 建立 LLM 字幕协议：模型只接收临时 cue ID 和文字，时间槽由本地工程管理；支持 DeepSeek、智谱 Coding Plan、阿里云 Qwen 和自定义 OpenAI-compatible 服务。
- 增加模型列表获取、思考强度、SSE 流式正文 / 思考内容、调试原始返回保存；对坏 group、空字幕、JSON 错误和过大批次提供重试、跳过与具体警告，避免一个坏字幕拖垮整批。
- 翻译输出保持原工程的字幕段数、时间范围和段落边界，只替换文本内容；修复翻译 SRT 被重新拆分而与原工程不一致的问题。
- 增加 OCR 字幕去重工具，使用 CPU 版 RapidOCR PP-OCRv6 tiny 检查画面文字，命中后标记工程字幕 `disabled` 并从 SRT 输出移除；已有 `disabled` 会保留，并支持报告与独立 SRT 视频输入。
- 增加实验性本地 Qwen3-ASR / FunASR CLI 和 Launcher 本地模型 Beta：独立安装运行环境、模型缓存、准备进度、取消、修复、重试和扫描；统一输出时间戳与工程格式，不将 Torch 和模型权重打进发行包。
- 修复 Windows 冻结包漏带 `maw/qwen_audio.py` 导致本地模型启动导入失败的问题；补充本地运行时模块打包契约，避免类似漏包再次进入发布包。
- 补充 Soniox 上下文类型和调试原始结果，修复 Soniox 调试参数、macOS Finder 启动时 FFmpeg 路径和 Shift 滚轮波形方向等跨平台问题；增加必剪 ASR 实验供应商及流式分片重试边界。

## HTML、在线编辑器与发布

- 统一 MAWE Server、便携 HTML、Tauri 和在线编辑器使用的前端脚本清单；`web/` 是唯一前端源码，模板改动后重新生成 `blank-editor.html`。
- HTML 编辑器顶部从“生成时间”改为显示版本号，并与 Launcher 版本号同步；版本源为 `pyproject.toml`，发布前由同步脚本校验 Launcher、HTML 和项目版本一致。
- 增加 Astro 官网与 GitHub Pages 在线编辑器，网站文档从仓库文档同步生成；在线编辑器由主分支推送自动构建和部署，Server 版仍是当前主流程。
- 暂时隐藏“同时生成单文件版网页编辑器（html）”选项，并在项目文档中明确：单文件 HTML 继续兼容保留，当前以服务器版和在线编辑器为主。
- 暂时移除 Windows `MOSE.exe` 与 macOS `MOSE.app` 的 Release 打包，Launcher 默认使用 Server 版或 HTML 编辑器，缩小发行包。
- 修复 Windows 与 macOS Release workflow 并发写入同一 GitHub Release 的竞态，并补充发行包、Launcher 版本和本地运行时的校验。

## 默认值与当前边界

以下是 `1.4.0-beta.4` 计划发布时的关键默认行为：

| 项目 | 默认值 |
| --- | --- |
| 多重字幕 | 关闭 |
| 绑定字幕时自动同步时长 | 开启 |
| 跨轨道吸附 | 开启 |
| 同时选中绑定的主副字幕 | 开启 |
| 共享波形轨道徽标 | 关闭 |
| 主字幕自动使用时间码拆分 | 开启，有可用字词时间码时生效 |
| JKL 播放模式 | 倒放和正放 |
| 副字幕语言类型 | 按设置，可独立于主字幕选择 |
| 本地模型 | Beta，需单独安装依赖和模型 |
| 主要编辑器 | Server 版；在线编辑器随主分支自动部署 |

本次回顾不把每个修复提交单独当成一个新产品项目；后续查看具体实现或回归原因时，可通过 `git log v1.3.2..HEAD` 追踪原始提交和测试。
